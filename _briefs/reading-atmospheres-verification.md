## 验证边界

本次确认了音频加载、解码与实际播放图，没有把主观音色偏好或长时间听感当作自动检查结果。朗读压低使用真实媒体事件监听，18% 策略和加载时状态改变由测试覆盖；没有为验证而调用收费朗读服务。

后台暂停监听 visibilitychange 与 pagehide。Codex 内置浏览器在新建后台标签时仍报告 document.hidden=false，因此本轮没有证明真实浏览器切后台的可见状态变化；不能将这一点写成已通过的物理设备验收。

氛围偏好尚未纳入书房迁移包，界面与 README 均已说明。环境录音上游列出 Pixabay 与 CC0 两类许可，但没有逐文件映射；来源、哈希与现有限制保存在 app/assets/atmospheres/NOTICE.md，公开发布前需要继续核对素材记录。
