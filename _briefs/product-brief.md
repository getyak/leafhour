当前品牌为 Leafhour，正式网站 https://leafhour.com，唯一公开仓库为 `getyak/leafhour`。下方设计与交接保留各自日期及授权范围；当前发布与验收见 [品牌上线记录](../docs/verification/2026-10-16-leafhour-launch.md)。

更新日期：2026-10-12。用户已把产品扩展为由 Agent 组织的章节体验，并指定官方 DeepSeek Harness 为内核。翻译是工具之一；默认安静阅读，探索按需展开并返回原句。自己的解释、原文限定和新例子用于检验理解，时长与完成率仅作辅助。具体策略保留为设计提案。

最新实现基线是本机专注阅读服务与七章完整双译草稿，见 `focus-reader.md` 和 `full-book-execution.md`。Book Map、Reader Model、Harness 与 MCP 尚未接入；下面旧阶段安排不能据以重复生成全书或把现有服务当成未实现。完整设计见 [DeepSeek Harness 系统设计](deepseek-harness-system-design.md)。

## 用户与目标

入口是用户真心想深入阅读的一本书。Leafhour 帮助他把阅读持续下去，在原文、译文和自己的思考之间往返；读过之后留下可带走、可修改、可供自己的 Personal Agent 使用的记录。

核心体验依次关注阅读本身、拥有自己书房的归属感、可投入的阅读时间，以及服务于自己的私有空间。归属感本轮先按“自己的书与理解在同一处，回来可以继续”设计；公共社区是可选分享的下游。

用户提出了一个产品假设：AI 降低了获取概览的成本，摘要和概念可能更容易被快速吸收，但深入一本书的耐心、代入与体验更稀缺。该假设用于指导设计，还没有被本项目验证为总体社会趋势。Leafhour 的默认入口是正文，摘要只作为可选择的辅助。

## 用户明确要求

产品以开源为目标，支持本地运行和自托管。用户可以上传自己的书，完整导出自己的记录；原创评论与笔记由用户控制，不要求转让给平台。

深读能力包含高质量翻译、原文核对、概念与论证解释。直译、意译分别保存，编辑注解不混入作者正文。用户可以对原文、译文和自己的评论继续追问，也可以留下仅自己可见的评论。

语言学习是同一书房的一种阅读方式。学习者可选择原文优先、按需翻译；深读者可选择自己熟悉的语言优先。源语言、目标语言与展示方式分别建模，不能将所有书都限定为英文或只支持中文译文。

深度集成 AI，同时允许自己的 Personal Agent 通过 MCP 获取授权章节、资源与阅读记录。每天陪读由用户主动开启、选择时段和渠道，并可随时暂停。

## 四个页面

我的书房只呈现自己的书与继续阅读入口。第一本书由用户选定；设计小样只放一份真实的四段样本，不生成假书单或虚构阅读成就。

书内阅读保持正文居中。目录、翻译、旁注、评论与追问随需展开。学习模式优先原文，深读模式优先偏好语言；切换保持同一段落。2026-10-16 用户授权松鼠陪读，并在后续要求登录后默认开启、允许随时关闭：当前书处于开启状态时，按当前与近期实际前台可见片段异步留短消息，后续至少间隔 5 分钟，可忽略、进入现有阅读对话或随时关闭；选字、写笔记和后台期间不弹出，不建立站外推送。

我的记录按书与原文锚点组织评论、未解决的问题、对话和阅读时段。用户原话与 AI 回答分开，AI 可以提出理解候选，不能把自己生成的判断冒充用户掌握的知识。

数据与 Agent 页面管理导入、导出、分享范围及访问授权。全量备份与公开分享分成两个入口；公开分享先预览实际内容。外部 Personal Agent 默认不能读全书房，按指定书籍和数据类型授权。2026-10-16 用户明确授权站内阅读对话按当前身份只读自己的书房、公版目录与章节、检索书目和网络；不读私人笔记、不写进度，原文回声仍限当前及邻段。具体实现契约见 `../docs/superpowers/specs/2026-10-16-reading-agent-design.md`。

## 第一版与后续

第一版先跑通一个私人阅读闭环：导入书籍、接续阅读、双语对照、个人评论、基于当前章节追问、阅读时间，以及全量导出再导入。最小 MCP 能按授权读取当前章节、旁注、个人记录与阅读位置。

第二批处理整本书的提取校对与高质量翻译，提供术语一致性、审阅状态和断点恢复。多人分享、托管同步与每天主动陪读在阅读闭环稳定后接入；主动陪读由外部 Agent 的调度与通知能力承担。

本轮继续交付设计与接口契约，不启动生产应用、模型计费、MCP 服务或实际推送，也不把当前私有仓库自动变成公开仓库。

## 成功判据

用户中断数天后能从同一位置、同一个未解决问题继续；遇到难点时可以找到原文、译文与解释各自的来源，形成自己的评论。书与全部个人记录能在新实例恢复，迁移不依赖订阅和专有服务。

阅读时长只反映记录口径下的投入，掌握程度需要另外观察用户的复述、纠错和新例子。不能用看过摘要、打开页面或完成计时来宣称用户读懂了书。
