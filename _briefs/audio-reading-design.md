# Leafhour 听读体验设计

> 当前品牌为 Leafhour，正式网站为 https://leafhour.com。本文保留原设计或验收日期；其中旧名称只表示当时的品牌。

日期：2026-10-15。状态：用户已认可，按实现计划在本机执行。延续已有书页、选文和书房授权；本轮目标为本机可用的阅读与听读闭环，发布另行处理。

## 用户意图与模型分工

用户希望在书页内朗读选文或正文，也能按章生成通俗的双人讲解；声音可以试听、保存偏好，Personal Agent 可以调用同一能力。页面要保持安静、清楚，正文是主要内容。

按用户最新指示，文字生成继续使用 DeepSeek，包括翻译、讲稿和文字解释。语音默认使用 Gemini Flash TTS，对应 `gemini-3.8-flash-tts`；图片默认选 Nano Banana 2.1，对应 `gemini-nano-banana-2.1`，用于日后图片功能。本轮保存图片模型配置，不增加图片生成功能。此前 `gemini-flash-latest` 的要求已由本条替代。

现有凭据为 OpenRouter 类型，首版通过该服务端接口调用 Gemini，模型 ID 分别为 `google/gemini-3.8-flash-tts` 和 `google/gemini-nano-banana-2.1`。DeepSeek 继续使用已有官方接口。配置文件只保存供应商和模型选择，API 密钥保存在被 Git 忽略的本机环境文件。声音复刻需要的 Google 官方 Voices 适配不纳入首版。

现有本机环境具备 DeepSeek 配置。上一轮 OpenRouter 密钥认证成功，但一次短段落语音请求返回 402，没有音频。实现可通过隔离供应商响应完成契约和界面测试，真实中文音质与延迟必须在有额度的凭据下另验，不能据此声称语音已接通。

## 入口与视觉

沿用当前纸白、墨绿及衬线正文。新界面复用现有主题变量，夜读与低动态效果偏好均生效。动效只用于面板进入和播放状态变化，约 140–180ms；播放时不做循环装饰动画。

章节标题下增加一行轻量入口“听这一章”，选择正文朗读或双人讲解。正文宽度和已有目录保持不变。没有播放任务时不占用底部空间。

用户选中文字后，已有浮动工具条增加“朗读所选”；点击单段则显示“朗读这一段”。跨段选择保留实际选文及其顺序。中英对照时读取选中的一侧，不猜测用户想听的语言。

首次使用不要求填写声音资料。先采用默认预置音色，播放器提供“声音与语速”。声音设置沿用阅读设置抽屉，可在几个精选声音之间比较相同短文，保存朗读和两位讲解者的偏好。试听只在显式点击时生成，并复用缓存。

桌面播放器贴近页面底部，最大宽度与正文协调，显示内容标题、语言及译法，提供暂停、上下一段和进度定位。次要操作收进展开层。手机先呈现播放按钮与当前段落，展开后显示完整控制，适配安全区。所有操作至少有 44px 的可点击范围。

## 正文朗读行为

创建播放会话时固定书籍、内容版本、选文范围、语言和译法。中文意译不能被读成直译；缺译文时解释原因并允许用户改听原文，不临时补译。

播放时轻量标示当前段落。自动跟随默认开启，用户手动滚动后暂停跟随，出现“回到正在朗读处”。回跳复用稳定段落锚点。切语言、换字体和打开注解不替换正在播放的会话。

“从这里开始听”按段排队，当前段完成后才推进。只允许一项播放会话，切换任务先停止旧音频。切书、退出账户或授权变化时停止并清理旧会话，避免播放其他账户内容。

显示“准备声音”“可以播放”“生成失败”等真实状态。取消立即阻止后续生成和迟到结果进入播放器；已发送供应商的请求仍可能计费。余额不足不自动重试，不自动换供应商。

语速使用本地播放器的 playbackRate，范围 0.75–1.5，调整不再次生成。听到的位置独立保存，不推进正文的阅读位置，也不增加前台阅读计时。播放完成不代表掌握。

## 章节双人讲解

点击后先打开内容准备页，显示本章范围、预计时长、语音生成方式和费用口径。用户明确发起后才将所选章节范围发送给 DeepSeek，不包含私人笔记。

DeepSeek 返回结构化讲稿；两位角色分别负责解释和追问，直接进入内容，避免冗长开场和互相附和。建议短版约三到五分钟；时长为预计值，不能伪装成已生成音频的实测时长。

讲稿每一轮包含角色、文本和实际出处。服务端核验书籍、内容版本、段落归属与引用子串；无效引用拒绝展示。讲稿标为 AI 讲解，补充例子与作者原文分开。每段可回到出处。

先让用户查看并编辑讲稿，再显式生成语音。编辑后保存新版本，失效片段只重做相关音频，不能复用已经不对应的旧结果。新生成讲稿不会自动覆盖用户修改。

单次讲稿上下文最多 30,000 字符、80 段，输出最多 24 轮、6,000 字符。超限时让用户选择较短小节，不截取开头后声称讲解全章。每次生成展示实际覆盖范围。语音逐轮或按小组生成，先完成的有效片段可播放，不等待全部合成。

## 领域服务与数据

新增独立 audio-service，与现有 library-service 共用书籍读取和授权。网页和 MCP 都调用该服务；供应商适配器不接收任意文件路径，也不能自行扩大书籍范围。

AudioSession 保存 ownerId、bookId、contentVersion、mode、选文锚点和状态。AudioClip 保存实际文本哈希、语言、译法、音色、供应商模型及状态。ChapterDialogue 独立保存 AI 讲稿、用户修改版及精确出处。VoicePreferences 按账户保存，匿名访客只保留本地偏好。

缓存键包含账户、书籍、文本内容、模型、音色和演绎配置。相同文本的重复播放不会重复生成；不同账户不共享私人音频。改变语速不影响缓存键。任务幂等键与实际输入绑定，冲突返回 409。

本机任务状态使用现有原子写入模式，文件保存在 local/ 下。进程中断后未完成任务标为中断，保留可恢复的已完成片段，不在重启时自动调用收费接口。

托管适配必须使用数据库条件写入及私人对象存储，不能依赖函数进程内队列或临时目录跨请求保存音频。本轮不部署；若托管后端尚不具备音频存储，界面明确说明并保持正文可读，不能假装支持。

生成文件允许下载。导出保留讲稿、出处、偏好和播放位置，并提供选带音频的恢复包；密钥与供应商声音访问密钥不进入内容导出。本人声音原始录音是否备份需单独选择。

## 接口边界

| 接口职责 | 输入与结果 |
| --- | --- |
| 获取能力与偏好 | 返回当前可用的模型、音色和功能状态，密钥仅服务端保存 |
| 准备朗读 | 指定书籍、内容版本、选文锚点及偏好，返回实际文本和费用范围，不生成音频 |
| 创建与查询会话 | 显式提交幂等请求，返回任务状态、片段和播放位置 |
| 获取音频 | 重新检查所有者和书籍范围，返回有效音频内容，禁止把 JSON 错误当音频 |
| 取消会话 | 取消后续生成，并拒绝迟到结果发布 |
| 生成讲稿 | 指定章及范围，返回来源已核验的 AI 候选 |
| 修改与配音 | 分别保存讲稿版本和启动语音生成 |

对模型返回的文本、错误和音频分别验证。请求超时、429、402、缺少配置及不可用音色有明确状态；安全错误不包含凭据或其他用户的书名。

## Agent

增加 prepare、generate、status、cancel 四类听读操作，使用与网页相同的服务。读取正文授权不自动包含收费生成；创建任务需要指定书籍的 audio:generate 范围，读取已有音频需要 audio:read。

Agent 返回音频资源和回到原文的定位，由用户或宿主决定何时播放。Agent 不能通过任意传入文本绕过书籍授权；朗读 Agent 回答时，文本归属为 AI 回答，采用独立有界输入。

本轮不创建日程、通知或主动播放。

## 自定义声音

首版先完成预置声音。Google 官方的文字设计声音及本人声音复刻可作为后续能力；具备真实接口和凭据后才出现入口。

复刻需要本人参考录音和同一人的授权声明。录制前说明上传目标、保存时间和删除方式；删除同时处理本机样本及供应商声音。OpenRouter 当前 Gemini 端点没有公开参考录音复刻能力，不能把普通 TTS 接口当成声音创建接口。

## 实现验收

先验证选文和内容版本，再验证任务及播放器。必要自动检查覆盖选文未篡改、缺译文、账号隔离、幂等、取消迟到、402、错误格式和内容变化使缓存失效。

真实浏览器检查 390px、768px、1440px，以及窄屏 320px。验证工具条不溢出、选择和复制不误触、播放器不盖住正文、手动滚动暂停跟随、键盘操作、夜读和低动态偏好。模拟音频只能证明界面链路，必须显式标为隔离测试。

真实供应商验收至少包含一段普通话、一段中英混合文本和一段双人对话，记录首个可播放片段的等待时间、时长、失败状态与实际费用。听感和是否漏读由试听核对。验证下载后仍能播放，并在独立本机实例恢复讲稿、音频和位置。
