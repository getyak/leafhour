# 书房、设置与阅读对话

2026-10-15 用户批准「从上次继续」方向，并要求账号归入设置、提供 Agent 对话窗口、移除原有数据与 Agent 面板，逐项打磨真实操作。

书房只保留可收起的左侧导航与内容。搜索、全部书籍、我上传的、阅读日历、带来一本书和阅读对话归入侧栏，底部统一进入设置。桌面可收为窄栏；手机使用可关闭的抽屉。关闭后返回触发控件，键盘可以完成相同操作。

有阅读位置时，主区只展示一次正在读的书、真实段落和继续入口；其余书在下一层。新读者直接看到书架。搜索时显示全部匹配书籍，不再重复突出在读书。预览读取单段，保留稳定段落 ID；中文直译、意译和原文按实际存在情况显示，并注明 AI 草稿或缺译文。

设置包含账户、外观和关于。使用真实登录状态和现有登录流程，退出只放在账户中。外观保持设备本地保存。移除原数据与 Agent 的导航、导出恢复及令牌操作界面，保留领域接口和已有数据，避免破坏自托管迁移或旧客户端。

阅读对话按账号与书籍隔离。打开窗口只读取状态；显式发送才请求生成。默认仅用当前段及同章邻段，保留用户原话，AI 回答单独标记并核验原文出处。关闭窗口保留草稿；停止生成明确取消，迟到结果不得覆盖取消状态。没有服务配置时明确告知，不展示假回答。

实现以现有 Node/HTML/模块体系为基础；模型生成沿用官方 DeepSeek Harness，不创建独立书库、不读取整个书房或额外私人笔记。对话允许在现有授权上下文中提出连续问题，外部资料和书中文字不构成操作指令。

验收覆盖访客和已登录状态，桌面、平板与 320/390px 窄屏，搜索无结果、上传无效文件及重试、设置刷新恢复、账号切换、日历返回、对话无配置/等待/失败/取消及来源跳转。自动测试和真实浏览器分别记录。按仓库约定审阅、PR、检查后合并，并区分合并、发布与线上验收。
