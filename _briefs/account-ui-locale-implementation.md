# GET-198：界面语言与账号偏好

目标是让首次访问采用浏览器语言，手动选择在登录后跨设备恢复。沿用已有英文、简中、繁中和日语页面、语言入口及阅读视觉；界面语言不改变书籍、原文、译文、阅读模式或阅读记录。

## 状态边界

`ui-locale.mjs` 继续拥有唯一的界面语言状态与 catalogue 加载契约。初始检测、深链、历史导航、账号恢复和手动选择必须区分；只有成功激活的手动选择可以发起账号保存。账号恢复不写游客偏好，也不重挂载输入、草稿、对话或业务控制器。晚到的读取和 catalogue 结果不能覆盖新手动意图或另一账号。

根首页作为自动语言入口，明确语言路径保留按路径呈现的行为。自动入口的选择顺序是有效的页面语言深链、登录账号偏好、本机手动偏好、浏览器语言；网络失败可按已知本机偏好和浏览器语言打开页面。自动选择不能冒充用户已保存的选择。已有 authored 首页继续按其完整文稿呈现，避免整页替换正文。

## 账号记录

使用独立的账号 `ui-preferences.json`，与阅读偏好、头像、称呼和书籍分开。API 为 `GET/POST /api/account/ui-preferences`，返回 `revision`、`updatedAt` 和可空 `uiLocale`；POST 仅接受 `baseRevision` 与 `uiLocale`。认证身份决定归属，请求体不能指定 owner，写入要求 owner header 匹配，并遵守现有 Origin 边界和4 KiB上限。

缺失记录只读为空状态，不落盘；手动保存及显式清除都推进 revision。CAS 冲突保留本机选择，读回真实版本并提示，只有显式重试才再次保存，不能自动覆盖另一设备的更新。未知版本、损坏结构或非法 revision 必须安全拒绝并保留原值，不能当作新记录或虚假确认保存。

## 交付与验收

先完成后端与合成隔离测试，再完成语言核心、账号生命周期与现有入口接线。独立审查首轮发现的持久化 P1 须修复并复测关闭。阅读页沿用320 KiB JS与200 KiB CSS门槛；账号工厂保留原始共享模块边界，不放宽体积或单例图检查。

最终验收包括四语新浏览器环境、根首页与明确路径、手动切换、刷新、重新登录、第二浏览器上下文、换账号与晚到请求、失败提示和显式重试。真实账号仅进行有界偏好切换并恢复原值，不能伪造用户反馈或写阅读进度。必须经独立 review、当前提交 CI、正常合并、同提交 Production 与实际页面验收后关闭任务；本计划不代表功能已经上线。

## Authored 页面与手动选择的接线

根 `/` 仅做一次有界自动导航，四语明确路径只读激活完整文稿；打开、刷新或 catalogue 重试均不保存偏好。首页和公开指南的原生语言链接保留完整页面导航，通过90秒、目的路径绑定的 sessionStorage 交接记录区分实际点击。目的文档 catalogue 成功后可按该次显式动作记住本机选择；只有源端与目的端各自确认的账号一致时，才走原 singleton 的 picker 与账号 CAS。点击时账号尚未确认的记录只用于本机，不能日后绑定另一个账号。损坏、过期、新手动意图、路径或账号变化均使交接失效。

账号工厂作为 `ui-locale.mjs` 的固定原始模块依赖，语言仍只有同一状态所有者。公开图只精确增加 `reader-api.mjs` 的现有身份接线和四个账号工厂 backing，不增加别名、任意 query 或动态 catalogue 导入形式。原320 KiB JS与200 KiB CSS门槛保留。界面沿用既有语言控件及 notice；失败、冲突与明确重试不能冒充已经跨设备保存。

library、reader 与来源校对页复用其原认证结果，立即废弃旧 owner 的回调。公开指南没有原账号控制器，仅在该入口做一次有界身份读取；不在库页或阅读页重复认证。页面离开废弃请求，BFCache 返回等待原宿主重新确认身份。

## 验证与交付边界

独立审查发现的后端持久化 P1 已修复，74项复测通过。首页的中断、取消导航与账号生命周期问题已补回归；账号接线 I1–I6 独立检查31项通过。账号核心已修复换账号时的旧语言残留、虚假 ACK、首次读取失败重试、失效 guard 重试、迟到状态覆盖；另在异步请求真正发出前复查 owner/intent，防止微任务间隙发送旧请求。原始反例与永久测试52项通过。

真实 Chrome 使用隔离合成账号检查设置保存、新英文浏览器恢复、登录账号根首页、完整页面语言链接和身份未确认时仅记住本机选择，页面错误与失败请求均为零。桌面与390像素手机设置截图已检查，选项分组、状态提示和原有纸面配色保持统一，手机无横向溢出。

这些结果是提交前证据；最终完整独立 review、当前提交 CI、正常合并、同提交 Production 与默认账号上线验收必须另行完成并记录，不能以本地结果提前关闭任务。
