# 书房工作台 · 本机实现与验收

日期：2026-10-15。用户批准工作台方向，并要求移除提案说明、提示语和重复的“我的书架”标题，消除书架与阅读记录两个导航入口的重叠。

## 交付

以 `8b09127` 为基线，在独立工作目录实现 `/library`。保留现有 Node、原生网页、书房接口与数据格式；不引入前端框架或组件依赖。

导航统一为“书房”。自己的书优先展示；桌面使用封面网格，手机使用小封面与书目信息逐行排列。继续阅读仅依据真实阅读记录，并保留段落定位。屏幕阅读器仍有页面和书籍区标题，页面不重复显示标题与说明文案。

阅读近况在右侧或手机页面下方。完整日历在当前页打开，关闭后保留书架位置；首页日历入口通过 `/library?calendar=1` 直接打开日历。数据管理也在当前页打开，保留导出、恢复与按书授权入口。每日目标、整本读完标记和当前书切换收在阅读设置中。

## 验证

- 完整测试：263 项通过；另运行正式网页构建及差异空白检查。
- 新增四项行为检查：自己的书优先、搜索不改变原目录、继续阅读保留段落定位、跨月跨年的一周日期、仅展示真实记录。其中搜索与排序合在同一测试。
- 真实浏览器验证：本机登录、自己的书优先、正文保存笔记、笔记从书房及日历回到同一段、每日目标从 25 分钟改为 20 分钟后刷新读回、数据管理打开、退出后页面及隐藏对话框中私人书名与笔记均清除。
- 320、390、768、1440 像素宽度均检查；页面宽度与滚动宽度一致。320 像素日历无横向溢出；夜色主题、键盘关闭对话框、首页导航及首页日历入口已检查。
- 最终浏览器未记录错误。

验收使用独立的 `local/verification/workspace-preview/` 数据，不连接生产账号、不调用翻译或模型。验收书名为“书房验收”，笔记明确标注本机验收；未计入生产阅读记录。

截图与测试日志保存在忽略目录 `local/verification/library-workspace/`。桌面登录态截图含验收书籍；`final-desktop.jpg` 与 `final-mobile.jpg` 为退出后的实际页面。
