# 听读实现验收

2026-10-15。本机实现，未部署或推送。已认可的设计与实现计划分别见 `audio-reading-design.md` 和 `audio-reading-implementation-plan.md`。

## 可使用的流程

选中文字后可预览并朗读，也能从当前段落往后听。播放器支持暂停、切段、语速、下载和回到出处。手动滚动暂停跟随，换段保留这个选择。未完成的声音显示中断状态，不自动重新收费。

章首可生成双人讲稿，修改保存后再配音。讲稿每轮核对原文引用；原始 AI 稿与用户修改分开。每次配音保存对应讲稿版本，之后编辑仍可查看旧音频的依据。“已保存的听读”可打开声音、位置和未配音的讲稿。

声音偏好提供四个精选预置声音，分别选择朗读者和两位讲解者。语速在本机调整。首次试听或生成需要显式点击；同一文本与音色使用缓存。

听读备份可带音频，也能只带讲稿与位置。书籍迁移仍使用原有书房备份。Agent 使用同一领域服务，生成和读取音频分别授权。

## 验证结果

全库自动检查通过 176 项，听读专项通过 29 项；构建与差异格式检查通过。全库包括并行任务的阅读氛围检查，该任务的文件未纳入本次提交。

真实浏览器验证了 320、390、768、1440 像素宽度，没有横向溢出；声音面板的按钮与选择框点击高度至少 44 像素。夜读和系统降低动态效果生效。选中文本与朗读预览逐字一致，顶部“从这里开始听”可点击。

使用两个独立本机数据目录完成导出、下载、导入与继续播放。空白实例恢复到第 2 段、2.4 秒；恢复后没有自动播放。旧配音讲稿可查看，最新修改稿可编辑，刷新后仍可从已保存入口打开。播放中退出账户后页面返回书房，旧播放器文档被移除。

播放器验证使用可解码的隔离测试音，不是 Gemini 语音。脚本、截图与回执保存在被 Git 忽略的 `local/verification/audio-reading/`。

真实 DeepSeek 使用合成短材料生成 8 轮讲稿，用时 7,979 毫秒，引用核验通过，没有发送私人书籍。Gemini 普通话短文调用返回 402，未产生音频；中英混合和双人语音未继续调用。真实音质、延迟及账单仍待有额度后验收。

费用预览是估算，不是账单。参考 [OpenRouter 单价](https://openrouter.ai/google/gemini-3.8-flash-tts) 和 [Google 音频换算](https://cloud.google.com/text-to-speech/pricing)，核对日期为 2026-10-15。单价快照到 2026 年底失效，未知模型与过期单价不显示虚构金额。

## 本次取舍

- 复用现有功能分支和目录，保留原有配置与未提交的托管说明；判断错误的代价是调整分支组织。
- 音频读取同时返回字节与格式，备份使用已授权的账户对象；判断错误的代价是调整内部接口。
- Gemini 余额不足后停止真实调用，不把隔离音频当音质证据；真实效果仍须有额度后核验。
- 持久托管任务、本人声音复刻和部署延续已认可的后续范围；使用这些能力仍需后续接入。
- 并行阅读氛围任务的文件独立保留；其集成结果由该任务验收，本次全库检查也已通过。
- 账户变化通过现有身份响应、窗口激活和位置保存检测，未增加即时跨标签页通知；已载入的音频可能在检测前继续短暂播放。
- 沿用仓库紧凑源码格式；未来维护可能需要单独整理格式。

## 启动与剩余条件

运行 `READER_PORT=8344 npm run start:configured`。文字使用 DeepSeek，语音使用 Gemini Flash TTS；图片仅配置 Nano Banana 2.1，本版没有新增图片生成入口。凭据在被忽略的本机环境文件中，原有 `.env` 未修改，新增 `.env.audio` 仅当前用户可读写。

OpenRouter 补足额度后，需用合成短文核对普通话、中英混合和双人音频，记录真实时长与账单。本人声音复刻需要另接 Google 官方声音接口，托管需要持久任务和私人对象存储。本轮不创建通知，也未部署。
