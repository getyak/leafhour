## 打开当前版本

## 本次实际完成

官网和书房采用出版物式文字层级与安静的书页布局。默认三本完整英文原文来自 Project Gutenberg，保留出处和许可，正文使用原书目录；没有假装预先译完整本。匿名可以试读，进入本机书房后可以上传文字版 PDF、TXT 和 Markdown，保存自己的记录。

阅读保留可选择的原文，直译与意译独立保存为草稿，缺译明确标示。按需翻译只发送当前及最多前后各一段，登录或切换已有译文不调用模型。首轮真实 DeepSeek 片段生成已验证；后续故障与迁移回归使用固定验收草稿，不代表新增云模型输出或全书译文质量复核。

想法与问题按稳定段落保存，原话和 AI 内容分开。确认丢失可以重试，后来写的草稿不会被旧响应清空。阅读位置支持同段续读、长段落近似定位和多标签冲突选择；读取个人记录失败时可重试，不用空记录覆盖原有内容。

书房可以导出提取原文、译文、笔记和位置，并在新实例恢复。源 PDF 不在 JSON 备份中，页面会说明；补回相同 PDF 可以保留原记录。私人原件只能由所属账户下载，下载前核对字节与哈希。

MCP 与网页共用书房服务，正文、笔记、阅读活动及写入分别授权。网页可以生成当前电脑的接入配置，预览隐藏令牌；主动复制或保存才包含单书凭证。官方客户端已验证范围拒绝、迁移后的记录读取和网页撤回后的立即失效，没有自动修改用户的 Agent 设置。
