# MCP 与 Personal Agent 交接契约

状态：下文为初版接口设计。2026-10-13 本机 stdio 已实现六项工具、书目及单段两类资源，网页与 MCP 共用书房服务；官方 MCP 客户端已实际验证读取、范围拒绝及网页撤回后的拒绝。章节资源 URI、远程 OAuth 和宿主 Agent 的实际配置仍未验收，不能将本机客户端验证视为已连接用户的 Personal Agent。当前启动与配置见项目 README。

2026-10-12补充：内部 Chapter Agent 采用官方 DeepSeek Harness，MCP 继续作为外部 Personal Agent 的接口；两者共用旁读的领域数据、授权及 Run 管理。网页和 MCP 后续调用 prepare/act/cancel，模型不能声明自己的 grant。具体运行关联、取消与恢复见 [系统设计](deepseek-harness-system-design.md)，不能把 SDK close 与本产品的单次 cancel 直接混为一谈。

## 资源

`reader://books/{bookId}/manifest` 提供已授权书籍的书目、语言、来源版本与章节列表。

`reader://books/{bookId}/chapters/{chapterId}` 提供章节结构与有界正文，较长章节通过段落范围或分页读取。每段返回稳定 ID、版本、来源页码、翻译状态及引用定位。

`reader://books/{bookId}/passages/{passageId}` 提供单段原文、所选译文与关联资源。原书注释、编辑解释和用户评论分开，个人记录另有授权。

资源与工具都通过同一访问检查。知道 URI 不等于有权限。服务不暴露任意文件路径，错误信息也不泄露未授权书名与评论。

书内文字、历史评论与 AI 回答都是上下文资料，不自带新指令或新授权。资料中的“发送、删除、公开”等文字不能触发相应动作，必须由当前用户请求和有效授权决定。

## 首批工具

2026-10-15 本机听读新增 `reader_prepare_audio`、`reader_generate_audio`、`reader_get_audio`、`reader_cancel_audio`。准备仅需 content，不调用收费模型；生成与取消需 audio:generate，读取状态与 `reader://books/{bookId}/audio/clips/{clipId}` 资源需 audio:read。网页与 MCP 共用任务，撤回后后续片段停止发布和生成。Agent 返回声音资源，由用户决定播放，不计入阅读时长。真实供应商语音仍受余额不足阻塞；官方 MCP 客户端的授权、任务和二进制资源链路由隔离音频验收。

| 工具 | 用途 | 默认权限 |
|---|---|---|
| `reader_get_context` | 本次位置、本章概览、当前段与邻近上下文；获授权时附未解决问题 | 指定书籍只读 |
| `reader_get_chapter` | 按章、段落范围与目标语言读取内容，带翻译状态和来源 | 指定书籍只读 |
| `reader_search` | 在已授权书籍中检索段落与术语，返回可核对定位 | 指定书籍只读 |
| `reader_get_notes` | 分页读取个人评论、问题与 AI 对话，返回作者和引用 | 单独授权个人记录 |
| `reader_add_comment` | 按稳定锚点写入评论，保留调用来源与用户/AI 归属 | 显式开放写入 |
| `reader_get_reading_activity` | 取得口径清楚的位置与时段聚合，不推断掌握 | 单独授权阅读记录 |

完整备份、公开分享、删除书籍和批量改动不作为第一批自动工具。后续确需提供时，先准备具体变更或分享预览，再由用户确认。

输入验证书/章归属、范围和版本。输出支持游标、长度限制与可选字段；不默认把整书与全部私人对话塞入模型。写入请求带幂等键，重复调用不生成多份评论。旧锚点无法安全迁移时返回明确状态，不猜位置写入。

## 日常陪读

用户先选书、目标、时间与允许使用的数据，例如“每天晚饭后从上次的问题继续，最多一条消息”。宿主 Agent 按计划唤醒，读取上下文与必要资源，组织一小段正文、一个有出处的解释或一个未解决的问题，再交给已选通知渠道。

正文阅读中、用户暂停、目标已完成或没有有用的续接内容时保持安静。积压不补发多条；通知失败有事件 ID 与重试上限。建议携带原书锚点，点击返回同段。

MCP 服务提供上下文与工具，个人 Agent 保存日程并承担通知。第一版不另建通用人格 Agent，不创建本聊天的实际日程或提醒。

## 真实性与归属

Agent 使用阅读记录不等于知道用户掌握程度。评论保留用户原话与修改记录；Agent 注解标为 AI 候选，用户选择保存或确认后才进入其认可的理解记录。

实际阅读时段与 Agent 提交的手动补记分开。Agent 不能通过传入数字给用户增加学习时间。授权可撤回；撤回限制后续访问，已经导出的副本无法由本机自动追回。
