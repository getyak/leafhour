# Leafhour

[English](README.md) | [简体中文](README.zh-CN.md) | **繁體中文** | [日本語](README.ja.md)

**Stay with a book.** Your personal reading room, with AI by your side.

Leafhour 幫助人一點一點讀完一本想讀的書：今天從上次停下的原句繼續，讀後留下一點自己的理解，明天再回來。正文保持安靜；原文與雙譯、個人筆記和深讀提示在需要時出現。

專案在唯一公開倉庫 [getyak/leafhour](https://github.com/getyak/leafhour) 開發，程式、設計文件、執行計畫與驗收記錄均採用 AGPL-3.0 開源。預設公版英文原文及來源許可在 `catalog/`，私人書籍、個人譯文、筆記、閱讀記錄和伺服器端密鑰不隨原始碼發布。

閱讀頁的松鼠在登入後預設陪讀，手動關閉過的書會保留選擇：先安靜閱讀約 90 秒，之後根據目前和最近前台瀏覽過的片段，至少間隔 5 分鐘嘗試留一句話；沒有貼切內容時保持沉默。每次閱讀最多三次主動生成。氣泡可忽略、收合或點開現有閱讀對話接著聊，個人草稿不會被覆蓋；在閱讀對話裡可隨時關閉。松鼠支援拖曳和鍵盤 Alt + 方向鍵移動，位置保存在目前瀏覽器，氣泡隨角色移動；不再常駐「陪讀中」標籤。選字、筆記、聊天及背景期間不彈訊息，不讀取私人筆記，不向站外推送。

## 現在能做什麼

本機新增完整入口：官網 → 公版書庫 → 本機書房或郵箱驗證碼 → 上傳 PDF / EPUB / TXT / Markdown → 按段雙譯 → 個人記錄與閱讀對話。預設提供《愛麗絲夢遊仙境》《沉思錄》和《瓦爾登湖》的完整英文原文，來源及許可保存在 `catalog/`；譯文按需生成，不預先聲稱已譯完。預設庫不包含私人樣書。

新版書房同時支援本服務與 Vercel + Supabase。雲端使用獨立的私人資料表、版本檢查和私人原檔儲存；預設公版書允許匿名試讀。託管版預設使用郵箱與密碼登入，驗證碼作為備援入口；新建書房和找回密碼先驗證郵箱，再設定密碼。同時支援 Google 與 Apple 登入，自託管時按實際設定顯示可用方式。

書房從上次停下的段落繼續，其餘書籍留在下層書架。搜尋、上傳、閱讀日曆和閱讀對話統一放進可收合的左側欄；左下角顯示頭像和稱呼，點擊可編輯個人資料；登出和頁面外觀放在「設定」。手機使用抽屜導覽。原「資料與 Agent」操作面板已移除，原有資料與領域介面繼續保留。閱讀記錄、計時口徑、草稿與備份的具體行為見 [閱讀與資料保留](docs/reading-journey.md)。

書架使用霧綠色紙紋、細擱板線和布面裝訂，支援夜間外觀與系統減少動態效果。同一本書的封面在書架、搜尋和繼續閱讀中保持一致，文字來自真實書籍資訊；紙紋素材的來源和提示詞見 [品牌素材說明](app/brand-assets/README.md)。

懸停或聚焦書籍可開啟更多操作，觸控螢幕直接顯示按鈕。封面與手柄可拖曳排序，也可在選單中前後移動或用手柄的左右方向鍵；登入後的順序按帳戶保存。移到回收站會保留原文、譯文和閱讀記錄，可恢復到書架，不提供永久刪除。

「加入讀書行程」可設定本地時間、時長、重複週期和提醒，下載 `.ics` 檔案；需自行開啟並加入系統行事曆，提醒才會生效。應用不會直接建立系統行事曆事件。

「送出這本書」可寫收件人稱呼和贈言，生成可拆開的紙質感贈書信。連結包含書籍介紹，收件人可下載完整閱讀包，登入後加入自己的書架。原文與勾選的已有譯文隨信送出，個人筆記、問題、閱讀位置和計時不包含在內；譯文保留草稿等原有狀態。收回連結會停止後續存取，已經下載的包和已領取的書不會被遠端刪除。託管領取要求原文與譯文合計不超過 3.5 MB，較大的包可下載到本機接收。

贈書按「寫贈言 → 看拆信 → 封好分享」進行。預覽複用真實收件頁面，僅在瀏覽器內傳遞可見介紹，不建立連結；明確封好後再自行複製或呼叫系統分享；同一帳戶關閉視窗再開啟會保留本次草稿或已封好的連結。收件人可先拆信再登入，登入返回後保持信箋展開。信封與卡片採用原創不規則紙邊、郵戳與柔和紙紋；動畫可折回，並尊重系統減少動態效果設定。

- 中文、英文、對照三種閱讀方式，直譯和意譯獨立保存；缺譯對照只顯示一次原文，明確標示缺失的版本
- 試讀時登入翻譯會返回同一原文段落，再次明確點擊才生成；服務未設定時如實停用入口
- 段落原文、註解、想法和問題按穩定 ID 對齊
- X-ray 論證透視、站隊翻頁、回聲批改和克制的章節互動
- 選取文字保存淡黃色私人高亮，點擊可取消或寫想法，從「我的記錄」回到原句
- 選取句子後生成可設定的單語或雙語分享圖
- 字體、字級、行高、段距、字距、首行縮排和紙面主題
- 閱讀日曆、每日目標、自己的理解與問題，按原文位置回訪
- 主動開始的前台閱讀計時，手動確認章節與整本讀完
- 高亮、評論、問題、閱讀位置、時段和閱讀標記匯入匯出
- 本機 JSON 儲存，或 Vercel + Supabase 私有託管

## 本機運行

Node.js 22.13 及以上：

```bash
npm ci
npm test
npm start
```

預設存取 `http://127.0.0.1:8330/` 官網，`/library` 是書房。原有私人樣書入口移到 `/read`；`/read?book=ID` 開啟新書房中的指定書。沒有本機私人樣書時也能用預設公版庫啟動。本機上傳與記錄放在被 Git 忽略的 `local/service/portal/`，不會進入公開原始碼。

需要讓個人資料獨立於原始碼目錄時，可設定 `READER_DATA_DIR` 後繼續使用 `npm start`。目錄佈局、重啟與更新方法見 [本機實例與資料](docs/local-instance.md)；未設定時繼續使用原有 `local/service/`，不會自動搬遷已有書房。

閱讀設定支援獨立選擇深讀/語言學習目標、優先語言、展示方式與直譯/意譯，切換時保留段落位置；舊記錄繼續原文優先。用法見 [閱讀目標與語言](docs/reading-preferences.md)。

已保存的想法與問題可單獨修改，保留建立時間、引用與原文位置；另一處修改發生衝突時，先讀取較新原話再明確保存。失敗重試保留新草稿，來源不確定時不猜測跳轉。具體行為與修改草稿的備份邊界見 [修改自己的想法與問題](docs/personal-records.md)。

需要 AI 時，將唯一模板 [`.env.example`](.env.example) 複製為 `.env`，填寫需要的 Key：`DEEPSEEK_API_KEY` 用於翻譯、閱讀對話和講解稿，`GEMINI_API_KEY` 用於本機語音。模型預設選好，只閱讀時無需設定。`npm start` 自動讀取設定，啟動提示會說明是否已設定、是否仍待驗證，以及目前部署是否支援語音。同一模板還包含預設註解的託管與進階選項，按需查看 [設定說明](docs/configuration.md)。

PDF 在本機提取，限制為 20 MB、500 頁和 200 萬文字；掃描 PDF 和加密檔案給出明確失敗原因，目前不含 OCR。EPUB 按內置閱讀順序提取，暫不支援加密或 DRM 版本。預設 30 本英文閱讀版使用已核對邊界的原書目錄，首次從正文開始，前言和附錄仍可開啟。私人上傳暫按每 30 段分成閱讀片段，介面註明自動分段，不能當成作者的原章結構。目錄調整保留段落 ID，已有筆記與位置繼續對應原句。

重新選擇無效檔案會清除舊選擇，不能誤傳上一次的檔案。上傳失敗後可以重試或換檔案；關閉上傳視窗會讓目前請求繼續，成功後更新書架。私人 PDF 閱讀頁可展開查看檔案名稱與提取說明，明確標示尚未校對。

來源說明中可下載自己上傳的原檔案校對；下載前校驗檔案內容，原件僅向所屬書房帳戶提供。JSON 備份沒有原件時會明確提示，再上傳同一原件可補回並保留已有譯文和記錄，包括從其他帳戶遷移的書籍。原件下載不屬於現有 MCP 正文授權。

書房顯示上次閱讀的章節，點擊「繼續閱讀」回到原段落和排版。登入後的伺服器端位置優先，匿名試讀只保存在本機瀏覽器。多個標籤頁同時閱讀時，舊位置不會靜默覆蓋新位置；頁面保留目前內容，讓使用者選擇較新的位置或繼續讀這裡。匯出目前記錄也遵守這項檢查。

閱讀設定中的「書頁佈局」可選捲動閱讀或翻頁閱讀。原文與中文譯文都可以像攤開的書一樣左右雙頁閱讀，用方向鍵 ← → 或頁底按鈕翻頁；窄於 900px 的視窗顯示單頁。翻頁到章末可繼續下一章，向前可返回上一章。中英對照保留原有排列；切換回來會保留翻頁偏好。書房在 980px 及以下改用抽屜導覽，為正文和書架留出空間。

長段落另外保存段內閱讀比例，重新整理、字級變化或不同視窗寬度下可恢復到段落中相近的位置。舊記錄繼續按原像素偏移恢復。比例定位不保證逐字相同；原文和段落標識保持不變。

想法和問題保存期間可以繼續寫。保存確認只清除那次提交，後來寫的文字仍作為草稿保留。草稿與待確認的提交按帳戶和書籍快取在瀏覽器；確認遺失後可準確重試，重新整理會先核對已保存記錄。瀏覽器無法保留草稿時會提示複製文字。讀後記錄裡的未完成內容可從「草稿」找回；多個標籤頁分別保留想法。書房匯出合併本機待同步時段與章節標記，讀後草稿單獨保存在備份裡；透過網頁恢復後仍是本機草稿，只有主動保存才成為筆記。段落旁註面板與讀後記錄共用草稿入口，舊版段落草稿也可找回並匯出。

匿名試讀開啟個人記錄時，可以登入並回到同一原文段落和面板。返回意圖只使用一次，後續重新整理仍按正常續讀位置。已登入但記錄讀取失敗時可在目前頁面重試；讀取到更新的位置後，先選擇從哪裡繼續，匯出也遵守這項保護。超過引用上限的整段文字不寫入記錄引用，原文與段落關聯保留，重試仍使用同一個提交識別碼。

### 書籍與目錄

頂欄書名和目前章節可以點擊，開啟書籍介紹浮層，查看已有簡介、作者、原文出處與目前章。浮層可用 Esc、關閉按鈕或點擊外部收合，正文位置保持不變。左側「書房」和「目錄」採用一致的圖示、間距與觸控高度；目錄按章排列，標記目前章，點擊整列即可進入。帶編號小節的書仍可展開小節並返回對應段落。

### 閱讀氛圍

閱讀頁右上角的「氛圍」提供林間書頁、雨窗夜讀、木屋爐火和海邊清晨，也可以選擇「只留紙面」。風景保留在正文周圍；開啟旁註後，正文仍有自己的不透明紙面。窄螢幕優先保留文字，夜讀與系統低動態偏好繼續生效。

選取場景會預設開啟對應的輕音樂與環境聲；切換場景時，聲音一起更換。兩路音量分別調整，調到零即可關閉其中一路，切換場景會保留這項靜音選擇。關閉面板後可繼續讀書，頂欄可以暫停聲音。重新整理保留場景但不自動播放，離開頁面會暫停，開始朗讀時背景聲音會降低。配樂由本機合成琴音與和聲，環境錄音和圖片隨應用提供，運行時不連接第三方媒體服務。來源、加工與許可說明見 [素材說明](app/assets/atmospheres/NOTICE.md)。

「場景動效」控制正文背後的林間光影、雨絲、爐火暖光與海面緩移，面板中的預覽也會跟隨。夜間模式可用，正文保持穩定。動效與聲音可以分別關閉；切到背景會停止運動，系統的低動態偏好優先生效。

主題、音量與動效偏好按帳戶和書籍保存在目前瀏覽器，暫不包含在書房匯出與恢復包中。聲音不是閱讀或翻譯的前提，也不會增加閱讀時間或觸發模型請求。

### 郵箱與翻譯

本機需要郵箱登入時，在同一個 `.env` 中設定 SMTP 後用 `npm start` 啟動，變數見 [設定說明](docs/configuration.md)。驗證碼真實透過 SMTP 傳送，十分鐘過期、一次有效、五次失敗後失效；註冊與登入共用入口，工作階段保存在 HttpOnly Cookie 中。沒有 SMTP 時不會假裝發信；本機書房是獨立的單人使用方式，不代表郵箱身分已核驗。

登出後清空頁面的私人書名、授權清單、顯示中的權杖和檔案選擇；書籍與已建立的 Agent 授權仍保存在伺服器端，授權需要在書房主動撤回。帳戶切換後，舊請求不能更新新帳戶頁面，舊恢復任務不能繼續向新帳戶寫入；從其他標籤頁返回時會檢查目前身分。

設定 `DEEPSEEK_API_KEY` 後，點擊段落再選擇「翻譯這段」。僅傳送目前及前後各一段，直譯和意譯獨立保留為 AI 草稿。字級、已有譯文切換和閱讀都不呼叫模型。該按段翻譯使用 DeepSeek 介面；原樣書回聲繼續使用官方 DSH。

翻譯進行中可以切到其他段落，結果仍歸屬原段落；回到仍在翻譯的段落時不能重複提交。切走或取消選擇後，遲到結果不會強制改變閱讀語言。失敗提示與重試也對應原段落。已有雙譯直接在本地開啟；未設定服務時明確停用生成入口，保留原文和已有譯文。

中文原文直接閱讀，沒有已有譯文時只提供原文視圖，不標成英文或缺譯。中文段落不呼叫中文翻譯服務；已有的雙譯記錄仍可讀取。摘錄標示「中文原文」，筆記引用另外保存原文或譯文的歸屬。中英文識別使用文字啟發式，載入舊私人書時也會校正早期語言標記；這不代表能準確識別任意混合語言書籍。

書房「設定 → 資料與遷移」提供開放 ZIP 備份與恢復、選定個人記錄 Markdown/JSON 和內容一致的分享預覽。備份包含已同步的閱讀內容、對話引用、記錄和位置，原始檔案可選擇納入；不包含憑據、授權或未完成的 AI 任務。本機未同步草稿與聽讀資料沿用各自的恢復/匯出入口。詳見[閱讀書房遷移](docs/library-portability.md)。舊 JSON 與授權領域介面繼續相容。

恢復先校驗整個清單、來源版本和目標衝突，錯誤包說明原因且不寫書房。有效包通過檢查後若發生 I/O 失敗，可能留下部分進度，必須重試，不能當作成功。重複 ZIP 匯入保留穩定 ID、目標已有位置與譯文；乾淨實例保留備份位置的時間和版本。不恢復模型運行或授權。

### 閱讀對話

側欄「閱讀對話」開啟圍繞目前書籍的視窗。可以先看原文、直譯和意譯，問題明確傳送後才執行模型。回答標為 AI 解釋候選，引用可以回到原文；使用者問題另存到對應段落，能在閱讀日曆中回訪。

對話沿用官方 DeepSeek Harness，預設僅按需分頁查閱目前書；傳送框旁可明確選擇並保存「書房、公版與網路」。會傳送問題、書名與目前章段位置、允許範圍內最近最多六輪對話，以及按需讀取的文字和檢索詞，不自動讀取私人評論。範圍、雲端處理說明和恢復規則見 [閱讀對話的查閱範圍](docs/reading-chat-scope.md)。每次生成有上下文、時間與費用上限。關閉視窗保留草稿，停止會向執行實例傳送中斷；重新整理先找回原請求，不重複生成同一次問題。沒有配置模型時可以保留草稿，傳送按鈕不可用。每本書最多保留 100 次提問，視窗可匯出這段對話；這是有界版本，尚無無限歷史。

### 朗讀與章節講解

選取文字後點「朗讀所選」，也可以在段落的更多選單選擇「從這裡開始聽」。章首「聽這一章」提供開篇導聽、從目前位置朗讀和雙人講解，也可進入整書導覽。DeepSeek 按原文分批整理並核對講稿，Gemini 配音，講稿可隨時展開查看和修改。底部播放器提供暫停、語速、段落切換、出處回跳和下載；在手機上點內容標題展開更多操作。

聲音與兩位講解者的偏好在「閱讀設定 → 聽讀 → 聲音與語速」中調整。改變語速在本機完成，不再次生成。首次試聽會生成固定短文，重複試聽複用已有聲音。未翻譯的內容明確提示，可由使用者選擇改聽對應原文。

模型分工為文字使用 DeepSeek，語音直連 Google 官方 Gemini 3.8 Flash TTS，返回 WAV 音訊。日常在 `.env` 填寫 `DEEPSEEK_API_KEY` 和 `GEMINI_API_KEY`，模型參數使用統一預設值。需要覆蓋時使用 `READER_TRANSLATION_MODEL`、`READER_AUDIO_SCRIPT_MODEL` 和 `READER_SPEECH_MODEL`。舊的 `.env.audio`、`READER_DIALOGUE_MODEL` 及 `npm run start:configured` 繼續相容；優先順序見 [設定說明](docs/configuration.md)。圖片尚無生成入口，預設模板不展示圖片模型。真實環境設定不進入 Git 或匯出，公開模板只保留變數與佔位值。

生成聲音需要有效額度，餘額不足會顯示真實錯誤，不重試扣費或自動更換供應商。取消會停止後續片段並拒絕遲到結果；已經發給供應商的請求仍可能計費。聽讀位置獨立於閱讀位置與時長，重新整理恢復後等待使用者點擊播放。

在聲音設定中可匯出與恢復聽讀備份，包含講稿、聲音、偏好和播放位置。恢復包限 32 MB；更大的記錄可分別下載音訊。匯入會先核驗全部來源和聲音雜湊，再寫入，已有修改稿發生衝突時不覆蓋。書籍本身透過原有書房備份遷移。章首和聲音設定裡的「已保存的聽讀」可開啟音訊與講稿，恢復後等待點擊播放；配音時的講稿版本單獨保留，之後編輯不會改掉舊音訊的依據。聽讀清單也能僅匯出講稿與位置，較大的音訊可分別下載。

本機和託管共用聽讀領域邏輯。託管任務使用 Supabase 私有儲存、並發租約與有界背景處理；離開後可透過已保存任務繼續尚未提交的步驟。正文、講解與閱讀位置分別保存。「問這裡」暫停聲音並帶出處開啟現有對話草稿，不自動傳送。完整範圍、費用與恢復說明見 [隨書聽讀](docs/guided-listening.md)。本人聲音複刻尚未開放。

當前導聽實現與驗證見 [2026-10-17 驗收記錄](docs/verification/2026-10-17-guided-listening.md)：真實官方 Gemini 雙人小樣已生成，本機瀏覽器已驗證播放、原文跳轉、提問草稿和分段接續。

驗證證據在被 Git 忽略的 `local/verification/audio-reading/`。早期記錄（2026-10-15）：真實 DeepSeek 合成材料講稿為 8 輪，引用檢查通過；Gemini 首次短文請求返回 402，未生成真實語音。播放器、編輯和遷移用隔離音訊驗證，不能據此宣稱 Gemini 音質或播放延遲已通過。

### 連接 MCP

新版書房已移除權杖和設定生成面板。已有 MCP 用戶端、按書授權與撤回介面繼續相容；接入協定與範圍見 [_briefs/mcp-contract.md](_briefs/mcp-contract.md)。網頁內的閱讀對話直接使用目前登入帳戶的單書權限，不需要另外建立 MCP 權杖。

收合權杖只清本頁顯示；撤回會立即停止後續存取，並清除對應的頁面權杖和設定預覽。已經複製的內容不會自動從其他地方清除。使用官方 MCP SDK 的 stdio 入口，連接同一個本機閱讀服務；下面為使用預設埠的手動範例：

```json
{
  "mcpServers": {
    "marginalia": {
      "command": "node",
      "args": ["/absolute/path/to/leafhour/server/mcp.mjs"],
      "env": {
        "READER_SERVICE_URL": "http://127.0.0.1:8330",
        "READER_AGENT_TOKEN": "your-scoped-token"
      }
    }
  }
}
```

工具包括 `reader_get_context`、`reader_get_chapter`、`reader_search`、`reader_get_notes`、`reader_get_reading_activity` 和 `reader_add_comment`。正文、筆記、活動與寫評論分別授權；寫入只接受明確提供的使用者原話，冪等鍵防止重複保存。Agent 讀取不增加閱讀時間。本機設定連接環回位址；雲端設定固定到發布標籤 `v0.3.0` 對應的完整提交 `fb6141fc4ceea4a15131fb7abca8a2d6579d6eb1`，透過原始碼包啟動同一 stdio 轉接器，並明確允許設定中的 HTTPS 書房。完整提交固定了實際運行的版本，也讓 npm 可以直接取得託管原始碼包。遠端存取仍按書與資料類型授權，拒絕重新導向；這不是遠端 OAuth MCP 端點。設定生成不代表已在使用者 Agent 中安裝。

## 私有託管

公開程式與私人資料分開：

```text
公開倉庫：功能分支 → PR → main → Vercel 驗證與部署
                                 │ server-side secret
                                 ▼
                         Supabase private tables
                         ├─ book + translations
                         └─ notes + reading state
```

建表遷移在 `supabase/migrations/`。新版使用獨立的 `reader_documents` 表與私人 `reader-originals` 儲存桶；RLS 開啟，`anon` 和 `authenticated` 沒有直接表權限。原有兩張單書資料表保留，不作為公開入口。Vercel Function 使用伺服器端 secret 存取。完整部署步驟見 [deploy/README.md](deploy/README.md)，自動更新流程見 [docs/ci-cd.md](docs/ci-cd.md)。

瀏覽器端不需要伺服器 key。唯一模板 [`.env.example`](.env.example) 的「託管部署」一節列出所需變數，真實值放入 Vercel Environment Variables；本機使用被 Git 忽略的 `.env`。

目前資料庫表結構、帳戶隔離、原件儲存與預設測試資料歸屬見 [資料庫與預設測試書房](docs/data-workspace.md)。
