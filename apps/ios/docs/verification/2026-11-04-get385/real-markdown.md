# 给迟疑者的页边札记

迟疑并不总等于迟钝或逃避。很多时候，它是认真辨认的一部分：当一个人没有立刻附和，而是把眼前的事多放一会儿，让经验、直觉和判断互相校对，这段停顿本身就在做工。犹豫的人往往已经看见了两种以上的可能，也隐约感到每种可能都各自带着代价，所以他没法爽快地走开。愿意思考这层代价，愿意承认自己还没想清楚，其实是一种诚实。 hurried 的人替世界省下时间，迟疑的人替自己省下后悔——两种节奏都有人需要，只是后者常被误听成不够坚决。

## 页边的位置

书页的正中央属于正文，页边则属于读者。正文说得响亮、整齐、有条理，页边写下的往往是半句、问号和"等等，这里为什么这样"。这些记号不成熟，却真实。**页边不是附庸，它是读的人在跟写的人私下交谈。**

*迟疑者的札记* 通常不完整，因为下笔时问题还没成形。它常常只有一句 `为什么急着下结论？`，或者一个画了又擦的圈。可正是这些 `未完成` 的痕迹，让一本书从纸面走进了人的生活。

### 辨认的三种姿态

辨认一件事，至少可以站着看、走近看、退后看。站着看最省力，走近看最费力，退后看得有耐心。迟疑者多半在第二种和第三种之间来回走：先凑近看清纹理，再退开看看它在整幅图里占什么位置。这个来回，就是犹豫的时间成本，也是它的产出。

#### 一个小例子

> 下午四点，他合上稿子，走去倒了一杯水。
> 回来时他没改一个字，只是把椅子挪了挪，正对着窗。

> 有人问他为什么不动笔，他说：
> > 我先看看这间屋子还缺不缺一把椅子。

##### 更细的注脚

这一小节其实只说明一件事：*停下* 有时是动作的一部分，而不是动作的中断。

###### 最小的字

最小的标题放最小的字，像页边最角落的一行铅笔字，留给以后翻书的人。

## 清单与表格

下面这些清单是虚构的，用来示范排版本身。

- 准备一支能写的笔
  - 铅笔适合随时推翻
    - 橡皮更适合迟疑的人
  - 钢笔适合定稿
- 留出一段不看手机的时间
- 把想不通的句子抄一遍

1. 先读第一遍，只标疑惑
2. 隔一天再读第二遍
   1. 把疑惑分类
   2. 删掉已经想通的
3. 写下仍然留下的问题

- [x] 抄下那天下午的四点
- [x] 挪动椅子，正对窗
- [ ] 决定要不要改变原来的写法
- [ ] 把页边的问号保留下来

| 起点 | 适合的时刻 | 读后留下什么 |
| --- | --- | --- |
| 一句读不懂的话 | 傍晚光线将要变暗、注意力剩得不多，却又不想马上起身去做别的事的时候 | 一个被反复描过的问号，以及第二天重读时忽然通了的那一下 |
| 一个反复出现的意象 | 刚读完一整章、脑子还很热，需要把散落的印象摊开来放一放的时候 | 几条互相矛盾的解释，和一条更愿意相信的 |
| 一段不敢划线的结论 | 与人争论之后，心里仍有不甘，想确认自己到底是反对对方还是在反对自己的时候 | 一次诚实的自我追问，可能推翻原有立场 |
| 页脚的一行小注 | 深夜，正文已经读不动，只想随便翻翻的时候 | 一个原本可以忽略、后来却反复想起的细节 |

## 两段代码样张

Swift：

```swift
struct MarginalNote {
    let page: Int
    let text: String

    func isUnfinished() -> Bool {
        return text.hasSuffix("?")
    }
}
```

Python：

```python
def hesitations(lines):
    notes = [line.strip() for line in lines if line.strip()]

    return [n for n in notes if n.endswith("?")]
```

长字符串样张（用于检查换行，不省略）：

```swift
let readingRoomName = "TheMarginaliaRoomOfDeliberateReadersWhoPauseBeforeTurningThePageAndSometimesTurnBackToReadTheSameLineTwice"
```

## 符号与链接

迟疑的人读得慢，页边写得零碎，可这些零碎最后会拼成一张只属于他自己的地图。正文是大家共有的路，页边是他在路上做的标记。标记不必漂亮，只要够清楚，让多年后的自己还能认出当时的迟疑有多认真。愿每一处停顿都被允许，愿每一条页边都留着笔迹。
