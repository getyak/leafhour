# Original book illustrations

These ten files are byte-for-byte copies of illustrations embedded in the specified Project Gutenberg editions. Cover art and site navigation are excluded. No redraw, recompression, cropping, resizing, or color conversion is applied.

The image-specific permission statement is **Public domain in the USA; source notices retained with the book**. Project Gutenberg metadata describes US public-domain status; it does not state a worldwide license. The software repository’s AGPL-3.0 license does not supply the illustrations’ copyright permission. Each reading edition retains its full source notices. Individual illustrators are not identified in these electronic source pages.

## Source editions

- Arthur Schopenhauer, *The World as Will and Idea*, volumes 1–3; translated by R. B. Haldane and J. Kemp: [38427](https://www.gutenberg.org/ebooks/38427), [40097](https://www.gutenberg.org/ebooks/40097), [40868](https://www.gutenberg.org/ebooks/40868).

- Charles Darwin, *The Origin of Species*, sixth edition: [2009](https://www.gutenberg.org/ebooks/2009). The illustration is the chapter-IV divergence diagram from this edition.

## Read-only verification

Pillow opened and verified every source file without writing image data. Direct viewing confirmed that `pg-2009-diagram.jpg` shows A–L species, branching dotted descendants and horizontal levels I–XIV. `pg-8438-fig01.jpg` shows Builder, Shoemaker, House and Shoes at the corners of a rectangle with crossing diagonals, matching the source discussion of proportional exchange.

The static application registry pins each path, MIME type, byte count, source page and SHA-256. Public-build verification checks every illustration that is present, including files below the normal 200 KiB threshold. The 257,348-byte Darwin file receives an exception only when both its exact registered path and original bytes match. Unknown or altered book resources fail the build check. Missing-resource requirements are enforced separately by release and HTTP verification.
