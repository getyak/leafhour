Leafhour 适合怎样的阅读？

Leafhour 是开源的 AI 辅助私人阅读书房。你可以持续阅读一本书，在原句旁留下高亮、理解与问题，需要时再请求翻译或和阅读助手对话。

可以导入哪些格式？

目前支持 PDF、EPUB、Markdown（.md）和纯文本（.txt）。PDF 提取的文字需要与原稿核对；扫描页会在你确认后自动识别。EPUB 按内置阅读顺序提取，暂不支持加密或 DRM 版本。

原文、译文和自己的笔记怎样区分？

三者分别保存和展示。AI 译文标为草稿，没有译文时保留原文。公版样书预存了开头部分的中文译文，不表示全书已经翻译。

自己的 AI Agent 可以读书房吗？

外部 Agent 通过 MCP 按书籍和数据类型授权。原文、笔记、阅读记录与评论写入分别控制。当前是技术接入，网页尚无完整的授权管理入口，详见 MCP 接入指南。站内阅读助手使用独立的只读边界，不读取私人笔记或写入阅读进度。

书籍与记录可以带走吗？

服务支持整库导出和恢复，不要求订阅。登录后在书房“设置 → 数据与迁移”下载 ZIP 备份、恢复书房或导出选定记录，原文件可自行选择是否纳入。未同步的记录与草稿仍留在原浏览器，处理方式见 隐私与数据说明。

网站支持哪些语言？

官网提供英文、简体中文、繁体中文和日语版本，默认英文。书房和阅读界面目前主要为简体中文。

使用 AI 和朋友共读有哪些限制？

直接阅读公版样书不需要调用模型。翻译与对话需要配置模型服务，自托管时由运营者承担供应商费用。赠书信可以分享所选阅读材料；在线好友的实时共读仍是后续设想。
