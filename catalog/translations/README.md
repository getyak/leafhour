# 中文开篇试读

三份文件提供限定的中文试读：Alice's Adventures in Wonderland 开篇六段，Meditations 与 Walden 开篇各四段。完整英文底本仍在上一级目录，来源与 Project Gutenberg 许可保持原样。

直译和意译由 Codex 在本次修复中分别编写，不来自既有出版译本，均保持 AI 草稿状态，未获得用户人工审定。试读译文采用 CC0-1.0；不改变英文底本许可，不表示全书已译。未调用 DeepSeek 或其他新增付费生成任务。

每段绑定英文文件 SHA-256、稳定段落 ID 和译法。底本版本不同时服务拒绝套用试读；段落缺失、双译不完整或元数据错误会使验证失败。其余段落原文保留，界面明确显示尚未翻译。

私人上传和用户自己的译文与这些公版试读分开，用户译文优先。打开试读、切换译法和中英对照无需账户，也不会请求模型。
