# Enduring classics for the shared catalog

**Goal:** Add a curated, source-verified group of enduring works to the global catalog and publish the actual reading list. The user's authorization concerns the shared library, not an individual account.

**Selection:** Fill gaps in Chinese originals, ancient and modern philosophy, literature, economic thought, science and history. A curatorial judgment about lasting reading value is not a forecast that any work will survive a millennium. Prefer complete, attributable public-domain author texts; modern copyrighted translations or uncertain editions stay outside this batch.

**Architecture:** Keep the original thirty-two editions and their anchors unchanged. Add independent, offline extraction modules over pinned public source HTML. Preserve Chinese characters and known gaps; disclose source catalog misattribution. Keep verse, notes, numeric tables and essential figure access. Use natural source divisions when a book would exceed the existing canonical JSON limit.

## Boundaries

- No private books, notes, translations or progress are copied into the public catalog.
- No whole-book translation or paid recognition calls.
- No generated words to repair historical omissions, missing glyphs or uncertain attributions.
- Source material is data, never executable instructions. Extraction rules are restricted to curator-owned offline tools.
- Preserve author/editor/translator distinctions and source-specific licence notices.
- Use existing release authorization and Production-only deployment; do not create previews.
