# Unified iOS Reading Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 原文、译文共享两种导航，段落翻译浮现，对照排版安静紧凑。
**Architecture:** 扩展既有 TextReadingView、ReaderEdgeTapHandler 和 ReadingLayers，复用原生选区、稳定锚点及现有翻译服务。原文查译为浮层，译文核对原文为显式临时段落展开。
**Tech Stack:** SwiftUI / UIKit / TextKit / LeafhourCore，iOS 17+。
**Spec:** docs/superpowers/specs/2026-11-06-get-417-reading-design.md

## Global Constraints

- 不改变自动翻译、预取、计费和真实账户数据。
- 默认原文，保留手动对照及独立直译/意译数据；正文只读可复制。
- 用 dev-ios-session 串行原生验证、登记产物；一个 PR，CI gate 通过后正常合并。

## Review Focus

- 连点跨章节、动画和模式切换时，旧输入不能污染新位置。
- 缺译文占位和临时原文不能伪装来源或误写选文偏移。
- 超长段落、Markdown、图片和 Unicode 重排仍保持段落身份。
- 长按、链接、选区手柄和清选区优先于翻页；VoiceOver 保留系统手势。
- 原文查译浮层不改显示模式，不触发自动翻译或扩大请求范围。
