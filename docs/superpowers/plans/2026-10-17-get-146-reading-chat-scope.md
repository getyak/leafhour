## 现状与目标

已有正式阅读 Agent、实例端 DeepSeek/官方 DSH 适配、当前章/段定位、分页工具、实际读取引用账本与结束前版本核验、六轮/24KiB历史、幂等问题、持久化/跨进程取消/超时、用户与AI分离、独立对话JSON导出和真实浏览器验收。2026-10-16 用户另已授权站内 Agent 按需读取当前账号书房、公版与网络，不读取私人笔记，不改变外部 MCP grants；保留此功能，不重做 Agent/模型或退回旧回声格式。

本机真实领域复现 `issues/GET-146/current-behavior.json`：未选择范围时，`reader_search` 无 bookIds 会列出并搜索同账号所有可读书，回答可登记另一私人书的真实引用；没有可持久配置范围的操作或响应。注释未发送，属于同账号默认范围缺口，不误报跨账号越权。复现仅两本合成书与确定性 adapter，真实模型调用 0。

目标：发送前可见本次允许读取与发送的文字；默认仅当前书按章分页，不隐式搜索整个书房。现有广范围阅读 Agent 作为明确选择保留，并在后续提问与刷新后继续执行该选择。问题、旧回答和引用保留，缩小范围不能从历史对话暗带回其他书的文字。

## 方案与取舍

比较：仅增加说明无法约束真实工具；另建模型/授权平台和新数据库会重复已有架构；在现有账号/书的 chat 文件增加版本化范围设置，并在每轮冻结与执行工具边界，可以满足需求且保留既有运行和恢复机制。采用第三种。

1. 仅两档：`book`（仅当前书，默认）与 `library`（当前账号书房、公版及网络）。本书范围仍可按需读取本书其他章节，保留用户已授权的跨段/章节追问；返回与引用都受现有单页/总预算约束，不把整书作为初始上下文。两档均不自动读取私人评论、账号凭据或写入进度。明确问题中由用户主动写入的文字会发送。
2. 范围保存在现有 owner/book chat 文档的兼容可选设置中，缺字段为 `book/revision0`。共享小模块定义枚举与严格校验，`view` 返回设置及发送说明。增加已登录 `POST /api/library/books/:id/chat/scope`，只接受 mode/baseRevision；同值不增版，修改用现有 CAS/文件锁原子递增。陈旧设置请求返回412，不覆盖另一处选择；运行中先停止再修改，服务端也拒绝并发改变范围，不能只靠禁用按钮。
3. 新提问携带 scopeRevision，服务端在与领取同一原子操作中核对并冻结真实 scope/revision。陈旧或缺失的新权限版本412，必须在生成、额度预留与写入问题前拒绝；默认book/revision0兼容旧客户端缺字段。已有相同ID请求优先按原冻结数据恢复，不能把丢应答重试升级到新范围；同ID不同原话/锚点/版本/范围版本409。无效设置失败保留数据，不扩大范围。
4. 工具工厂默认book；list/search只取得当前书，显式其他书ID/目录/分页/引用均在读取前拒绝，广范围工具不登记为可调用。显式library保留原有按当前用户捕获的能力；模型不能切换身份或更改范围。分页、来源可见范围账本、结束前版本/取消核验与错误不登记来源保持有效。测试原有广范围能力时明确选择library，不把新默认约束当功能删除。
5. 新turn内部保存冻结模式与版本，公开回执提供范围版本供客户端恢复匹配；不导出当前权限设置、凭据或可用授权。仅book的模型历史使用同版本、同范围的已完成本书对话（及已知仅本书的陪读），legacy/广范围回答继续显示和导出但不自动进入缩小后的模型上下文；library维持当前书最近六轮、按完整轮裁到24KiB。界面说明会发送问题、书名/当前章段位置、允许范围的最近对话及按需读取的原文/译文与检索词，不宣称只发送页面当前可见字。
6. UI在发送附近展示当前范围与云模型文字说明，提供有标签的范围选择并等待服务端确认。保存范围不调用模型；范围失败/陈旧/跨账号响应不改草稿或冒充已保存。pending/未确认提问时禁用范围切换，异步票据继续按账号/书隔离。冻结pending在本机保存scopeRevision，刷新重试沿用原版本；412读取当前设置后保留问题，用户核对后再点击发送，不自动重发到更广范围。旧pending无字段按旧版本恢复。
7. 保留现在的引用展示/原文跳转、用户与AI标签、停止/收起/恢复、文本/Markdown安全、对话JSON导出。整书房备份如何包含全部对话另归 GET-148；本任务不把 UI 对话导出谎称成完整书房恢复。无需迁移现有问答、修改外部 MCP 权限、模型Key/供应商/预算、自动陪读触发或重新翻译。
