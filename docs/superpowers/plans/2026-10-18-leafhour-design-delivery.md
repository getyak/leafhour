P0/P1 回归优先于排期；发现会影响当前交付时先修复。共享模块的子任务可在同一完整 PR 内交付，但各 issue 分别记录验收，Epic 只在全部子项和必要跨页面检查通过后完成。

每批从最新公开 main 建立隔离分支，由本机 Pi + MiMo Pro 承担明确编码边界；父任务负责设计、集成与实际浏览器验收。独立 sub-agent review 复核 P0/P1，修复后跑当前提交适用 CI/CD，正常合并，读回真实生产来源和 Linear 状态。未实现、未运行的平台和未收到的本人反馈均不能写成通过。

原阅读内容任务仍按用户决定处理：GET-150 小样与 GET-153 真实试读待本人填写；GET-151 只核对现有草稿，不新增付费翻译、不自动写回建议。GET-155 的真实宿主安装与首个定时回执各自留证，不因设计任务覆盖它们。
