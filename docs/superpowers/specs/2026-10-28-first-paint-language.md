# Selected language from first paint

User authorizes implementation, checks, PR/merge and production release without another confirmation.

The defect: library/read HTML is fixed English; the singleton starts English and applies query/device/account language after first paint. Static production routes prevent a server-only renderer change from fixing hosted pages. Native blocking=render was experimentally insufficient across top-level await.

Use localized initial HTML for library/read via a lean hosted HTML entry (no reader/model runtime initialization). Selection: one validated ui query, verified account UI preference, a validated nonsecret device hint, browser language. Authored public home/support paths retain pathname authority. Preserve the current URL, business query values, stable reading state and four-language catalogue boundaries. No preference/model writes on HTML reads. Response private,no-store and Vary Cookie,Accept-Language,Sec-Fetch-Site; do not use locale hints for authorization.

Shared hint cookie name leafhour.ui.hint.v1, value `1.<preference-or-dash>.<browserLocale>`, where preference is system/en/zh-Hans/zh-Hant/ja or dash (none); browserLocale is an exact supported code. It mirrors local device preference plus resolved browser language, never an account ID or token.

Initial HTML data attributes: data-ui-initial-locale, data-ui-initial-source (page/account/device/browser), data-ui-initial-preference (system/exact code or empty), data-ui-initial-owner (verified owner ID only for account selection, optional), and data-ui-device-hint. Attribute values escaped. Static inline classic bootstrap is identical across languages; it synchronizes old localStorage choices into the hint before body parsing and performs a distinct-document same-origin handoff if the server's fallback differs. Closed aliases /_ui/home, /_ui/library and /_ui/read guarantee an HTTP document request even when a reading fragment is present; the selected document restores its canonical URL with history.replaceState before UI owners start. Cross-site canonical requests without a usable Strict session cookie or valid ui value receive a language-neutral handoff document, so the same-origin alias can recover the account preference without weakening Auth cookies. Internal-* rewrite roles distinguish framework-normalized aliases and prevent repeated handoffs. During that navigation the abandoned document is not painted; failed handoff gets a selected-language native retry, not an indefinitely hidden page. No writes to account or device preference itself. Strict codec and loop bounds.

The singleton accepts validated server account/device seeds, loads the selected full catalogue before owner modules construct UI, and never reinitializes English over localized HTML. Account seeding is fenced on verified owner adoption/change. Manual selections mirror the device hint only after existing persistence semantics; initial/re-entry does not create a manual choice. Catalogue failures retain localized initial shell with a visible native retry rather than silently painting English.

Hosted read template uses the generated compiled private .ui-entry/read.html, preserving script/CSS budgets; hosted library uses authored app/home.html through homeDocument locale mapping. Canonical root/library/read public HTML files are omitted so Vercel filesystem routing cannot shadow the function rewrites. Include needed templates explicitly in the function package. Selfhost shares selector and renderer. CSP hashes the fixed bootstrap bytes, never enables unsafe-inline scripts. The boot helper is not another mutable language runtime.

Tests: actual HTML in all four locales and no-JS response, strict duplicate/invalid query, cookie/browser and account priority, bad/stale owner, legacy local/session choice, blocked storage/cookies, refresh/reentry, slow/failed catalogue, source prose safety, CSP and function packaging, current full CI/build. Real browser paint probes must catch English flashes under delayed catalogue/account responses, including production.
