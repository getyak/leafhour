# GET-375：阅读旁注与消息引用

以本次用户说明和 GET-375 为设计依据，直接完成实现、验证、审阅与默认 PR 交付。沿用原生 SwiftUI、TextKit/PDFKit 和当前账号书房服务。

书内对话改为半屏旁注，保留上方正文，可上拉展开和关闭回原位置。账号级 Chat 保留独立入口。用户问题去掉整块灰底；原文摘录以细引线标注，正文与 AI 回答继续分开。无摘录时不显示绑定状态。阅读回答时输入收为可点击的“继续问”，草稿、录音、失败恢复或键盘输入时保持完整输入。停止生成始终可用。

长按用户消息、已完成 AI 回复提供引用、复制、点赞/取消点赞；引用保存消息 ID、角色与当时正文，输入区可移除。服务端从当前账号、当前会话解析原消息，客户端内容不能充当来源。重试保持已提交请求不变。点赞先保存到该账号/书的本机对话记录，不伪称云端反馈。

新生成的回答首句直答，后续用短段按需解释，不重复已展示的完整引文，不默认编号、加粗或模板总结；不裁剪既有答案，也不增加聊天字数上限。

返回书房先定位实际阻塞，持久保存与失败恢复必须保留。阅读进度以章节内位置估算全书百分比，PDF 使用实际页序，明确无可靠位置时只显示章节；不把屏数当书页。右下角短暂悬浮显示，不放进左侧功能栏；保留用户常显设置。选择文字与打开旁注时隐藏，避免遮住选区。

取舍：半屏旁注优于继续推入独立 Chat 页面，阅读关系更清楚；相比固定的小浮窗，系统半屏支持键盘、大字和展开。进度选右下角，比顶部书名旁更接近翻页反馈，也比底部中央更少和系统手势争位。

验收：真实原生构建；隔离合成书的旁注、引用、输入收起与恢复、关闭位置保留；账号/书隔离和幂等测试；大书返回的保存链回归。模拟器不等同真机《剑来》验收，合并、线上发布、TestFlight 和真机分别记录。
