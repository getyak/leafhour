# Approved listening player, page translation and lock-screen playback

The user approved the 对照底页 design after comparing interactive previews, requested removal of every 回到朗读 entry, a common reading/listening controller with chapter/page navigation and configurable page translation, and a lock-screen cover. They explicitly chose continued locked/background playback with lock-screen controls and complete-paragraph translation for paragraphs intersecting a partial page.

## Product behavior

Restore the pre-301 full-screen player structure: compact book identity, continuous native selectable original/spoken text, a separate current-paragraph comparison region, independent centered transport, and the existing ReaderBottomBar shared with reading. Controls never overlay source or comparison. Portrait/landscape/narrow/large-type layouts must fit. Maintain one current-sentence emphasis and a quiet word accent; retain real UTF-16/source mappings. Use the reading paper/font/size/spacing. No repeated large book icon or article-sized title. Hiding controls preserves access through a 44-point reveal target. No return-to-narration button, link, overlay or settings action; scrolling/selection can suspend follow, and explicit play/pause or sentence seeking can resume it without a separate return affordance.

The awake reading controller contains previous/next chapter, previous/next page and an explicit translate-this-page action. Capture the visible source paragraphs from actual TextKit/PDFKit geometry. Translate only those complete paragraph IDs, in document order, under the current source version, account and language pair; never infer a viewport from chapter order or translate the whole chapter. A page may intersect only part of a paragraph: complete that full paragraph, as explicitly chosen by the user. Exclude headings/images/empty text; preserve existing complete dual translations and stop rather than overwrite partial/mismatched versions. The existing explicit translation confirmation remains, stating actual paragraph count/cost and full-paragraph boundary. Ordinary page turns/settings do not generate translations. Results display through the configured original/translation/parallel mode and literal/interpretive variant. Unknown geometry is unavailable, never a guess. A page snapshot must match session, navigation, source/layout and active language pair when submitted; rotation/font changes invalidate it. A resumed uncertain generation keeps its original immutable scope.

Locking/backgrounding keeps explicitly started local audio playing. Reading time and translation generation still pause in background. Incoming audio interruptions, route loss, explicit stop, book/account changes and microphone activity retain their existing protections. Lock-screen metadata uses real book/chapter identity and no selected text/private notes. Prefer the current book's actual cover, aspect-fitted; missing artwork uses a restrained title/author cover derived from real metadata and the reading theme. The cover and async image completion are bound to the current book/source/account. Native remote play/pause/previous/next commands target only the active session. Do not invent a whole-book duration, progress, waveform, art or track timing. Clear metadata on stop/account/book teardown without clearing a newer owner's session. Temporary rate boost restores on interruption/background/release and is not persisted.

## Architecture and boundaries

Reuse ReaderSession, ReaderSpeech, ReaderSpeechAudioPlayer, BookCoverResource, ReaderBottomBar and ReaderReadingContent. Add a validated visible-page snapshot and page scope to the existing full-paragraph translation plan. Add a small MediaPlayer adapter and separate cover renderer/loader; keep source/service permissions unchanged. No new model provider, paid calls for acceptance, private data fixtures or preview deployment. Synthetic local tests and simulator evidence do not establish physical lock-screen/audio quality. Normal source PR/merge and existing production/TestFlight automation remain authorized.
