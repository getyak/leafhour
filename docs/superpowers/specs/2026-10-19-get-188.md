# GET-188 首页移动导航

状态：设计已独立复核；尚未实现或验收。当前基线 `9cac0f0`。
开始实现前先整合 GET-173 的已交付版本，复用其 Popover 能力边界。

## 体验与视觉

900×844 的真实 Chrome 页面中，现有导航高90px、顶部y=-5，出现换行；
1101×844 时导航高44px、顶部y=18，能排在一行。因此 ≤1100px 使用菜单，
≥1101px 保留桌面导航。390px 与900px都要验收，不能只测手机最窄宽度。

紧凑页头保留品牌、现有外观按钮、一个44px安静的 pill 菜单按钮。
登录入口进入全高的原生 dialog sheet；纸面与夜色继续使用现有 token、
serif 标题、hairline、focus ring 和 reduced-motion。菜单行至少48px。
入口、分组、留白服务于找到书和返回阅读，不另加设置面板或 onboarding。

复用现有书房、如何阅读、自有书房的实际本地化锚点，最多两步到达；
语言仍是真实链接。菜单只挂载在 `/`、`/en`、`/zh-hans`、`/zh-hant`、`/ja`。
原导航隐藏规则不能让菜单里的链接一起隐藏。修改键点击保持原生行为。

## 控制器与焦点

一个 `home-navigation.mjs/css` 由 portal 挂载，原生 dialog 拥有开关、
Escape、关闭按钮和滚动边界。开着其他 modal 或外观 popover 时拒绝打开。
通过 interaction-craft 的显式逐 dialog 焦点所有权接口排除通用 close RAF；
其他 dialog 继续使用原行为，不做全局 DOM 或原型补丁。

关闭原因区分 user、navigation、auth-handoff、palette-handoff、breakpoint。
只有用户关闭返回初始 opener；跨到桌面时关闭菜单并使用可见品牌回退。
同页锚点允许浏览器正常滚动，再用一个受保护的 RAF 聚焦真实目标，保留
原有 tabindex；新 modal 已打开或请求失效时，不再抢焦点。不延迟导航。

登录前先关闭菜单、聚焦仍可见的菜单按钮，再立即打开既有 auth dialog，
确保 auth 最后能返回有效目标。登录后的账号入口使用受验证的
`/library?settings=account`。不得恢复到已关闭 sheet 的子控件。

palette 复用已有 bootstrap 单实例：portal 注入 `openPalette(opener)`，
关闭菜单并聚焦可见按钮后，发出 `palette:open` CustomEvent，detail 为
真实 opener。bootstrap 接到请求后走已有的 gesture/open 路径；不重复
mount、不克隆未布线的 launcher、不增加隐藏按钮或全局可变函数。

异步 import 完成、实际显示之前，统一重查请求/owner代次、其他 modal、
已打开的 popover，以及 opener 的连接、可见、非 inert 状态。等待期间
若 auth 已打开则取消本次请求；若跨到1101px令 opener 隐藏，使用可见
品牌或既有安全页级目标作为最终返回点。失败保留已有 notice/retry，
消费 rejection，不让第二个定时器或 close handler 覆盖焦点决定。

## 真实续读与数据边界

可选续读行只来自当前账号实际已授权且有阅读进度的书。复用
`chooseCurrentBook`，链接使用 `readingBookUrl(book, null)` 的 book-only
协议；由 GET-186 阅读器独自验证和恢复段落、版本与显示状态。
新访客没有进度时显示开始阅读/试读，不能把 Alice 冒充当前在读书。

在 `clearPrivateUI` 开始时同步 `homeMenu.clear(ownerScope.capture())`。
更新仅发生在当前 refresh generation 校验、books赋值、访客本地续读
校验完成之后；用固定 session/books/owner getter 与 owner revision
拒收旧结果。同 owner 重试也先清除旧续读行。不能额外取私有目录、
持久化私有书名/URL，或改写阅读记录。书名和作者直接 textContent，
不经 homeText；静态控件文案拥有明确四语言词条，供 GET-192 接续。
