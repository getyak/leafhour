# Quiet reading controls

The supplied WeRead screenshots demonstrate spatial controls: short labels, icon grids, direct typography adjustment and visible paper choices. Leafhour will adopt those interaction principles while keeping its own restrained green palette and native navigation.

Scope: native iPhone reading page, reading tools, typography/paper/reading preferences and the shared global Reading Style screen. The web reader keeps the same categories, named paper tiles and real WenKai preview, with existing saved IDs retained. Native Latin family choice remains specific to iOS. Account/data, book records, existing navigation, original PDF typography and explicit generation boundaries remain intact.

Use a compact common control surface, rather than making every choice a form row. Keep short visible names for discovery; VoiceOver receives full labels and selected states. Frequent tools become a three-column grid, reduced at accessibility sizes. Secondary export and web capabilities remain explicit destinations. Settings retain text/paper/reading categories with an actual preview, direct size/spacing sliders, Chinese font samples and a separate Latin family chooser. Add local Kai style and six Latin alternatives, eight paper colors plus system. Native font choices resolve locally with an explicit Chinese cascade and honest system fallback. Native Dynamic Type remains supported.

Alternatives considered: merely shortening existing form labels would leave the long navigation problem; copying WeRead's exact layout would obscure Leafhour's independent translation and provenance features. Shared compact controls best meet the request and avoid divergent global/per-book settings.

Verification: legacy settings decode, new settings persist across books without moving notes/anchors, real Core Text Latin/CJK glyph fonts, preview/page parity, paper/night contrast, tools destinations and return, cold restart, narrow and accessibility layouts. Simulator acceptance is distinct from physical-device and TestFlight release.
