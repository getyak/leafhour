# GET-385 · 陪读留在页边

本单按用户已明确的半屏旁注方向实现。对照 Linear 的松鼠、豆包截图：去掉气泡并不足够；整屏目的地、能力自述和答题模板仍会让阅读中断。

采用现有会话与领域服务，改变呈现和召唤入口。Web 从底部打开约半屏的纸面旁注，保留上方正文；窄屏键盘可见时按可视高度留出输入空间。iOS 复用已有半屏和键盘几何，正文与提问均去掉消息气泡；书房召唤旁注，底栏只保留书房和我的阅读。账号会话与选书入口仍可从旁注访问，草稿按既有账号、书及版本保存。

不采用整屏 Chat 再缩字号，也不另建旁注会话或转换历史内容。沿用现有直接回答提示，补充无书上下文的正向表述，明确不主动输出权限说明、不使用编号答题模板或 emoji tip。用户明确要求步骤、列表或询问能力时仍如实回答；不删除引文、代码或必要限定。
