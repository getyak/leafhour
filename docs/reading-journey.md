# 循页的阅读与数据保留

循页围绕“今天继续读，明天还愿意回来”组织书房。选择一本书，回到上次的原文位置；读后可以写一句自己的理解或留一个问题。阅读日历把真实保存的时段、笔记和明确确认的读完标记放回日期中，可以再次打开原页。

## 时间怎样记录

计时需要主动点击“开始阅读”。页面可见且处于前台时累计，切到后台、手动暂停或结束后停止。超过五秒没有前台运行信号的间隔按挂起处理；长时间阻塞也可能保守地少计。一天内重叠的区间合并，不会因为开两个阅读页就得到两倍时长。跨午夜按查看日历时的所在地时区拆分。阅读时间表示停留，不能证明理解。

翻到下一章、滚到末尾、Agent 读取正文都不会标记读完。章节与整本读完由读者确认，可以重新打开阅读。早期设计预览中的计时记录仍可迁移，日历不会把它当成真实阅读时间。

日历的逐书摘要保留当天的原文位置。单日详情只展示最近20条，较早的书仍能回到当天读过的位置；完整记录保留在备份中。

## 自己的理解与草稿

结束计时后可以写理解和问题，两者分别保存到当时的原文位置；也可以直接关掉，下一次继续读。深读提示只提供提问、用自己的话复述、核对原文和回顾问题的可选步骤。打开提示不会请求模型，也不会替读者生成“自己的理解”。

阅读栏的“草稿”可以找回以前停下位置的未完成文字。每个阅读页保留独立内容；同一段的两份想法会分别出现。接着编辑另一页的草稿时，先保留新副本，再隐藏旧版本；原来的页面继续输入时，它的新版本仍能出现。

保存失败会保留原提交标识，重试先确认那一次提交。保存期间继续写下的文字不会被旧确认清空。账号与书籍分别隔离；退出不会把旧账户的待同步内容交给另一个账户。

段落旁注面板与读后记录共用这个入口；旧版本段落草稿保留原缓存，并可从统一列表找回、导出。

## 备份与恢复

“导出书房”合并服务端记录与同一浏览器、同一账户的待同步阅读时段和章节标记。尚未提交的读后草稿写在每本书的 `localReadingDrafts` 中，和已保存评论、问题分开。草稿恢复后仍只留在当前浏览器，主动保存才会进入书房笔记。普通个人记录的格式仍兼容旧备份；阅读时段、标记与目标使用记录版本3。机器名称与存储命名空间保留 `marginalia`，改名不会另建账户。

网页按书分段读取并校验备份，在浏览器合成一个文件，避免几本较大的书超过托管平台的单次响应上限。传输中记录发生变化，会重新准备这一本；连续变化时提示结束阅读后重试。校验失败不会下载半份备份。单份备份沿用最多100本的格式边界，导出仍受浏览器内存限制。

恢复前验证书籍、原文锚点、记录和读后草稿。网络中断可能留下已经恢复的书，可重复恢复合并。已有较新的最终时段不会被旧检查点覆盖。旧版本备份不会清空当前的阅读目标或新标记。独立使用服务端恢复接口的工具只恢复已提交记录；本机草稿扩展由网页恢复。

仍在进行的阅读只导出最近保存的时段。结束计时后再备份，可保留这次完整记录。当前托管实例有文档与请求大小上限，特别大的单本备份可能需要本机恢复；本版不承诺无限云端历史。备份不含原始PDF、服务端密钥或Agent令牌；原文件另行下载。

托管书籍的容量会计入已保存的译文，个人记录也在写入前检查。新增内容若会超过容量，服务会拒绝这次写入并保留原有资料。新译文尚未保存时会明确说明；可以先导出备份，在本机恢复后继续。

## 验证范围

自动测试覆盖前台区间、乱序确认、跨午夜与夏令时、并行草稿与章节标记、账号隔离、旧备份兼容和新实例恢复。实际页面另外验证了断网重试、两页同时编辑、旧草稿找回、导出文件与干净服务恢复，以及390像素布局、夜间主题和原文选择复制。另有实际按钮导出的六本书、约7.7MB备份，在干净实例恢复了相同原文、日历与五份合成草稿。合成验收记录只用于本机测试，不代表真实用户阅读或学习效果；模拟尺寸不代替实体手机验证。
