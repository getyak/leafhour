# GET-153 · 真实试读记录方法

本文件是待执行的方法与空白记录，不是访谈结果。2026-10-18 尚无新增参与者、数日留存、理解改善或付款证据。用户可本人试读；联系其他参与者需要另行明确授权。真实原话、阅读记录和书籍属于运行数据，不提交公开仓库。

## 一次试读

1. 开始前记录日期、匿名参与者编号、书籍与原文版本、阅读目标（深读/语言学习）、当前替代工具与实际费用/耗时。记录同意范围，不收集不必要的身份信息。不要预设读者会付费。
2. 在本人选择的短段阅读，观察何时核对原文、换直译/意译、展开注解及返回正文。保存稳定段落ID和具体阻碍；请本人指出屏幕上的作者原文、所选直译/意译、编辑注解与AI回答各是什么，记录正确辨认或混淆的具体位置。区分观察事实、本人原话、AI建议和研究者解释。计时只报告投入，不能代替理解。
3. 请本人用自己的话解释同一命题、指出一个限定并给出新例子；再核对来源，允许纠错。先记录原话，再单列AI的候选解释与研究者判断；AI复述不记为用户掌握。语言学习另观察未知词、指代或否定的判断，不能从中文深读结论外推日韩市场。
4. 保存一个真实未解决问题与位置。至少中断两天后实际返回，记录能否找到同段、同问题、耗时与恢复失败；未等到返回时，结果写“尚未观察”，不能用改系统时间或自动浏览器代替。
5. 本人导出选定书籍与个人记录，在干净实例恢复后实际找到同段、评论和问题，核对译文版本与来源；再询问愿意为何付费、替代成本和不愿付费原因。意向、报价接受与实际付款分别记录；本研究不自行发起扣款。

## 最小记录字段

| 类别 | 记录内容 | 判断边界 |
| --- | --- | --- |
| 会话 | 匿名参与者编号、真实时间、同意范围、任务与环境 | 同一人多次会话不算多个用户 |
| 来源 | bookId、contentVersion、chapterId、passageId、所选译法及来源状态 | 缺页码/未校对原文明确保留未知 |
| 观察 | 具体动作、成功/失败、返回锚点、页面错误、本人请求的帮助 | 自动验收与人工试读分开 |
| 理解 | 本人原话、纠错前后、新例子、来源依据、观察者判断 | 不以时长、AI复述或模型分数宣称掌握 |
| 价值 | 现用替代方案及实际成本、付费理由/拒绝理由、意向或付款凭据类型 | 未付款不计付费用户；无凭据不推断金额 |
| 后续 | 同一匿名参与者的真实延迟返回与迁移核对 | 一次任务成功不等于长期留存或市场规模 |
