# 阅读目标与语言

在书页打开“阅读工具” → “阅读设置”，可以分别选择阅读目标、深读优先语言、阅读方式与中文译法。

- **未设置 · 原文开场**：保留原来的习惯，每次打开先看原文。
- **深入理解**：切换到你选择的原文或中文；没有对应译文时仍可读原文，并显示缺译提示。
- **语言学习**：先看原文，按需核对已有译文。

原文、中文译文和对照仍可单独切换；直译、意译各自使用自己的已存版本。更换目标不会改写原文或生成译文，缺少直译时也不会借意译填充。中文原文书没有另一语言译文时，继续显示中文原文。

显式设置目标后，重新打开会恢复最后主动选择的阅读方式与译法；没有设置目标的旧记录继续原文优先。切换前后的书、章、段落位置保持对应。恢复阅读外观只重置排版与纸面，保留目标和优先语言。

每本书保留自己的选择。登录后，偏好随阅读位置保存并进入现有阅读备份；访客只保留在当前浏览器。离开前确认阅读位置已保存；浏览器不能持久保存或服务暂时无法同步时，按书页提示重试或另存待同步记录。显示译文和重新打开书页不代表译文已被人工校对，也不能证明已经理解。
