# 密码优先登录验收

日期：2026-10-15。用户批准默认邮箱与密码登录，验证码作为备用入口，并简化登录页面。

默认页面使用纸白、深绿与赭色书签，标题采用宋体。邮箱与密码在同一表单中，支持自动填充、显示密码及回车提交。切换验证码时保留邮箱并清除密码。创建书房与找回密码分别验证邮箱，确认后设置至少八个字符的新密码。仅配置 SMTP 的本机实例继续使用原有登录方式。

## 权限与并发回归

普通登录会话不能设置密码。设置密码还需本次邮箱验证生成的独立凭据，服务端仅存凭据哈希；旧表单不能对替换后的账号会话改密。凭据十分钟内有效，在派发更新前即消费。并发、延迟返回或响应丢失不能触发第二次改密；只有供应商明确拒绝相同或不安全密码时允许在原期限内重试。

邮箱验证尚未完成返回时，窗口焦点检查延后，避免 Cookie 已更新但表单回执未到时重置页面。密码、验证码及供应商令牌不写入浏览器持久存储。实际账号的密码从本机钥匙串在运行时读取，没有写入验证文件或命令参数。

合并、部署与正式域名的最终验收分别核对远程 PR、`release.json` 源提交、Production 工作流与线上真实账号流程，不以本机检查代替线上完成。
