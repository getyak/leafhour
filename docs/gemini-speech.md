# Official Gemini speech · 2026-10-17

Speech now goes directly to `https://generativelanguage.googleapis.com/v1beta/interactions`, authenticated by the server-only `GEMINI_API_KEY` header. Obtain the key from [Google AI Studio](https://aistudio.google.com/api-keys), then set it in the same local `.env`. An OpenRouter key is a different credential and is never forwarded or used as a fallback. Text translation and dialogue scripts continue to use DeepSeek.

The default official model ID is `gemini-3.8-flash-tts`. Existing `READER_SPEECH_MODEL` overrides retain their name; a legacy `google/` routing prefix is removed before sending the official model ID. The request preserves text verbatim, places optional delivery directions in `speech_metadata`, requests mono 24 kHz 16-bit WAV, limits output to 2,000 tokens, and sets `store=false`. This opts out of retrievable Interaction storage; it does not make a separate promise about Google's account tier or data-use terms. See Google's [speech schema and formats](https://ai.google.dev/gemini-api/docs/speech-generation), [Interactions API reference](https://ai.google.dev/api/interactions-api), and [storage controls](https://ai.google.dev/gemini-api/docs/interactions-overview#data-storage-and-retention).

The adapter checks bounded JSON/base64, completed status and the WAV container before saving audio. It rejects malformed or partial output, limits decoded clips to 4 MB, honors cancellation and never automatically retries a paid request. Key/permission and quota failures use fixed actionable messages without exposing provider bodies.

New sessions use chunking version 2: at most 200 UTF-16 code units per clip, preserving Unicode boundaries, exact source offsets, punctuation, English word boundaries and speaker attribution. Normal trailing whitespace stays with a spoken word; impossible blank-only chunks are rejected during preparation before any provider request. Reading, dialogue and AI-answer audio use this same policy. Unversioned sessions retain the original chunking so existing MP3 clips, cache keys and listening positions remain valid. Backups preserve the version and accept up to 512 clips within the existing 32 MB package cap; larger audio can still be downloaded separately.

Price previews now reference [Google's published Gemini API rates](https://ai.google.dev/gemini-api/docs/pricing), checked on 2026-10-17. The default model's standard paid reference is $0.50 per million text input tokens and $9 per million audio output tokens through 2026-12-31, using 25 audio tokens per second. Unknown models and expired references have no dollar estimate. Duration and text-token estimates remain approximate, and a configured key does not verify quota or billing.

Hosted speech still requires a persistent private queue and audio storage. This migration does not enable that backend; hosted capability metadata continues to report speech unavailable.
