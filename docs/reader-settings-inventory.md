# 阅读设置的逐项盘点与重组

2026-10-15。依据当前网页控件、偏好模型及其真实保存路径盘点。用户要求切换网页时声音继续，以及按阅读场景重新管理配置。

共有 36 项可配置偏好：阅读 18 项、氛围 4 项、听读 5 项、摘录图片 9 项。双人讲解另有 1 项当次任务范围选择。重复入口不重复计数；播放、备份、目录等动作单独列出。

## 判断与新入口

最常做的决定是读什么、字是否舒服、纸面是否舒服，放在「阅读」首页。对照布局只在对照模式出现，中文译法在译文或对照模式出现。高级外观保留原值，收起不代表清除。

声音、习惯、数据分别有独立入口。氛围场景的完整挑选仍保留专门的预览面板；设置内直接提供场景状态、播放暂停和两路音量。正文听读另行选择声音与语速，不和背景音乐混在一起。图片导出配置继续只在摘录预览时出现。

沿用书页的纸白、深灰和墨绿（`#faf9f5`、`#292a25`、`#716f65`、`#3f594c`、`#dfdfd5`），正文继续使用本机宋体／Georgia，控件使用系统无衬线。以固定的四个设置页签代替纵向长列表；常用项直接呈现，细节通过明确标题的折叠区展开。

## 氛围：4 项

| 场景：无／林间／雨窗／炉火／海边 | 一次选择匹配的画面与声音 | 声音 → 阅读氛围，可打开完整场景预览 | 本机浏览器 |

切换标签页或应用不再暂停声音，视觉动效仍可暂停。手动暂停保持有效，返回页面不会擅自重播；关闭或刷新当前书页会结束该页面的声音。后台播放不计入阅读时长。没有新增一个默认不明确的「后台播放」开关。

## 1 项任务配置与动作归类

双人讲解的范围（全章／某小节）只在准备讲稿时选择，属于当次任务。每日阅读目标在书房管理，阅读器只展示，不制造第二个设置入口。

以下是动作而非偏好：

| 原有入口 | 处理 |
| --- | --- |
| 全书目录 | 保留设置页底部的便捷导航，顶栏也可直达 |
| 我的记录 | 数据页首项 |
| 导出阅读记录与设置／导入记录 | 数据 → 阅读备份 |
| 已保存的听读／导出听读／恢复听读 | 数据 → 听读备份，从声音选择面板移出 |
| 导出阅读体验／导入阅读体验 | 数据 → 阅读体验备份，保留原有独立记录包 |
| 恢复默认排版与纸面 | 改称恢复阅读外观，明确仅重置阅读外观，不动内容和声音 |
| 关于这份译文 | 阅读页的译文说明；原文模式收起 |
| 氛围播放／暂停、只留纸面 | 声音页与场景预览共享同一播放状态，不保存自动播放意图 |
| 朗读播放、前后段、进度、返回原文、下载本段 | 留在播放器，属于当前播放任务 |

| 听读试听 | 留在声音选择场景，手动触发，保留费用说明 |
| 全屏、返回书房、章节导航 | 继续是阅读工具，不当作可持久化偏好 |
| 体验验证 | 从用户设置移除；开发入口 `/evals` 保留 |
| 材料来源与偏好保存范围说明 | 留在对应声音／译文说明中 |

## 验收重点

原文模式没有任何译文或对照配置；译文模式只有译法；对照模式才出现排列、风格、预览、译文配色。切换模式后隐藏选项仍保持原值。四个页签支持键盘，手机不横向溢出。声音切换到后台仍运行，手动暂停与实际离开页面正确区分。最终结果另见本轮真实验收记录。
