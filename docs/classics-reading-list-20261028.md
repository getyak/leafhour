# 本批新增经典书单

这一批选择二十四部新作品，另为已有《道德经》补充中文原典。长著按来源中的卷次或明确的阅读范围分册，共增加三十二册／版本，共享目录合计六十四册／版本。

我更看重作者怎样提出问题、组织论证和讲故事。观点有争议，也可以通过不同作品之间的对读继续检验；这份书单不按一套现成结论排列。下面的理由是选书判断，作品本身的作者、译者和范围以每本来源详情为准。

《道德经》的中文原典也已列入本批目录，与已有 Legge 英译版分别保存。上表的书名链接只筛选共享书库；长著会同时显示本批的全部分册。

中文原典共八册，保留底本的繁体、异体与少量缺字，不按常识补字或冒充校勘本。其中《红楼梦》为三个阅读分册，不据电子本额外指定纸本分卷与版次；第三册不全部归作曹雪芹亲笔。其余二十四册为英文原著或公版旧英译，没有生成现代中文译文。

版本上有几处需要看清：《人生的智慧》在所选英译中分为两册，必须合读；《作为意志和表象的世界》的三册是英译分册，不是德文原作卷数；爱比克泰德是论说选篇与完整手册，不是完整《论说集》。《庄子》的来源目录题署有误配，按实际三十三篇古文识别，并保留误配说明。

原版图、源注、戏剧分行和数表随相应文本保留或提供原图入口。每册都记录具体电子版本、来源与许可范围，个人译文、笔记和阅读记录不会因共享目录增加而公开。
