# 顶栏、书籍介绍与目录验收

2026-10-15。用户要求顶栏的书名与当前章可点击，浮出书籍介绍，并改善“书房”“目录”的对齐与美感。本次沿用现有阅读器和真实书籍元数据，没有调用模型、改动正文或新增依赖。

## 设计与行为

“书房”和“目录”统一为 44px 高的图标加文字入口，使用相同字号、基线和间距，以细分隔线区分返回与书内导航。窄屏收起“书房”文字，保留带可访问名称的返回图标，书名可省略显示。

中央书名是可聚焦按钮，保留章节信息与轻量展开提示。点击或按 Enter 后在顶栏下方打开原生非模态书籍浮层，显示已有的中英文书名、作者、简介、当前章、章节数、翻译草稿说明及可用的原文来源。没有简介的上传书明确显示缺失，不生成书籍资料；作者缺失时隐藏该字段。来源只接受无账号信息的 HTTP/HTTPS URL，书籍文字通过 textContent 写入。

目录用固定编号列、章名列与当前状态列排版，保留中英章名，使用细分隔和浅色当前章底色。原书章节可整行点击进入；编号小节保留展开入口和原段落锚点。仅当当前章在可视范围外时滚动目录，不移动正文。书籍加载完成前，两个目录入口与书籍介绍入口均禁用。

## 真实验证

- `npm run verify:deploy`：469 项通过、0 失败、1 项原有平台跳过。跳过项为 `a modified Node license is rejected even when the executable matches the pinned official binary`。隔离运行时初始化、静态构建、公开资源检查与 259 项软件文件发布清单检查均通过。
- 新增 4 项行为测试，空实现下分别因缺失元数据、目录项和小节链接而失败，完成实现后通过。覆盖章节计数不含前言、缺失简介与危险来源 URL、整章单次点击、编号小节原段落定位。
- 真实 Chromium 中，Enter 打开、Esc 关闭并返回书名按钮焦点，aria-expanded 同步关闭。打开介绍前后 scrollY 均为 310，首个可见段落顶部均为 117.546875px。点击目录会轻量收起介绍并打开目录。
- 从目录直接进入第 3 章与第 12 章，顶栏、书卡和当前章标记同步；第 12 章的当前行自动进入目录可视范围，第 3 章仍能从列表开头看到前言和第 1 章。
- 在实际 CSS 宽度 320、390、768、810、1440px 核对：顶栏入口互不重叠，介绍浮层位于视口内，无页面横向溢出。390px 夜读目录也完整位于视口内，无内部横向溢出。
- 夜读介绍的文字为 rgb(228,229,220)，纸面为 rgb(29,34,30)。系统减少动态效果时，介绍动画为 none。应用控制台未出现错误或警告。
- 独立代码审阅没有未解决的阻塞问题；发现的加载前目录入口问题已用禁用状态与空值保护修复。

## 验收环境与边界

浏览器行为测试使用独立 8373 临时实例和匿名公版《爱丽丝梦游仙境》，未写入真实书房，也没有改变用户 8372 预览的阅读位置与偏好。截图和结构化尺寸记录保存在忽略目录 `local/reader-navigation-qa/`。验收使用独立标签页，清除该标签页尺寸及低动态模拟后关闭，用户预览保持自然尺寸。

本轮未在真实 iPhone 或其他浏览器内核验收。浮层资料来自已加载的书籍，不表示新增了自动撰写简介功能。远程检查、PR 合并与生产验收以对应运行状态为准。
