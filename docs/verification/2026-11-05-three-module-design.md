## 独立审阅与修订

审阅提出 2 项 P1 和 2 项 P2，设计逐项补充：

| 发现 | 设计修订 |
| --- | --- |
| 最终结果、领域记录、计点与对象存储缺少一致性边界 | 不可变对象先暂存校验；领域 CAS、引用、任务终态、交付回执和最终事件同事务提交；丢响应查询唯一提交回执 |
| 租约没有约束供应商派发 | 派发前原子记录许可，绑定尝试、fencing 与稳定幂等键；日志持久确认后才发许可；未知结果暂停核对 |
| 数据库回退会丢失备份之后的派发记录 | 独立加密异地追加日志；新恢复代次与旧执行器隔离；queued 等非终态也可能需要隔离，不自动重放 |
| 固定监听端口与多个指针无法完成描述中的切换 | 候选 API 使用独立端口/Socket；Caddy 重载配对入口；先排空再启新 Agent，持久记录各组件实际版本和切换阶段 |
