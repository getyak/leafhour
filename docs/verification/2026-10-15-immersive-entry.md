# 默认沉浸阅读与无标签对照验收

日期：2026-10-15。用户要求进入书页时增加全屏沉浸感，去掉重复出现的原文、译文提示。

## 实现范围

书页 HTML 在首次显示前就设为沉浸布局，顶栏隐藏并设为 inert，不会等待脚本加载后才收起。右上角保留小型全屏和工具入口，工具栏覆盖在书页上，打开和收起不改变正文排版。设置内可切换普通阅读布局；再次打开书页仍默认沉浸。手机窄屏打开工具时使用两行顶栏，保留书名、简介、目录和设置。

沉浸布局与浏览器全屏独立。打开目录、设置、书籍信息时不会退出全屏；用户点击全屏按钮或按 F 才调用浏览器全屏接口。进入新页面时不能自动隐藏浏览器地址栏：[Fullscreen API 要求当前页面有用户操作](https://developer.mozilla.org/en-US/docs/Web/API/Element/requestFullscreen)。不支持或拒绝全屏的浏览器继续使用沉浸布局，并提供准确提示。

每一对正文不再插入可见的“原文／直译／意译”行，也不保留标签的空白高度。两侧通过语义分组及无障碍名称保留来源区别，原文、两种译文及段落 ID 保持原数据。缺译提示继续明确展示，译法与草稿来源可在设置内查看。

## 真实验证

- `npm run verify:deploy`：477 项测试，476 通过、1 跳过、0 失败；隔离运行包、网页构建、公开内容检查和发布清单检查通过。
- 新增单元回归验证首次呈现的沉浸状态、无可见重复标签、语义来源、导航键盘焦点、浏览器主动退出全屏以及请求被拒绝时的回退；新增模块也经过本地 HTTP 可用性检查。
- 在实际本地阅读器以匿名公版《爱丽丝梦游仙境》验收，页面脚本错误为 0；没有模型请求或真实账号数据写入。
- 首次进入顶栏不可见且不能被键盘误入，页面没有自动请求浏览器全屏。点击工具后导航可访问，焦点进入导航；Esc 收起工具后回到菜单按钮。打开工具前后段落锚点未移动。
- 对照正文可见标签数为 0，译文可正常选择为摘录，未翻译段落的提示保持可见。
- 点击真正全屏按钮进入成功；打开工具及设置后仍保持全屏；点击退出全屏以及浏览器自身退出后，页面保留沉浸布局，按钮状态更新。F 快捷键可触发全屏。
- 普通阅读切换可用，刷新后恢复默认沉浸入口。桌面 1440px、手机 390px 和 320px 验证导航入口和正文，无横向溢出。
- 独立审阅提出的菜单展开后键盘顺序问题已修复并复审通过。浏览器全屏 Promise 与 fullscreenchange 是异步事件，验收在对应事件完成后检查状态。

本记录描述本地代码与浏览器验收；线上提交、发布与正式站点验收分别以实时结果为准。
