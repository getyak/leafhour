# 纸感书架验收 · 2026-10-15

本轮按用户截图重做 `/library` 的材质、边框、封面与字体层次，保留侧栏、继续阅读、书架、搜索和书籍信息的既有功能。浅雾绿纸面压低颗粒对比度；细线采用固定的不规则轮廓；书籍用布面、书脊和数层纸页边缘构成，封面与文字信息上下排列，细搁板线托住同排书籍。没有增加木柜、拟真房间或额外装饰文案。

书名和节选继续使用系统宋体与 Georgia，操作仍用系统无衬线字体。封面从真实元数据绘制，缺失作者不补写；上传书籍按稳定书籍 ID 选择装帧色，同一本书在继续阅读、搜索与书架上保持一致。书名不在数据层截断，视觉封面允许省略，完整书名保留在下方和链接名称中。

## 本机实际检查

独立临时服务与浏览器页签仅使用三本公版书，没有向云端写入书籍、笔记或阅读记录。用户原有阅读页的位置与外观没有改动。

- 320、390、768、810、1024、1440、1920px：继续阅读与书架均无横向溢出；同排封面下沿对齐，手机端为两列。搜索三本公版书可检验移动端换排。
- 搜索书名及作者、无结果提示、清空恢复、侧栏收展及手机导航可操作；折叠时上传按钮仍显示完整提示。
- 书籍信息浮层位于屏幕边界内；Escape 收起并保留焦点；原有中文试读和来源入口可见。
- 夜间背景、墨色与操作按钮可读；系统减少动态效果时，封面和主区过渡为 0 秒。系统高对比度接管墨色，取消纸面背景和搁板遮罩。
- 在临时页签注入超长连续英文标题与作者名后，320px 仍无横向溢出；随后重新加载恢复真实公版数据。
- 装帧单元测试覆盖同书身份稳定、搜索位置变化、不同上传书的色彩差异、重新绘制清除旧内容、完整 Unicode 标题以及 HTML 字符作为文本插入。
- 独立代码审阅发现并修复浅色封面小字对比度和上传按钮提示被伪元素覆盖的问题。修复后的 lichen 材质全纹理估算最低对比度约 5.09:1；22 项针对性测试通过。

`npm run verify:deploy`：471 项通过，0 项失败，1 项既有平台跳过。隔离运行包初始化成功，公开构建及软件发布清单检查通过。跳过项为 Node 许可证篡改拒绝测试，不属于书架功能。
