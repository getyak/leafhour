## 实现与独立审查

- 主按钮为实底 pill，次按钮为纸底细线 pill，文字导航保持轻量。覆盖首页、
  登录、书房、赠书、阅读引导/结束、摘录导出、回声、音频、保存想法和对话操作。
  标签页、日期、纸面预览、选择卡、步进器和工具栏保留其状态/位置语义。
- 共享品牌焦点环按局部纸面解析；输入框保留边框/柔光变体，错误边框不被覆盖。
  聊天输入框把环画在 wrapper，内部 textarea 不重复画框。
- 普通分隔线/浮层边界使用 `--line-hairline`（8% 局部墨色），交互边界使用
  `--line-control`；浮层/模态层共用墨绿阴影家族。引用、原文高亮、选中态、
  插画、印刷和 forced-colors 属于明确例外。40 个普通边框消费者和支持页夜间
  别名已逐项核对；这不表示源码没有颜色字面量。
- 外观按钮打开「跟随系统 / 纸白 / 夜色」原生 radio 菜单，选择立即应用；
  保留兼容存储键、跨标签同步、无效值恢复和 reduced-motion。
- 三位独立 sub-agent 审查；确认的 P1 与 P2 均修复并复核关闭，包括遗漏的 CTA、
  share primary 层叠覆盖、夜色次按钮回退、输入框 wrapper 焦点及局部配色继承。

37 组焦点对比为从实际 CSS palette 重新计算的 WCAG 数值，最低 **3.81:1**；
不是浏览器像素采样。auth 的纸白/夜色按钮文字对比为 9.04:1 / 8.32:1。
详细值、作用域及例外见 [实现规格](../superpowers/specs/2026-10-18-get-169-components.md)。
