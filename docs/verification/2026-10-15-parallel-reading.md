# 对照阅读风格与布局验收

日期：2026-10-15。范围：现有网页阅读器的本地展示与偏好保存。

## 选择依据

用户希望参考截图中的对照设置，保留少量高价值风格，并可设置上下或左右、颜色及背景。以长文可读性、核对效率、学习用途和低操作成本筛选出五种预设；这是产品判断，没有声称用户研究评分或学习效果已经得到验证。

| 风格 | 主要用途 |
| --- | --- |
| 素面对照 | 原文与译文同等清晰，持续细读、核对措辞 |
| 译文淡化 | 先关注原文，保留可读的译文参考 |
| 引用侧线 | 用细线区分译文，减少往返时找错段落 |
| 柔和底色 | 让译文更容易定位 |
| 点按揭晓 | 逐段尝试理解原文，再查看已经保存的译文 |

排列、译文颜色、译文背景相互独立。宽屏可左右或上下排列；767px 及以下的正文与预览都按段落上下排列。译文颜色提供跟随纸面、松绿、墨蓝、茶褐，背景提供跟随风格、无底色、柔和底色；整页背景继续使用现有纸面主题。设置页直接预览，不必先离开原文阅读模式。

## 真实验证

- `npm run verify:deploy`：472 项测试，471 通过，1 跳过，0 失败。隔离运行包、网页构建、公开构建检查和发布清单检查均通过。
- 新增偏好可经进度保存、记录导出、另一隔离实例导入完整恢复。非法枚举导入返回 400，原记录保持完整；旧记录补齐默认值。网页重新打开仍遵循既有原文优先规则，对照风格保留。
- 在本地实际阅读器使用匿名公版《爱丽丝梦游仙境》样本检查五种风格，每种都能选择中文译文生成对应摘录。
- 点按揭晓在初始状态隐藏已有译文；键盘回车可展开，再次操作可收起。缺译提示始终可见。跨两段原文选择时，隐藏译文不会混入摘录。揭晓前的整段默认引用归属为原文，旁注源文沿实际选中层。
- 桌面 1440px 验证左右和上下；手机 390px 验证自动上下、预览一致、页面没有横向溢出。刷新后布局、风格、译文颜色及背景恢复。
- 对五种纸面、五种风格、四种颜色、三种背景共 300 组实际计算样式进行正文对比度检查。最低约 4.503:1（暖纸、译文淡化、茶褐、柔和底色），均达到 [WCAG 正文 4.5:1](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。此检查范围为译文正文，不代表整个产品的无障碍认证。
- 浏览器流程没有页面脚本错误。所有操作使用现有译文，没有请求模型或写入真实账号测试书籍。
