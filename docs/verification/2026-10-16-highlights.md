# 文字高亮验收

日期：2026-10-16。

选中文字后点击“高亮”，以淡黄色保存到当前账号。点击已有高亮可以取消或写想法；“阅读设置 → 数据 → 我的记录”收录高亮并返回对应文字。原文、直译和意译分别标记，未翻译段落仍保留原文。

## 数据与边界

高亮保存书籍版本、章节、稳定段落 ID、语言、译法、文字范围和当时的摘录。服务端核对文字后保存，重复提交不会复制记录。取消保留删除标记，导入旧备份不会重新启用已取消的高亮。私人高亮随书房备份导出，可在干净实例恢复，不进入赠书阅读包。

译文更新后，当时的摘录继续保留；只有文字仍精确对应时才在正文标色。跨章节或混合语言的无效选择会关闭旧的高亮入口。最多选择同章八段，含段落分隔符不超过 4,000 字。后台保存回执不会清掉后来选中的文字。

## 已验证

- 领域服务与实际 HTTP 路由：账号隔离、匿名与旧账号拒绝、保存和取消、重复请求、译文变化后的同 ID 重试、备份恢复与删除标记合并。
- 真实 Chromium 页面：鼠标拖选保存、刷新恢复、重叠高亮分别取消、跨段选择、写想法保留完整摘录、“我的记录”回访与写想法、原文及两种译法分开显示。
- 故障场景：服务已写入但回执丢失后重试不重复；慢请求期间新的原生选文保留；长段落回访后操作条可见；旧译文摘录不会标到当前译文中的其他文字。
- 390px 手机宽度与 1440px 桌面宽度，以及夜间高亮；页面无横向溢出，操作条位于视口内，浏览器无脚本异常。

浏览器验收使用隔离的阅读样本与临时数据，不向真实账号写入这些测试内容。JSON 结果和截图保存在本机 `local/verification/highlights/`，未随源码发布。手机检查是 Chromium 视口验收，不等同于真实 iPhone 长按选文验收。

完整 `npm run verify:deploy` 已通过：664 项通过，1 项因当前平台不适用而跳过。该跳过项是 Linux Node 许可证校验的反例测试。包含阅读运行时构建、公开资源检查和发布文件清单检查。
