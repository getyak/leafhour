# GET-328: new complete 73-page public Alice fixture

This is a **NEW source / NEW hash** acceptance fixture. The historical
`Alice-complete.pdf` was unavailable. This generator does not recover that file,
reproduce its hash, or turn the earlier unsuccessful Files flow into a pass.

Run from this checkout with its existing `pdf-lib` and `pdfjs-dist` dependencies:

```sh
node tools/generate-get328-alice-pdf73.mjs --artifact-dir /absolute/external/artifact-directory
node --test tests/get328-alice-pdf73.test.mjs
```

The output directory is mandatory and must be outside the repository. The files
are `Alice-complete-GET328-20261107.pdf` and
`Alice-complete-GET328-20261107.manifest.json`. No binary fixture is committed.
Regeneration is byte deterministic, with no creation/modification dates or random
trailer ID. If either preexisting output differs, generation fails without
overwriting either file.

The only source is the repository's public-domain `catalog/alice.txt`, SHA-256
`01b38ea4c710a84bc18d0bd41271a5a1a92b94e97b2812f4dece97d4a694725e`.
All twelve narrative chapters, their headings, all 811 paragraphs, all 26,441
whitespace-delimited words, and `THE END` are included. The Gutenberg metadata,
front matter, duplicate contents list and license wrapper are outside the
narrative selection. Paragraphs remain intact and in order; source line wrapping
is reflowed. Punctuation and word order are unchanged. The canonical narrative
SHA-256, after collapsing whitespace runs, is
`fab10098897c657bbd45a4c647c01c5819068270613c8574800aaf08508419aa`.

All 73 pages contain substantive typeset narrative. Every page has the visible,
extractable header `GET328_PUBLIC_ALICE_PAGE_<page>_OF_73`, using a one-based page
number without zero padding. The last two markers are therefore
`GET328_PUBLIC_ALICE_PAGE_72_OF_73` and
`GET328_PUBLIC_ALICE_PAGE_73_OF_73`. Page 73 contains the actual ending
`happy summer days.` followed by `THE END`.

Before writing files, the generator parses its actual PDF bytes with PDF.js,
checks 73 substantive pages and their markers, validates glyph bounds, recovers
paragraph boundaries from real line positions, and compares every paragraph and
the full canonical narrative against the pinned source. The manifest records
source/PDF hashes, exact coverage, each page's word and paragraph ranges, unique
narrative quote, last 16 words, page text hash, and a dedicated page-73 receipt.

Host tests independently parse the actual generated bytes, reconstruct the entire
narrative, inspect every page marker and text bounds, check repeat generation,
and reject removed, blank, reordered or duplicated pages and changed sources.
They also remove the final `END` word from the actual PDF text stream while
retaining 73 pages, all page markers and line positions, and require rejection.
These host checks establish fixture identity and content only. Native Files
import, PDFKit page 73, cold resume and device acceptance require their own run.
