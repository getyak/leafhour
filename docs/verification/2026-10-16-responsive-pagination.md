# 窄窗口与双页翻读验收

2026-10-16。用户明确选择像摊开的书一样分成左右两页，用方向键或按钮翻页。本轮沿用正式阅读器，未生成译文、讲稿或收费音频，未修改真实账号数据。

## 行为

阅读设置新增“书页布局”：滚动阅读和翻页阅读。原文、中文直译和意译均可翻读；宽度达到 900px 显示双页，窄窗口显示单页。两页是同一正文的连续排版，中英对照继续使用原来的独立模式，暂时收起翻页设置并保留偏好。

左右方向键和页底按钮前后翻页，章末进入下一章，上一章从末页返回。原始段落标识、正文、译文状态和选择复制能力保留。缺少译文继续显示原文及缺译提示。翻页偏好随阅读位置、导出和恢复保存，旧记录默认滚动阅读。

窗口变化、字号、模式切换和刷新使用原段落及段内比例恢复相近的位置，不承诺逐字相同。段落操作锚定当前可见片段；鼠标点按不因跨页段落的焦点滚动而跳页。Tab 进入另一页的段落会同步位置；关闭旁注返回焦点时保留当前跨页片段。

书房在 980px 及以下使用抽屉导航，让继续阅读、书架与搜索有完整宽度。播放器沿用已有的动态高度留白；听读跟随判断水平方向的可见性，主动翻页暂停跟随并保留播放。

## 验证

完整验证包含 677 项测试：676 项通过，无失败，1 项原有 Linux 平台限定测试在 macOS 跳过。隔离阅读运行时初始化、网页构建、公开产物和发布白名单检查通过。

真实 Chromium 检查首页、书房和阅读器的 320、390、600、768、820、900、1024、1440px 等宽度，未出现页面横向溢出。980px 边界两侧分别显示抽屉与固定侧栏；阅读器 899/900px 边界分别显示单页与双页。320×568 的翻页栏与底部阅读工具不重叠。

在已存在的公版中文样本中切换原文、译文、对照；字体从 22 调到 23，设置与实际状态一致。对照期间隐藏翻页，返回译文后恢复。开篇仍为 6 段独立译文，其余正文保留未译提示。逐页遍历第一章，43 个段落排版片段全部可见，未遗漏片段；章末进入第二章第一页，再返回第一章末页。

真实鼠标拖选保留选中文字，方向键不触发误翻页；旁注和设置打开时不抢走方向键。20 次 Tab 后，焦点段落与保存锚点一致，缩到 850px 后仍可见。刷新恢复同一段落、字号和翻页偏好，并沿用原文优先的既有规则。

独立审阅发现键盘焦点定位与听读横向跟随两处问题，新增回归测试并修复。第二轮检查又补充跨页段落关闭旁注后返回焦点的保位测试。已合入同期文字高亮主分支，保留高亮实现及其测试。第三项集成检查修复长段落后半段的高亮定位：按摘录所在排版片段水平翻页，不再只定位段落开头。

## 边界

浏览器检查使用独立本机实例和匿名公版书。没有为验收生成音频或向真实书房写测试记录。听读跟随用隔离播放状态和几何测试验证；本轮没有再次证明供应商音频生成或移动设备后台策略。未在真实 iPhone、Firefox 或 Safari 内核完成验收。PR、发布与线上验收以远程运行记录为准。
