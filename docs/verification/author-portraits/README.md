# 人物页验收记录

2026-10-28。本记录区分正式实现、隔离环境中的验证与真实模型实验。合并和 Production 状态以关联 PR 及同提交发布回执为准。

## 已实现

人物馆包含人物与作品时间线、创作背景、原句与出处。四语言界面提供清纸和夜读，也保留大字、键盘与减少动态效果。作者入口可从当前书进入，未收录的作者先带入搜索，再建立自己的资料并回到原书。私人书名、书籍 ID 和阅读位置不进入人物公开链接。

人物领域服务与网页、阅读 Agent、外部 MCP 共用。创建与保存不会暗中调用模型，逐项更新可修改一份长年表中的单个事件。生成使用版本化撰写规则和官方 DSH，事实候选保持待核。借用旧证明的新叙述会另建候选引用，原句与原证明保留。

公开副本先预览，重新打开面板后仍可逐个撤回。私人叙述不自动公开，来源也只保留实际使用的片段。投影版本 3 使不符合当前规则的旧私人副本失效，原私人资料保留。图片与链接使用当前实例的地址，支持自托管。

## 实际验证

最终真实 Chrome 流程使用合并后的正式服务、公版人物与临时本机账号，没有配置模型密钥，也没有写入真实云端书房。四种宽度为 1440、768、390 和 320 px。姓名没有孤字末行，页面没有横向溢出。实际完成了发布、关闭面板、刷新、重新打开和单独撤回，撤回后的副本返回 410。未收录作者从新目录进入搜索、创建私人资料，再返回原书的路径通过，浏览器未报告脚本异常。

另有夜读、大字、四语言切换及出处焦点返回的实际浏览记录。Canvas 长文本与组合字符导出保留完整字节，按竖图、方图分别分页。真实设备上的系统分享收件、Safari 和读屏语音输出没有据此宣称通过。

独立审阅复现并关闭了来源尾部私文公开、叙述借用已核证明、取消后迟到保存、关闭面板后无法撤回旧副本，以及人物引用妨碍备份的问题。托管适配器的并发测试使用真实适配器与受控数据库 RPC，暂停在最后一次授权之后。撤权会等待同键写入栅栏再返回成功，旧提交重试时拒绝保存。它不冒充生产数据库的实写验证。

标准 MCP 客户端还完成了无令牌自动发现、动态注册、PKCE、用户授权及后续工具调用。人物资源使用 `/api/people/mcp`，原有阅读资源继续使用 `/api/mcp`，两种令牌跨入口使用会被拒绝。该验证把 HTTPS 逻辑地址和部署路由映射到本机隔离服务，使用真实 SDK 与产品授权实现，没有手工预置访问令牌，也没有声称已替用户连接实际个人宿主。

## 模型实验与评分边界

冻结任务为 24 个场景，每个运行 3 次，规则位于 [评测场景](../../../tests/fixtures/people-benchmark-cases.json)。首轮 72 项实跑保留 62 通过、10 失败。其中 54 项为确定性行为，18 项使用真实陌生人物目录、来源和 DSH，8 项通过。失败涵盖网络、输出格式与结构校验，未保存的候选没有被计为成功。

后续纠错与修正分别记录，未覆盖首轮。最后一次真实 DSH 已完整保存 4 个事件和 1 部作品，全部新增事实为待核，人物和任务也保持未核状态。累计真实调用 20 次，19 次有可计算用量、1 次费用未知。已知用量计价小计为 US$0.009413，不是账户账单总额。发起额度记录为 23，未突破 24 的聚合上限，没有购买余额。

最终确定性重跑为 54 项通过、0 失败，18 项真实网络与生成项目未在该次重复运行。新回执保存执行源文件指纹。早期实验没有记录的执行指纹不会用当前代码倒填。综合九维评分仍为未完成，没有宣称超过 98 分，也没有用工程通过率代替审美与读者启发。
