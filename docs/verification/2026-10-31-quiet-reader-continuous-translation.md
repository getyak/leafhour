# 正文优先阅读与连续翻译

2026-10-31。设计来源为用户已批准的 [Duo 阅读页](../superpowers/specs/2026-10-30-iphone-duo-reader-design.md)。本轮把安静阅读落入正式 iOS 源码，并为 iOS、Web 与复用网页运行时的 Android 增加当前章／紧接下一章的自动译文准备。

## 实际行为

iOS 默认显示正文、轻量章节／内容归属和一个独立 44pt 工具入口。目录、语言、文字与纸面、笔记、听读和陪读按需展开。工具区在空间足够时放在旁边，紧凑空间使用独立工具页；宽窄变化不重新创建笔记编辑器、提交 ID 或 ReaderSession。普通文字选择和复制沿用 UIKit，PDF 与翻页输入继续走已有渲染器。

单栏正文最大宽约 420pt，保留用户字号；可用系统宋体用于中文内容，缺少该字体时回退系统衬线。大字号短横屏减少标题占用，为真实 TextKit 字形保留完整可读行。原译对照在宽窗口显示原文副栏与主要译文栏；副栏按来源段落跟随主要语言，只有主要栏写入阅读进度。窄屏逐段配对。没有可靠句内双语映射时只承诺同一来源段落，不伪造原文字符偏移。

自动准备共用 `POST /api/library/books/:id/reading-translation`，每次至多处理一段，当前章优先，然后只处理紧接下一章。原文模式、关闭开关、页面后台、账户／书籍／来源变化都会停止后续派发；已派发单段仍由原来源与账本核对。上下文也限制在这两章，不向第三章延伸。已有非空直译或意译（draft/reviewed）原样保留，只补缺失版本。

所有新付费生成继续检查报价、模式、真实余额、来源、幂等与结算，不充值或更换供应商。跨客户端竞争使用相同来源身份；已保存结果直接复用。可信失败终态最多允许三次确定性自动尝试，未知／运行中状态不换 ID；错误停在工具内，等待显式重试。Web/Android 自动回执不切模式、不逐段弹通知，活动选文或笔记期间延后正文替换。iOS 将译文字符位置与原文偏移分开保存，自动到达不会改写活动选文。

关闭自动准备和离线状态仍可读取可信译文缓存。译文选文、作者原文与个人笔记保留不同归属；上传、拉取与迁移草稿分别有回归覆盖。仅本机且未同步账号的书仍提供原文阅读及明确的同步入口，不自动上传私人原件。
