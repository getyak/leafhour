# 阅读缓存与离线阅读验证

日期：2026-10-29。本记录涵盖实现与本机验证。合并、正式发布及线上验收结果由关联 PR 和正式站的 release.json 记录，平台限制单独保留。

## 实现结果

重复打开书籍时先核对阅读清单。清单没有变化，服务器在核对当前账号与正文状态后返回 304，本机复用既有内容。当前章按内容摘要读取，正文修订和两种译文都参与摘要计算。简介等书籍资料更新后仍会重新取得，不能只凭原文版本号判断整本内容没变。

最近读过的章节自动保存。书籍菜单提供“保存到此设备”，整本下载完成且配套界面资源通过核验后才显示“可离线阅读”。取消保留已经完成的章节，空间不足不会报成下载成功。普通缓存有容量上限，主动保存的书不会被静默淘汰。

断网后可以打开已保存内容，原文与两种译文保持独立，缺失章节不补造正文。进度和笔记草稿继续保存在本机，联网后先确认账号与正文。另一设备已有新位置时保留双方候选，读者明确选择后才继续保存。无法对应新原文的位置提供恢复副本。

本机阅读不冒充云端登录，不保存访问令牌，不排队发起收费任务。退出账号或清除本机书籍会先撤销访问，再删除文件。草稿和待确认记录不作为普通缓存删除。已知服务器拒绝访问时，不能用断网回退重新打开旧私人副本。

## 已观察的浏览器结果

匿名公版《爱丽丝梦游仙境》在隔离的本机服务中验证，未使用其他真实账号的数据，也没有发起收费生成。

| 场景 | 实际结果 |
| --- | --- |
| 主动保存整本 | 13 / 13 个目录条目完成（含前言），固定保存，正文与书目约 375663 字节 |
| 断网刷新 | 正文可读，显示“离线阅读” |
| 断网切章 | 经目录进入第二章，显示实际第二章原文 |
| 关闭页面后断网重开 | 仍在第二章，恢复本机位置 |
| 手机宽度 | 390 × 844 像素下没有横向溢出 |
| 恢复网络 | 重新确认身份并打开在线正文，保留第二章位置 |
| 本机书房 | 只列出当前设备实际保存的书和范围 |
| 只保存部分内容 | 仅第一章已保存，第二章续读点仍保留，临时打开第一章并明确提示缺章 |
| 清除本机内容 | 经离线书房的真实按钮清除后，列表为 0，本机范围标记已撤销 |

早期浏览器样本的断网刷新为 227 ms，关页重开为 206 ms。后续同一环境连续打开 5 次，可读时间分别为 668、189、184、162 和 160 ms，中位数 184 ms。5 次都收到 304，清单正文传输为 0 字节，章节请求为 0。该环境同时运行验证任务，这些样本不能据以宣称所有设备和网络上的稳定提升幅度。

## 验证范围

定向测试覆盖摘要损坏、原文版本不变时改译文、同键请求合并、缓存容量和固定书、账号往返切换、清理失败、迟到响应、分段大章节、下载中断、未完成下载的真实状态，以及进度冲突与恢复。新行为先观察失败，再补实现并复测。

界面资源只从公开发布清单构建。书籍正文和私人接口不进入 Service Worker 的共享资源缓存。新旧页面按配套资源组读取，首次接管、工作线程重启、旧页面继续打开工具与本机书房跳转均有回归检查。

本机全量功能测试执行 4156 项，4155 项通过、0 项失败、1 项平台条件检查跳过。测试、隔离运行时、构建和发布边界检查均完成。公开资源清单的 220 个文件已逐一核对摘要；未知构建文件仍会被发布检查拒绝。CI 与正式发布的最终结果以关联 PR 为准，不把本机结果写成线上已通过。

Safari、真实 iPhone、系统长期清理存储后的行为仍未完成设备验收。浏览器可以清理本机存储，书房备份保留独立导出入口。现有阅读壳会产生内联样式的安全策略控制台提示，本轮没有放宽策略，也不声明控制台零错误。
