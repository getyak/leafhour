# 2026-10-23 阅读与书房体验精修

本轮依据真实 Chrome 账户操作、桌面与窄屏截图以及独立代码审阅，收拢重复设置与辅助说明，并修正定位、焦点和恢复文件校验的边界。未修改书籍内容、译文审核状态或个人记录。

## 观察与处理

| 场景 | 读者原先看到或遇到什么 | 本轮处理 |
| --- | --- | --- |
| 书房纸条 | 筛选隐藏续读卡后，历史纸条全文占据首屏，书架被推到下面 | 默认显示有数量的摘要；展开仍能看全文并返回原文 |
| 阅读习惯 | 四个带来源和删除入口的偏好控件之后，又有一套常用排版表单 | 常用表单在前，来源与管理默认折叠 |
| 外观 | 说明将账号同步的界面语言也称为当前设备设置 | 四语言文案区分设备外观与账号语言 |
| 恢复备份 | 未选文件或文件无效时仍可进入确认 | 只有当前账号与当前文件校验成功时启用；确认时重新检查 |
| 章节开头 | 每次都显示完整的按需翻译与发送范围说明 | 普通说明折叠；触发翻译处仍显示云端发送范围与草稿说明，试读范围、任务进行中、失败及后台结果继续显式显示 |
| 阅读工具 | 计时方式与长解释先于开始按钮出现 | 主要计时操作在前，计时设置默认折叠；游客不显示空入口 |
| 高亮记录 | “写想法”可能先打开旧段落，再被异步定位关闭 | 定位成功后才打开想法；取消与失败不打开旧目标 |
| 注解与批注 | 页签方向键无效，或关闭后焦点落到隐藏按钮 | 补全页签键盘操作与可见入口的焦点恢复；异步刷新不抢输入焦点 |

筛选、上传、账户、每日陪读、数据导出恢复等代码路径另经清单审阅。上传后转入对话、偏好自动筛选隐藏续读卡、阅读设置中目标与展示方式的多层关系，作为后续交互方向保留；本轮没有据此重构流程。

## 证据范围

真实账户检查覆盖游客登录入口、密码登录、筛选与清除、续读入口、账户资料展示、阅读习惯滚动、外观、数据页初态、上传入口、书内阅读工具、阅读设置和窄屏正文。本机浏览器另检查修改后的设置布局及注解页签键盘操作。

截图包含私人书房内容，仅保存在本机本次任务的 `output/ux-review-2026-10-23/`，不进入公开仓库或部署包。公开报告不复制私人书籍、纸条正文、邮箱或账户标识。

没有提交新笔记、上传书籍、付费生成、变更授权、执行恢复或删除记录。上述业务结果仍需要各自的真实验收，不能从界面截图推断已通过。

## 验证与发布

各项行为改动先补复现，再完成回归。独立审阅发现并修复了游客空计时入口、纸条刷新丢焦点及偏离共享焦点样式的问题。

全套验证发现模拟聊天测试读取真实报价记录后会随日期过期。测试仅固定模拟运行的日期，保留真实超时与取消，并新增真实报价过期时在启动运行前拒绝的测试；生产报价与费用保护没有修改。

最终测试、构建、检查及生产提交结果在发布验收后补记。交互约定见 [界面修饰指南](../ux-craft-guidelines.md)。
