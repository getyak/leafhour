# 阅读 Agent 书目检索说明补充

2026-10-16，发布后的真实生产验收发现：Agent 能执行书房、书目与网络工具，但使用宽泛的推荐任务作为书目搜索词，并把外部未命中误解为推荐范围受限，最终选择不符合读者要求的已有书籍。此前使用具体英文书名的隔离检索已成功。这是工具能力说明的可用性缺口；此记录不包含私人书名或原始对话。

本次仅补充 `reader_recommend_books` 的工具描述与参数说明：书房提供背景，外部候选独立检索，可自由推荐书房之外的书，用具体书名、作者或简短关键词核实；未命中不构成推荐或阅读禁令，候选也不等同于最终推荐。没有规定工具顺序、回答模板或推荐类型。权限、费用和来源核验机制保持原样。

验证：现有 `tests/reading-agent-tools.test.mjs` 19 项通过，0 失败、0 跳过。未新增仅比对说明文字的测试，未执行付费模型请求或全项目构建。此次本地测试证明原有工具行为未回归；生产推荐质量仍待控制者重新验收。
