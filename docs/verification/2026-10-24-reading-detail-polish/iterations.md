# 阅读页细节遍历记录（2026-10-24）

每条是一次独立的“观察 → 改动 → 验证”。验证方式：同一台机器、同一本书（gutenberg-alice）、
同一浏览器引擎（Playwright Chromium）在 1440×1000、768×1024、390×844 三个宽度重拍截图，
并用 `capture.mjs` 记录的控件矩形与间距数值对比（`compare.mjs`）。截图只保存在本机
`output/reading-polish-2026-10-24/`，不进入公开仓库。

判据来自 [界面修饰指南](../../ux-craft-guidelines.md)：正文先于设置；按钮写动作、状态写结果；
点击区域至少 44px；普通解释只出现一次；不隐藏错误、不缩小控件。
