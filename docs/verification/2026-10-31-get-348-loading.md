# GET-348 contextual loading

Refs https://linear.app/getyak/issue/GET-348

The server previously returned one bare `ws.loading` paragraph for the calendar
and notes routes. It stayed at the top of the content area while session, books,
the lazy workspace module and stylesheet loaded. After mounting, the workspace
also painted empty records before its first data requests settled.

The server and browser now share the existing decorative paper companion and
verified public Alice excerpt. Calendar, notes and library use their own localized
status. The excerpt retains source attribution and Chinese AI-draft provenance;
it does not imply ownership, reading progress or completed activity. No model
request was added. Workspace-only styles remain outside the reader CSS budget.

The first data load keeps the arrival until records settle. Guest mode resolves
to sign-in, failures expose visible error/retry, and account-entry failures retry
the whole entry. Background refresh retains unchanged editors and failed books'
previously loaded records with an explicit partial-failure warning.
