# 阅读设置与后台声音验收

2026-10-15。完整配置清单见 [阅读设置的逐项盘点与重组](../reader-settings-inventory.md)。本轮只调整设置组织与声音生命周期，没有生成译文、讲稿或收费音频，没有写入真实账号的书籍与阅读记录。

## 已实现

旧控制器在 `visibilitychange` 检测到页面隐藏时主动调用 `session.stop()`，旧测试也将其视为预期。现在可见性只影响视觉动效，后台阅读计时仍暂停；声音按用户的播放／暂停选择继续。实际离开、刷新或关闭当前页面仍释放声音；手动暂停后返回页面不会自动重播。

设置固定为阅读、声音、习惯、数据四页。原文模式隐藏中文译法、对照排列、风格、预览和译文配色；中文模式只显示译法；对照模式才出现完整对照设置。隐藏偏好不清零。

字号、字体和纸面在阅读首页直接呈现，精细排版与译文配色折叠。声音页直接调氛围播放与两路音量，并与场景面板同步。正文听读使用紧凑的声音选择，双人讲解角色折叠。备份统一移到数据页，保留阅读体验的独立导入／导出。摘录图片九项配置留在分享场景。

## 验证证据

- 完整测试：481 项，480 通过，1 项仅 Linux 适用的测试在 macOS 跳过，无失败。使用随应用提供的 Node 24.19.0、两路并发完成。本机 Homebrew Node 22 缺动态库，未用于通过声明。
- 独立阅读运行时构建及初始化通过，无模型请求；网页构建通过，公开产物检查为 117 个文件、9 项注册媒体；发布白名单与来源校验通过。
- 真实浏览器逐项操作原文、中文、对照三种模式；对照五种风格可选，切换模式后译法、风格、颜色保持。声音偏好中的讲解角色默认折叠，展开后可修改。
- 四页签单页可见，左右方向键切换焦点；390 和 320 像素宽度没有抽屉横向溢出。匿名试读的导出入口继续遵守原有登录边界；原先的阅读体验导入入口仍能显示。
- 控制器回归测试覆盖后台加载完成、返回不重启、手动暂停保留、实际离开页面释放声音，以及两处音量／动效／播放控制同步。
- 独立审阅发现并修复阅读体验入口的挂载容器遗漏，以及播放器“回到正在朗读处”未更新设置摘要的问题。

首次本地全量测试受机器负载影响出现运行时超时与一次临时连接中断；降低并发并使用可用运行时重跑全部通过。没有修改超时阈值或跳过失败测试。

## 边界

后台音频的操作系统锁屏、节电限制及不同移动浏览器策略需要对应设备单独验收，本轮不将桌面结果外推为手机锁屏保证。氛围偏好仍只保存在本浏览器，不随书房备份迁移。完整表格逐项记录每个偏好的优先级、位置、出现条件和保存范围。
