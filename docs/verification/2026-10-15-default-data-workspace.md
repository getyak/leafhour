# 默认测试书房与旧书迁移验收

日期：2026-10-15。账号：`test@cubxxw.com`。范围为既有资源迁移与数据结构检查，没有新增翻译或模型调用。

## 实际数据

Supabase Auth 原先没有该账号，本次通过服务端管理接口建立，并验证钥匙串中的密码可以完成供应商登录。正式网站通过现有验证码验证接口建立了同一账号的会话；验证码由管理端生成，没有发送邮件，不作为实际收信证明。网页继续使用现有验证码和第三方登录方式。

迁入《有限与无限的游戏》的英文 PDF 和既有阅读包：7 章、101 节、579 段、每段独立直译与意译、148 条编辑注解、66 个术语。迁移前后的段落 ID、英文、两种中文文字、注解和术语逐项一致。PDF 共 8,009,574 字节，正式网站私人下载后的 SHA-256 与本机底本一致。原文保持未校对，译文保持 AI 草稿，没有提升审阅状态。

本机 5 本上传小样、云端 1 本合成书，以及公版《瓦尔登湖》的既有测试译文和记录也迁入该账号。账号书架共 10 本，其中 7 本私人书籍、3 本共享公版书；记录合计 209 条评论、1 个问题、1 个合成阅读时段。这些是历史测试数据，不能用于证明用户真实阅读或理解。

13 份旧云端测试文档保存到目标账号的资源归档。旧样书的体验脚本、指标与本机/旧云端体验记录另存于 `legacyReadingResources`，随书籍 JSON 导出。原目录和旧云端数据保留；其他真实账号的记录未迁入。

## 验证结果

- 50 项迁移与恢复核对通过，包括独立服务重新读取、内容一致、原有文档未变、匿名及其他身份无法读取私人书籍。本机来源文件的哈希保持不变。
- 正式网站 17 项接口核对通过，包括账号会话、书架、完整正文、双译、注解、术语、原件签名下载、三段导出及整体校验和。匿名目录仍只有三本公版书，匿名数据库直连被拒绝，错误账号请求头被拒绝。
- 正式浏览器显示已登录书架和真实书籍正文，点击段落后识别出已有直译与意译草稿。验收浏览器阻止书房写入，避免把 Agent 页面访问计入用户阅读或改变进度。
- 书房导出已恢复到干净本机实例，核对完整章节、译文和体验归档；另行补入匹配 PDF 后，原件下载字节一致。普通书房 JSON 不包含二进制原件，完整原件恢复包含上述独立步骤。
- `npm run verify:deploy` 通过：323 项测试全部通过，构建、媒体完整性、发布文件范围与公开内容检查通过。

浏览器读取听读偏好时仍返回既有的 503；本项目当前托管版未提供持久听读 worker，本次未启用听读。线上探索与回声接口也未接入；保存旧体验归档不能当作线上探索功能已经完成。

## 证据与交付边界

原始数据、迁移脚本、结构快照、备份与证据位于被忽略的 `local/account-data-audit/`。主要核对记录是 `migration-evidence.json`、`http-evidence.json` 和 `project-verification.log`，不随公开文档提交书籍全文、阅读记录、登录会话或真实凭据。

数据库没有重建或改表，现有产品源码未修改。公开提交仅包含默认数据账号规则、数据库说明和本验收记录；实际书籍与测试记录已写入私人数据库，不依赖新的部署才能访问。PR 合并与网站发布由后续 CI/CD 状态分别核对。
