# 官网空间与动效验收

日期：2026-10-15。范围为官网，沿用现有书页、自然光、森林绿和文案。书房与正文的阅读行为保持原有实现。

## 设计依据与实现

本轮实际浏览了 [Ambi 官网](https://www.ambi.ai/en) 的首屏与滚动段落。借鉴的是物件的前后关系、画面裁切、留白和分段展开的节奏；将它们转为循页的窗景、前景书页和示例纸面。这是设计判断，不表示本轮验证了 Ambi 产品能力或用户效果。

首屏标题逐行进入，图片与前景稍后落定，整体约 1.5 秒内结束。后续内容在首次进入视野时轻移和淡入；书封与按钮在悬停、按压和键盘焦点下反馈。没有自动循环的背景动画。官网动效模块独立加载，书房服务端隐藏官网时不创建观察器。

滚动视差采用命名视图时间轴，由图片外框作为观察对象、网页作为滚动源。初版直接在图片上使用 `view()`，实际检查发现其滚动源成为不滚动的裁切框，进度固定在 50%；已修正并重新验证。浏览器不支持时间轴时保留静态图片，内容仍可读。

入口内容默认可见，不依赖 JavaScript 移除隐藏类。减少动态效果会关闭入场与视差，并取消正在进行的 JavaScript 动画；后台暂停观察，回到页面时恢复尚未展示的部分。键盘焦点进入时取消动画，已获得焦点的内容不会再触发入场。

原生 API 依据：[视图动画时间轴](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/animation-timeline)、[Intersection Observer](https://developer.mozilla.org/en-US/docs/Web/API/Intersection_Observer_API)、[Element.animate](https://developer.mozilla.org/en-US/docs/Web/API/Element/animate)。未新增依赖或外部素材请求。

## 实际验证

- 完整 `npm run verify:deploy` 退出码 0：424 项测试通过，阅读运行包、托管构建、公开资源与发布清单检查通过。
- 动效生命周期的 5 项测试覆盖隐藏官网、减少动态效果切换、后加载书封、后台与清理、不支持观察器的降级和焦点先于观察回调的顺序。
- Codex 内置浏览器检查 320×740、390×844、768×1024、1440×900：均无横向溢出，主入口在首屏可见；日间与夜间外观正常。
- 实际滚动时，书页图片的时间轴滚动源为 `HTML`。390px 下从页面滚动位置 1688 到 2532，图片纵向变换从约 -2.77px 到 +1.95px，确认视差真实发生。
- 模拟系统减少动态效果后，页面动画列表为空，主图片变换为 `none`，正文及入口保留。
- 从官网点击“开始阅读”，进入 `/library`，官网隐藏、书房侧栏保持固定，官网动画数量为 0；点击“先读几页”进入公版原文，章节正文实际加载。浏览器未记录控制台错误。
- 独立代码审阅检查焦点、后台、页面恢复、变换叠加、书房隔离与资源映射；发现的焦点顺序问题已修复并增加失败后通过的回归测试，复查无剩余问题。

验收使用临时本机服务和共享公版目录，没有写入真实账号、调用模型或创建付费任务。截图保存在本次对话附件。未实测 Safari、Firefox、真实手机或屏幕阅读器；没有据此宣称这些环境已经通过，也未进行性能或用户完成率测量。线上发布状态以 PR、CI、生产检查与当前部署提交为准。
