# GET-375 阅读旁注与返回响应

来源：用户截图与 [GET-375](https://linear.app/getyak/issue/GET-375)。样本均为隔离合成书和对话，没有读取用户《剑来》原件，没有新增付费模型任务。

## 实现

书内对话使用可上拉展开的半屏旁注，正文保留在背后。问题去掉整块灰底，摘录与历史消息引用分别显示；没有摘录时不显示绑定状态。阅读回复时输入收为“继续问…”，草稿、语音和错误恢复保持完整输入，生成中保留停止按钮。

用户消息和已完成回复的原生文字菜单提供引用、点赞/取消点赞、复制消息，同时保留系统选词操作。消息引用随草稿和已发消息保存；服务端按当前账号、会话和书籍版本查找原消息，不采用客户端传来的预览文字。点赞保存在该账号/书的本机对话草稿，尚未新增云端反馈服务。明确拒绝发送时恢复引用，等待期间新选的引用优先保留。

新回复先直接回答，再用自然段解释，避免重复整段已展示的文字。保留按需解释与来源，不裁剪历史回答，不增加聊天字数或工具预算。真实模型输出风格尚未实测。

进度移出左侧功能栏，按原文字符位置估算全书百分比，PDF 按实际页序计算。索引离开主线程后一次建立，兼容不等长章节与 Unicode 标量偏移。右下角短暂出现；显示工具时移到工具上方，选字与打开旁注时隐藏，保留常显偏好。

返回延迟的实际阻塞是阅读计时每次落盘重复解码整本索引，以及旧状态快照积压。计时改用既有可失效缓存；正在写入的快照保留，尚未开始的旧快照由最新完整状态承接。返回并行等待时间和状态保存，有保存反馈、防重复点击和失败留页恢复。

## 验证记录

- LeafhourCore 完整测试：347 项，0 失败，2 项因未提供用户本地样本跳过。包括慢写、失败重试、索引替换和 manifest 变更。
- 15 MB、32,000 段合成索引：独立运行的五次计时保存由约 0.506 秒降至 0.0234 秒；同时写入压力下的一百次编辑由 102 次实际写入降至 2 次，最新草稿与位置保留。这是本机保存链测量，不是 iPhone 返回首帧测量。
- Node 全量初跑：4,621 项，4,602 通过、4 失败、1 取消、14 跳过。原因分别是资源争用下的请求/进程超时，以及源码快照遗漏当时尚未跟踪的新模块；解析函数随后收回现有模块。受影响聊天与失败文件低并发复验 164/164，发布快照 6/6；PDF 打包检查在资源恢复后单独通过，未修改超时。
- 原生 app tests：49/49。明确拒绝发送后的引用恢复已由红转绿，并覆盖等待期间选择新引用的情况。
- 模拟器已通过半屏尺寸断言、书内提问与回复、输入收起、继续输入、返回原位置，以及独立的大字号键盘/移除摘录、安静翻页与全局 Markdown 输入验收。长按引用、继续追问、保存引用、点赞/取消点赞及输入唤醒的完整流程也已通过。
- 网页构建与公开产物检查通过，检查 740 个产物；文案导出与 lint 通过。CI 和发布回执在交付时补记。
