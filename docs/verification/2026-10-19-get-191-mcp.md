# GET-191 — MCP guide reading surface

The four MCP guides now share the privacy page's paper/night colors, header,
serif heading hierarchy, body measure and footer. A small MCP-only stylesheet
keeps technical tables and command examples readable without rewriting them.

## Actual browser acceptance

Native Chrome Guest was operated through macOS accessibility and keyboard input.
The anonymous local service had all product generation providers disabled. The
browser observer recorded geometry and focus only; it did not drive the UI.

- All four MCP/privacy language pairs were visited at actual CSS widths 1200,
  700 and 390 pixels: 24 states. Each document's scroll width equalled its width.
- All eight pages were also visited at 390 pixels in explicit night and in fixed
  paper with dark system media: 16 more states. Fixed paper stayed paper.
- MCP navigation stayed visible at all three widths, including 700 pixels.
  Its navigation links had at least 44px height. The pre-existing privacy-page
  navigation is hidden at 700px; that shared navigation issue belongs to GET-189.
- At 390px, the English table region was 340px wide with 580px of content;
  native Right keys moved it 120px. The code region was 340px wide with 428px
  of content and moved 80px. Visible focus rings remained inside the page.
  Tab left the table for the repository link and left the code for Privacy.
- The original code retained its whitespace and line breaks. Table headers
  retained their scope attributes and use the quieter shared typography.

These are desktop responsive-browser observations, not physical touch-device or
Android acceptance. Early system-night captures with interrupted navigation were
excluded; the explicit-night observations and images are the acceptance evidence.
Transient intermediate dimension-entry values are likewise excluded.
