# GET-224：双语跟随与安静的缺译段

关联任务：https://linear.app/getyak/issue/GET-224

## 行为

- 新的双语偏好默认按段落上下显示原文和已有译文。已明确保存的并排偏好继续有效。
- 没有所选译法的内容只显示可选择的原文，不借用另一种译法，也不显示缺译占位句。空白草稿同样处理。
- 并排模式中的未译原文跨列居中，最大宽度 650px；中点和星号分隔符使用紧凑排版。
- 试读边界沿用现有唯一段落 ID，只插入一次；英文模式隐藏这条说明。
- 移除已无渲染入口的占位样式，继续满足原有 CSS 资源上限。
