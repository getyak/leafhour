# 阅读场景动效与声音联动验收

2026-10-15。按用户新增要求改进现有阅读氛围：选择场景即开启配套声音，背景呈现场景自己的运动。沿用现有本地照片、环境录音和合成配乐，没有调用生成模型或新增媒体服务。

## 行为

林间书页有缓慢光影与树影摆动；雨窗夜读有循环下落的细小雨丝；木屋炉火有柔和暖光变化；海边清晨使用局部水面缓移与反光。面板预览使用相同动效，正文纸面保持不透明。夜读继续支持动效；关闭动效或系统开启减少动态效果后停止动画，系统偏好实时生效。后台暂停动画，关闭面板后预览动画暂停，书页背景仍可继续。

主动选择场景即开始对应的轻音乐与环境声，包括此前已经暂停声音的情况。切换场景会切换音景，“只留纸面”停止声音。两路音量独立，零音量选择保持；动效开关不改变声音播放。刷新只恢复主题和偏好，保持静音。后台暂停声音，返回后仍需主动恢复。

## 真实验证

- `npm run verify:deploy`：465 项通过，0 失败，1 项因运行平台跳过；跳过项为 `a modified Node license is rejected even when the executable matches the pinned official binary`。隔离阅读运行时构建并初始化成功，未发起模型请求；静态构建、公开资源检查和发布清单检查成功。
- 新增 4 项控制器回归测试，修改前均因缺少联动行为而失败，修改后通过。覆盖主动选景自动播放、刷新静音与单路静音保持、加载期间取消、后台及系统低动态切换。现有竞态、失败重试和朗读压低检查继续通过。
- 隔离本机服务中的真实 Chromium 页面，使用匿名公版《爱丽丝梦游仙境》。四种场景均通过点击进入 `playing`，音乐及环境声名称匹配，书页与面板具有对应动画。动效关闭后照片和天气层的动画名称均为 `none`，声音仍为 `playing`；顶栏暂停声音后，照片和水面动画继续。
- 系统低动态模拟后，控制器状态为关闭动效，开关禁用且给出跟随系统的说明，照片与天气动画均为 `none`；恢复后动效恢复。夜读背景两层动画继续运行，正文颜色为 `rgb(228,229,220)`，纸面为 `rgb(24,27,25)`。
- 在实际页面宽度 320、390、768、1440px 检查：页面和氛围面板均无横向溢出。截图与结构化结果保存在本机忽略目录 `local/atmosphere-motion-qa/`。
- 两次动态采样中，照片与水面层的变换矩阵均不同，前三个可见段落的顶部坐标始终分别为 116.046875、158.7421875、373.8359375px。刷新后场景仍为海边，播放状态回到暂停。应用没有报告错误或警告。
- 独立代码复查完成，没有未解决的阻塞问题。复查中发现的雨层位移裁切风险已用完整雨纹高度的纵向扩展修正。

## 验证边界

动效由照片分层、雨丝与光影组成，不是实拍循环视频。验证覆盖应用行为与实际视觉布局，没有声称已完成人群长期舒适度测试或真实 iPhone 验收。后台行为由隔离控制器测试覆盖，本轮没有将内置浏览器的标签切换当成物理设备后台事件证明。

本次验收使用临时服务与公版目录，不写入真实书房，不读取其他用户数据。声音与动效偏好仍只保存在当前浏览器。远程检查、合并与生产发布以 PR 和生产流程状态为准。
