# 壁炉火焰运动验收

2026-10-16。修复用户反馈的“炉火没有动”：此前只有静态照片缩放和低幅度暖光变化，火焰没有运动。

## 实现

以照片中左侧炭堆与右侧木柴为固定燃烧位置，加入向上流动、轮廓不断变化的透明火焰层。壁炉照片保持固定，正文纸面继续遮挡背景。火焰在本机以小尺寸画布每秒最多绘制 20 帧，不下载视频，不调用模型。窄预览改为对准右侧木柴，照片和火焰始终使用相同裁切位置。

只在壁炉场景、页面可见且允许动效时绘制。关闭动效、系统减少动态效果、切换其他场景、页面隐藏或离开时取消绘制；预览合上后停止预览绘制，书页背景继续。恢复页面和系统偏好后可恢复运动。设备无画布上下文时保留照片。声音仍由既有独立控制器管理。

## 验证

- 新增三项渲染回归测试，修改前因缺少火焰实现而失败，修改后通过。覆盖燃烧像素的时间变化与位置约束、暂停释放帧循环及恢复复用画布、无画布能力时的回退。
- 完整发布检查通过：660 项测试中 659 通过、0 失败、1 项按平台跳过。跳过项为已有的修改 Node 许可证检查；隔离阅读运行时构建初始化、托管页面构建、公开资源与发布清单检查全部成功。
- 最终氛围与火焰相关检查共 17 项通过；另增控制器集成检查，覆盖预览、场景、用户与系统动效偏好、隐藏状态、页面离开和返回。独立只读审阅未发现阻塞问题；真实画布由以下浏览器实测补足。
- 真实 Chromium 阅读页与打开的预览在 650 毫秒间隔内各有 13,190 个颜色或透明度分量变化。三个真实正文段落的顶部坐标保持为 250.046875、292.7421875、507.8359375px。
- 通过真实控件检查动效开关、系统减少动态效果及恢复、切换场景、关闭预览、夜读纸面。关闭时连续读取像素保持相同，预览关闭后仅书页背景继续绘制。16 项页面检查通过，无应用错误。
- 在 320、390、768、1728px 宽度检查面板和正文，无横向溢出。照片与火焰的裁切位置分别匹配为 78% 47%（手机）与 78% 50%（桌面）。截图已人工查看。

## 边界

这是照片与程序火焰叠加，没有替换成实拍循环视频。验证使用匿名公版《爱丽丝梦游仙境》和临时书房服务，不写真实账号数据，不访问其他用户书房。未进行真实 iPhone 验收或长期设备能耗测试。真实后台切换尝试中，自动化浏览器始终返回 document.hidden=false，因此没有将该尝试记为后台通过；后台暂停由真实控制器的隐藏状态测试和渲染器取消帧测试覆盖。浏览器读取画布用于验收会产生性能提示，这不是应用运行错误。
