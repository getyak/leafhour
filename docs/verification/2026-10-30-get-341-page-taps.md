# GET-341 iOS page taps and reading space

[Linear GET-341](https://linear.app/getyak/issue/GET-341/ios-左右翻页优化).

## Change

Paged text and PDF accept short taps in the left/right 30% of the body for previous/next navigation. The center and the top/bottom 44pt strips keep the existing reading-tool disclosure. Continuous scrolling keeps its tap behavior. Text uses the existing source-anchored page coordinator; PDF uses native PDFKit page navigation. Native multiple taps, selection, Copy, links and long press retain priority; in-flight restoration blocks page requests.

The reader measures its real header and dock, adds an 8pt gap and a 52pt minimum inside the existing safe area. It no longer imposes a portrait 100pt dock floor followed by 24pt padding. At 402×780 hosting geometry with real UIKit large text, the measured top/bottom insets are 52/94.33pt versus 64/124pt before: 41.67pt less reservation, with 14 complete source lines. Insets remain stable during chrome disclosure; real type/viewport changes still remeasure. No reading-data migration or provider call is included.
