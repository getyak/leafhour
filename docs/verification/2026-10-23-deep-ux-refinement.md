# Leafhour 真实账户全链路体验审查与精修

本轮从已登录书房出发，通过 Browser Use 和 Computer Use 检查真实页面、操作结果、键盘焦点与窄屏形态，再由独立实现代理处理书房、阅读器和账单展示。所有观察与截图均来自本轮；旧验证文档只用于了解已有约定。

## 实测发现与改进

| 场景 | 实际观察 | 本轮处理 |
| --- | --- | --- |
| 首页进入书房 | “我的书房”实际先打开账号设置，读者需要关闭弹窗才能看书 | 书房入口直接到达书房，账号资料保留独立入口 |
| 返回书房 | 自动应用的主题与阅读形态筛选把 39 本缩至 12 本，最近阅读卡消失；清除后恢复，重新进入又自动施加 | 偏好只决定新书默认值，不再自动写书架筛选；显式链接、手动选择和浏览历史继续有效 |
| Aa 阅读设置 | 手机首屏被目标、语言与长解释占据，字号在很后面 | 字号、字体、纸面前移；目标与起始语言默认折叠，展示方式仍直接可调 |
| 批注开关 | 浮动标签盖住返回书房；单纯下移还会盖手机正文 | 唯一开关进入现有阅读工具组，保留显示选择、读取状态与重试 |
| 计时卡 | 状态被两个按钮挤成极窄文字列 | 状态与时间独占一排，动作在下一排 |
| 账号资料 | 页头、标题下与邮箱下重复说明记录归属，底部动作容易被挤出 | 删除重复说明，保留准确的本机／云端区别及操作状态 |
| 搜索焦点 | 完整搜索框和内部输入框同时出现焦点轮廓 | 只由完整输入区域呈现共享焦点样式 |
| 搜索无结果 | 搜索不匹配时仍只建议换阅读语言，未解释搜索词 | 搜索词存在时优先提示书名、作者与筛选条件 |
| 习惯页 | 托管阅读隐藏旧开关，却留下孤立说明及分隔 | 隐藏整组已失去操作对象的旧功能，本机独立模式继续保留 |
| 账单错误 | 页面显示读取失败，同时宣称没有订单、没有点数分录 | 为历史读取增加独立状态；仅成功空数组显示空记录，失败和未查询保持未知；缺失数组拒绝为无效响应 |

读取账单失败不能证明支付配置的实际状态。合法的 `enabled:false` 仍表示支付未开放；缺失、失败或未核验的 catalog 不再被解释为关闭，更不会开放结账。没有调整生产支付配置、后端账本、发放或扣点规则。

## 元观察与修饰规则

1. 页面上的承诺应对应下一步：“我的书房”不应把读者带进账号管理，找不到书也不应先要求理解隐式偏好。
2. 当前页面的操作与未来默认值是两层状态。字号、纸面、展示方式服务此刻阅读；目标、起始语言与新书偏好无需每次占据首屏。
3. 普通解释出现一次即可。信任所需的来源、译文草稿、费用、保存失败和授权范围仍在实际决策处出现。
4. 安静来自合理分组，不来自隐藏错误或挤小控件。未知与空、个人想法与 AI 内容、原文与译文仍有明确区别。
5. 截图中的疑似问题需要测量与行为复核。例如窄屏声音说明一度看似越界，实际宽度与滚动宽度均为 307px，未据此误改。

完整规则见 [界面修饰指南](../ux-craft-guidelines.md)。

## 当前覆盖与证据边界

| 步骤 | 本轮实际操作 | 健康度与验收范围 |
| --- | --- | --- |
| 1 | 已登录首页进入书房 | 确认多余账号弹窗，进入路径已纳入修复 |
| 2 | 书架筛选、清除、重新进入 | 确认自动筛选反复出现；手动清除可恢复续读 |
| 3 | 搜索无结果与清除 | 确认空态建议不匹配；恢复入口可用 |
| 4 | 手机筛选面板与 Escape | 面板可用；关闭后焦点回到筛选入口 |
| 5 | 账号、阅读偏好、外观 | 确认说明重复；没有提交账号或偏好变更 |
| 6 | 数据恢复初态 | 没有文件时恢复动作禁用；未执行真实恢复 |
| 7 | 续读、工具展开、Aa | 真实阅读可用；设置层级和导航遮挡已纳入修复 |
| 8 | Read／Sound／Habits 与键盘页签 | 已实测方向键和 Home；声音初态可见，未生成或购买音频 |
| 9 | 段落操作与个人想法面板 | 空输入保存禁用；关闭后焦点回到对应原句，未保存新记录 |
| 10 | 手机导航与带书弹窗 | 文件限制和取消可见；关闭后回到可见导航入口，未上传真实文件 |
| 11 | 已登录账单与失败初态 | 确认伪空记录；后端真实支付和账本修复不在本轮结论内 |

桌面基线为 1440×1000，手机基线为 390×844；平板与修改后的真实浏览器回归在交付记录中分别登记。原生产手机字号控件顶部为 1843px，本机同尺寸修改后为 214px；后者属于隔离本机页面证据，不能冒充已发布同账号验收。

截图可能包含私人书籍、个人记录或账号资料，只保存在本机 `output/ux-deep-audit-2026-10-23/`，通过本机 Git exclude 排除，不进入公开仓库、部署包或 PR。公开记录仅保留去身份化的观察与验证结论。没有清除书籍、个人记录或历史测试数据。
