## 已核对的跨模块边界

- 书架以账号 ID 判断作用域，同账号邮箱资料变化保留书房；共享刷新任务等待正在执行的请求与显式复查，快照发布阻止较早缓存覆盖网络回执。上传在取源记录前同时保留源书与目标书身份，阅读中延后迁移并复用已保存上传回执。
- 前导生成在正文路径之外异步进行，开篇材料有段数、字符和编码容量界限；服务缓存及引用解析包含账号、来源、书籍、原文版本和语言。赞助额度与普通聊天点数分开。导览引用在独立 AI 字段中保存，用户 `text` 保持问题原话，历史和 portable 路径保留该归属。
- 随读翻译只在显式开启后处理冻结窗口；导航开始即撤销旧代次，排版变化不会提供新导航授权。关闭、后台和离开停止后续提交。设备持久保存原请求、报价与恢复位置；服务将取消传给供应商，并以保存前检查和可信回执处理提交边界的不确定结果。
- 目录 AI 搜索使用独立 worker 和草稿命名空间，只读被冻结的当前书快照；来源同时核对书籍、版本、章节、段落、原文与偏移。恢复展示原问题，停止状态未确认时保留原请求，不能直接建立第二次搜索。
- 书签与笔记分开保存。译文展示位置使用自己的 UTF-16 偏移、译法、语言和完整译文指纹，保留独立原文锚点；变化或缺失时拒绝猜测跳转。新旧语言默认由版本标记区分，缺少 state 文件与修复路径保留旧规则。对照参数接入实际文字渲染及 Markdown 映射。
