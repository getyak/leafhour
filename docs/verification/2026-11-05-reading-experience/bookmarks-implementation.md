# R9/R10 书签实现记录

日期：2026-11-05。实现范围为此设备的书签，不包含云同步。独立设计见 `bookmarks-design.md`。本记录由书签实施 Agent 编写。主执行负责统一构建与设备验收。

## 已实现

新增 `ReaderBookmark` 与可选 `ReaderState.bookmarks`，书签与私人笔记分开。颜色保存不透明 sRGB 六位代码及名称，允许自定义颜色和可选书签名称。原文版本与云内容版本分别保存。文字按源段落与 Unicode scalar 偏移定位，PDF 保留 pageY，插图保留 resourceY。规范化位置去重，重复添加保留原色和名称。版本变化保留旧书签并拒绝跳转。

`ReaderSession` 新增增改删、位置查询、可见范围查询和跳转接口。保存反馈依赖原有持久化 receipt。失败不会返回成功。未保存项可重试，失败移除恢复显示，不覆盖同时写入的其他记录。`isBookmarkPersisted` 区分待保存项。存储沿用当前账号或设备书房目录，并校验来源和锚点。

新增原生颜色配置与本书列表面板，每个操作区域至少 44pt。App 适配通过可选回调与阅读界面连接。paged 使用独立纵向 pan。scroll 只观察真实顶部开始的原生 overscroll。72pt 进入松手添加，56pt 以下回撤，取消或失败不提交。VoiceOver 走显式按钮及可访问性动作。上一屏、下一屏动作继续保留。

TextKit 回报段内源字符范围，PDF 回报实际页内坐标范围，插图回报资源比例范围。长原文段落不能因 passageID 相同就让所有分页都显示同一书签。BookDetail 导出文案补充书签，完整 ReaderState 随原有 records 导出。

App 新增 3 项测试，检查独立 pan 与可访问性动作、长原文段落的真实范围、扫描 PDF 的页内几何。所有本次 Swift 文件已通过 `swiftc -frontend -parse`，本次差异通过 `git diff --check`。语法检查不代表 Xcode 构建、App 测试或真机通过。

按设计的功能30、交互25、性能25、边界20分别记录 R9/R10。当前仅根据源代码检查与部分 Core 测试，不给产品已验收分数。已核实的自动化范围按上述证据记录，产品验收记 0/100，待验上限100。性能、真实手势误触率、VoiceOver、动态字号、减少动态与真机均未验收，不补写95分。

## 边界

- 书签保存在此设备。服务和网页版完整备份没有新增书签通道。没有宣称云同步。
- 新隔离库恢复测试使用完整 ReaderState 编解码并保存，未新增 native records 导入 UI，也未声称用户迁移已验收。
- 现有译文段落的 `sourceOffset` 始终映射原文段首。译文页中部添加书签会保存对应原文段首，没有生成虚假的字符对齐。译文内精确字符恢复仍需独立设计。
- 书签手势在 PDF 放大时关闭。显式按钮仍可使用阅读器已有的可见位置记录。
- TextReadingView 与 PDFReadingView 已交回主执行，书签适配与后续翻译/搜索整合由其统一提交。Models、ReaderScreen、目录面板和 Xcode 工程由其他负责人整合。
