# Leafhour iOS：持续打磨

用户在 2026-10-27 授权持续优化交互动效、视觉与相关功能，截止为当日 12:00 Asia/Singapore。沿用已选择的原生阅读与半屏陪读方向；原方案和证据保留在 `../2026-10-26-ios-half-sheet/`。

本轮先处理两个可直接观察的问题。面板拖动使用可打断、继承释放速度的稳定弹簧，遮罩随面板连续变化；拖拽区达到 44 px，按下即反馈，取消手势不会意外关闭。选文工具跟随真实选区，避开导航和底部工具，收起后清除临时选择反馈。正文、讨论和出处的位置与归属契约保持原方案。

考虑了只加装饰动效、替换整个阅读结构、精修现有交互三个路径。选择精修现有交互，因为它能让进入、操作、返回更连贯，也能通过输入事件和实际画面核对。颜色和排版仍使用 Leafhour 的清纸、墨绿和正文宋体。按钮只做短促按压反馈，长文没有持续播放的装饰动画。

本轮仍是固定公版样章的设计原型，不调用模型、不写真实书房。原文、直译、意译、讲解、用户笔记独立归属。减少动态关闭弹性位移；减少透明度与高对比度使用实体承载面。所有手势保留按钮替代。

验证分三层：纯计算测试检查帧间隔差异、释放与回弹、边界；真实浏览器检查拖拽反向/取消、半屏正文继续阅读、选区定位与碰撞、草稿/出处回程；截图检查清纸、夜读、窄屏和大字。Figma 同步另读回，不将 Web 的检查写成原生 iPhone 验收。
