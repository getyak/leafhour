## 隔离方式

浏览器使用合成身份 `conditional@example.invalid`。所有非 GET 请求均由浏览器路由接管，没有向运行服务写入资料、书籍、记录、赠书或授权。公版目录、开篇和原文只作匿名 GET；合成身份不带到真实公版请求。资料保存、排序、归档、恢复、上传、赠书创建、撤回与接收的成功及错误均为明确标记的隔离响应。

下载的日程和阅读包交给了真实浏览器保存。日程没有导入系统日历；阅读包下载不等于在另一实例恢复；没有发送邮件、生成模型回答、生成语音，也没有创建可在真实服务使用的赠书链接。赠书 token 固定为 43 个 A 或 B，只属于隔离界面。

## 本轮修复的实际问题

有效头像在本机被 CSP 的 `img-src` 拒绝。已只允许图片使用 `blob:`，没有扩大脚本执行来源；真实 HTTP 头回归先失败后通过，PNG 已在浏览器成功预览。

重试按钮消失、控件忙碌禁用或整块内容重绘时，原焦点会落到 BODY。新增独立的 `action-focus.mjs` 跟踪操作：等待期间用户主动移到别处便放弃恢复；仅在仍属于原操作时回到新重试按钮、同书手柄、阅读正文或成功结果。它用于本轮确认的恢复路径，相关回归包含“不抢走其他编辑控件焦点”。

赠书历史打开、收回、保留及译文复选热区不足；赠书页品牌与页脚返回动作不足；读页动态重试、术语和来源折叠不足。已按具体动作扩大到 44px，正文内联链接保持自然排版。

深读提示的叉号、Esc、外点和“回到阅读”原来计时恢复语义不同。现统一只恢复打开前正在阅读的状态；原本暂停、后台及冻结状态不被主动恢复。

正式书籍的阅读体验导入接口尚未接入。设置中隐藏整组不可用的体验备份入口，仅在原有兼容体验包可用的路径展示。当前没有书名/作者等元数据编辑入口；资料编辑与赠书信文字编辑不被冒称为书籍元数据编辑。

封面原生拖拽被标准的 `pointercancel` 交接事件提前清空，导致后续拖过不接受 drop。已仅让匹配指针的手柄取消重置状态，原生拖拽仍由 drop/dragend 收尾。前后真实事件序列分别保留；新增回归验证原生交接与手柄取消两种行为。
