# 书房、设置与阅读对话验收

2026-10-15。范围见 [_briefs/reading-room-renewal.md](../_briefs/reading-room-renewal.md)。本次实际应用已替换原书房布局，设计稿不是运行验收依据。

## 交互验收

在隔离本机服务中走过 1280px 桌面、820px 平板及 390/320px 窄屏。实际浏览器确认侧栏收起后刷新保持、图标具有可读名称、手机抽屉关闭与设置返回焦点、夜色即时切换与刷新保持。官网首页没有书房收起按钮，导航不再引向已移除的数据面板。

已登录时，正在读的书只出现一次，预览使用真实单段，原文与意译可切换并标出 AI 草稿。搜索覆盖在读书与书架，未匹配时可清空；没有上传书时给出上传或登录入口。阅读目标实际保存，日历可跨月查看问题并回到原文。退出后，私人书籍与对话从页面清除，设置保留明确反馈。

上传检查了错误扩展名、重新选择、按钮禁用、有效 TXT 导入和打开真实阅读页。测试文件只进入隔离临时目录。上传选择区域支持回车和空格；上传期间关闭窗口可继续浏览，完成后更新书架。

对话检查了访客登录、登录后返回对话、书籍间草稿、关闭重开、发送、停止、刷新恢复、回答归属、原文引用及导出。隔离服务使用明确标注的测试生成器；导出 JSON 包含三次提问、独立 AI 回答与取消状态。发送中刷新后找回同一次请求，完成后清除对应草稿，未重新发送。

## 真实模型验证

单独使用官方 DeepSeek Harness，对公版《爱丽丝梦游仙境》的 `01b38ea4c710a84b-p00008` 提出一个阅读问题。结果为 completed，回答单独标记为 AI，四处引用均是允许原文的精确子串。运行回执为 `deepseek-official` / `official-deepseek-harness`，共三次有界模型请求；费用预留约 0.059354 元，低于单次 0.10 元上限。预留值不是供应商结算金额。

该验证使用临时个人记录和公版上下文，没有向真实账号写入测试书，也没有全书生成。它证明本机真实模型链路；正式站点的发布与回答必须另行确认。

## 云端运行环境差异

正式站点的实际默认测试账号可完成身份与当前公版段落读取，但首次问答在约 1.3 秒返回失败。安全诊断确认位于官方 SDK 初始化阶段，运行包与客户端入口存在，尚未发送模型请求。预览环境只构建代码，没有生产账户和模型凭据，不能用于真实问答验收。

在官方 AWS Lambda Node 24 镜像（SHA256 `9a096eb2cb6fa96419b5742e1b4a64b6bf7d3aa954beb92461a2a3e072061497`）中，真实 Node 24.21.0 和锁定的 `node-addon-require-builtin@0.1.9` 可复现 `Unsupported/no-getter`；Node 22.23.3 的 AWS 镜像亦失败。原生绑定不能识别这两种发行构建的 getter 机器码，因此仅修改 Node 主版本无修复依据。SDK 载入自定义 profile 的包解析服务会首先调用该接口；通用的“host preparation”标签不能证明沙箱故障。

同一 AWS 容器改用官方 Node 22.23.3 后，五个内部模块 getter 与真实 Harness 启动、关闭均通过；检查了子进程实际回收，全程断网、假密钥、零模型请求。`node-linux-x64@22.23.3` 的运行文件和许可证与 nodejs.org 校验过的发行包逐字节一致：二进制 SHA256 `fde6a4bf8d0562f7751d1a2d6cb9b417c4cfe107bbcb0aa3e9a24e125e348f48`，许可证 SHA256 `c738ae413cf561f174e34f6961f8ca458aae2369a73640dda6234c629b98bcc4`。发布包只携带二者，不复制开发头文件。

托管启动入口使用 SDK 公开的 `dshBin` 选项，在同一子进程中 `execve` 到已校验的官方运行文件。PID、标准输入输出、EOF 和取消路径保持一致；不创建代理子进程，不禁用沙箱，不扩大模型工具权限。CI 现在会在上述固定 AWS 镜像中再次执行实际隔离启动和关闭。
