# 书房、设置与阅读对话验收

2026-10-15。范围见 [_briefs/reading-room-renewal.md](../_briefs/reading-room-renewal.md)。本次实际应用已替换原书房布局，设计稿不是运行验收依据。

## 交互验收

在隔离本机服务中走过 1280px 桌面、820px 平板及 390/320px 窄屏。实际浏览器确认侧栏收起后刷新保持、图标具有可读名称、手机抽屉关闭与设置返回焦点、夜色即时切换与刷新保持。官网首页没有书房收起按钮，导航不再引向已移除的数据面板。

已登录时，正在读的书只出现一次，预览使用真实单段，原文与意译可切换并标出 AI 草稿。搜索覆盖在读书与书架，未匹配时可清空；没有上传书时给出上传或登录入口。阅读目标实际保存，日历可跨月查看问题并回到原文。退出后，私人书籍与对话从页面清除，设置保留明确反馈。

上传检查了错误扩展名、重新选择、按钮禁用、有效 TXT 导入和打开真实阅读页。测试文件只进入隔离临时目录。上传选择区域支持回车和空格；上传期间关闭窗口可继续浏览，完成后更新书架。

对话检查了访客登录、登录后返回对话、书籍间草稿、关闭重开、发送、停止、刷新恢复、回答归属、原文引用及导出。隔离服务使用明确标注的测试生成器；导出 JSON 包含三次提问、独立 AI 回答与取消状态。发送中刷新后找回同一次请求，完成后清除对应草稿，未重新发送。

## 自动验证

`npm run verify:deploy`：419/419 测试通过，网页构建、公开资源检查、239 项软件发布白名单与源提交检查均通过。专项覆盖账号与书隔离、单段预览边界、稳定 ID、原文版本变化、幂等发送、并发进程、共享存储比较写入、取消后的迟到结果、刷新恢复与较新草稿保留。

全局模型门槛为同时两项、每小时一百项、每天五百项，账号每小时十项；同书一个运行中的请求。跨实例取消通过共享状态通知，测试中的中断信号约半秒到达。正常完成会清理监视定时器并释放自己的租约。超时租约可恢复，失败请求仍计入次数。

官方最小运行器按构建平台提取真实依赖，当前生成 926 个文件、约 9 MB；构建器用假密钥在隔离目录启动真实 SDK 子进程后关闭，没有发送模型请求。输出目录保护会拒绝覆盖已有非运行器目录。Node 22.22.0 与本机 Node 26 的完整测试均通过。Linux 的原生依赖由 CI 安装并重新构建，不能复用本机成品。

## 真实模型验证

单独使用官方 DeepSeek Harness，对公版《爱丽丝梦游仙境》的 `01b38ea4c710a84b-p00008` 提出一个阅读问题。结果为 completed，回答单独标记为 AI，四处引用均是允许原文的精确子串。运行回执为 `deepseek-official` / `official-deepseek-harness`，共三次有界模型请求；费用预留约 0.059354 元，低于单次 0.10 元上限。预留值不是供应商结算金额。

该验证使用临时个人记录和公版上下文，没有向真实账号写入测试书，也没有全书生成。它证明本机真实模型链路；正式站点的发布与回答必须另行确认。
