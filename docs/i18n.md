# Website and repository languages

Updated 2026-10-17. The public website and the GitHub repository support English (default), Simplified Chinese, Traditional Chinese and Japanese. The reading room and reader application remain primarily Simplified Chinese; this document covers the official website, its public documents, and the repository front matter.

## Languages

| Language | HTML `lang` | Website route prefix | Repository files |
| --- | --- | --- | --- |
| English (default) | `en` | `/`, `/mcp`, `/privacy` | `README.md`, `SECURITY.md` |
| Simplified Chinese | `zh-Hans` | `/zh-hans` | `README.zh-CN.md`, `SECURITY.zh-CN.md` |
| Traditional Chinese | `zh-Hant` | `/zh-hant` | `README.zh-Hant.md`, `SECURITY.zh-Hant.md` |
| Japanese | `ja` | `/ja` | `README.ja.md`, `SECURITY.ja.md` |

Every language has one URL per page. English is the default both at the website root and in the repository; `/en` and `/en/mcp` stay as aliases of the default English pages with canonical URLs pointing at `/` and `/mcp`. Each page declares `hreflang` alternates for all four languages plus `x-default` and offers a language switcher whose labels are endonyms (English, 简体中文, 繁體中文, 日本語), with `aria-current` on the current language. Repository files link each other in the same order at the top of the document.

## How the homepage is localized

`app/home.html` is the single authored homepage source, written in Simplified Chinese. `app/home-locale.mjs` holds one catalog row per presentation string — `[source, English, Traditional Chinese, Japanese]` — plus rows for sign-in service messages and rows for dynamic counts (`10 秒后重发`, `双译开篇 · N 段`, …). `homeDocument(source, locale)` renders any locale: it translates presentation strings in one pass, then fixes the `lang` attribute, canonical and `og:url` URLs, brand and guide links, the language switcher's `aria-current`, and the JSON-LD `WebPage` node. Both `server/portal-document.mjs` (local routes) and `tools/build-vercel.mjs` (hosted static build) use this renderer.

Rules for the catalog:

- One row per authored string; every row carries all three translations next to its source, and the completeness test fails on any missing column or duplicate key.
- The English rendering is tested to contain no source-language text outside the labeled Chinese sample quote and the switcher endonyms, so a new or edited homepage string cannot silently leak.
- The sample quote is product demonstration content and stays Chinese everywhere except the Traditional Chinese page, where it is shown in Traditional Chinese.
- Strings that come from books, accounts, APIs or model output are never added to the catalog; only authored presentation text belongs here.
- Runtime strings (sign-in dialog, book cards, appearance controls) go through `homeText(value, locale)` and `authErrorText(value, locale)` with the same catalog.

## How the public documents are localized

The MCP guide and the privacy notice are authored per language (`app/en/…`, `app/zh-hans/…`, `app/zh-hant/…`, `app/ja/…`) because they are long-form documents whose wording is reviewed per language. Each file carries its own canonical URL, `hreflang` set, JSON-LD, and language switcher. When one language changes, update the others in the same change.

## Hosted build

`tools/build-vercel.mjs` writes `index.html` (English default), the alias pages `en.html`/`en/index.html`, and `zh-hans`, `zh-hant`, `ja` homepages both as flat files and directory indexes (`zh-hans.html` + `zh-hans/index.html`, …) so static hosts resolve either form to the same localized page; it also writes unprefixed copies of the English guides at `mcp.html` and `privacy.html`, while the per-language guides and notices are copied from `app/`. `tools/verify-release.mjs` checks exactly these files, and `tools/smoke-release.mjs` checks every public route's canonical URL and language metadata against the table above.

## Adding a string

1. Edit `app/home.html` (or the runtime call site) with the Simplified Chinese source string.
2. Add one row to `strings` in `app/home-locale.mjs` with the English, Traditional Chinese and Japanese values.
3. Run `npm test`; the catalog completeness test and the no-leak test cover the change.
