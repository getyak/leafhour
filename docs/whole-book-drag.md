# 整本书调整顺序（GET-165）

桌面使用整张书卡的原生拖动，包括封面与标题区域。阅读链接和更多操作按钮保持各自用途。左上角拖动圆钮不再常驻；键盘聚焦原有调整位置按钮时，显示带文字的 44 px 控件，仍支持左右方向键与菜单移动。

触屏长按书卡 450 ms 后进入拖动。短按封面仍打开书；长按前移动超过 8 px 则保留原生滚动。拖动结束抑制同一手势的遗留点击，新的一次明确点按立即可用。笔输入沿用原生拖动与菜单，不将触屏长按结果外推为笔输入验收。

第二指无论落在书架、侧栏还是页面留白，都会取消待启动或正在运行的拖动，允许原生多指手势。Esc、取消、失焦、账号或筛选切换也会移除浮动封面、释放捕获并取消待执行回调。账号变化后的旧手势不能保存到下一账号。

排序始终使用完整 metadata 列表，包括渐进窗口之外的书；本次不修改排序 API 或保存格式。

隔离 Chromium 使用 33 本书（包含合成私人书籍，无真实账号数据，关闭模型适配器）。1440 px 验证从标题区域原生拖动、全部 33 个排序 ID、刷新后服务端顺序保持及键盘控件；390 px 使用 CDP 真实触屏事件验证短按跳转、正常滑动、长按移动、拖动不误开书、下一次点按立即可用，以及网格外第二指取消后多指移动未被阻止。
