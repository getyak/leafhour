# 林间光与海水动效（GET-163）

2026-10-18。用户反馈森林与海边两个阅读氛围“还是没有微微的动感，略有一些，希望有一下，灯光穿过森林和海浪”。本轮只让光影与水面动起来：照片和阅读相机保持不动，正文栏依旧不透明，文字排版、选择与输入不受影响。

## 设计

- 林间书页：柔和光柱缓慢呼吸、缓慢滑动，方向与照片右上方光源一致（向左下倾斜）；光柱之间是更暗、更慢的树冠阴影。呼吸周期 5–9 秒、滑动更慢，2–4 秒并排比较能看到明显变化，但不刺眼。
- 海边清晨：只在水平线以下的水面生成窄窄的波纹高光，轻微左右漂移、明暗起伏；水平线、天空和照片本身不动。
- 森林与海边不再做照片全局缩放漂移——动感属于光和水，不放大相机。雨窗夜读与木屋炉火的既有动效、四个主题配色、选择器、场景动效开关、本地偏好与声音生命周期均未改动。四张选择缩略图继续静止，让四个选择保持安静。
- 声音与视觉渲染完全分离：渲染器启用、切换或停止都不会启动、暂停或改写声音；恢复的场景依旧静音，只有显式选择才播放。

## 实现

`app/nature-motion.mjs` 是一个有界的自然动效模块，暴露 `setScene`/`setActive` 两个显式控制（沿用 `hearth-motion.mjs` 的生命周期模式）：

- 光柱、树冠阴影与波纹都是启动时一次算好的布局表加缓存渐变；每帧只做 `setTransform`/`fillRect` 级别的绘制，没有逐像素 CPU 扫描，也不在帧内分配数组或渐变。
- 输出固定 320×200 画布，帧率上限 20fps（距上一帧 ≥50ms 才绘制）；只运行当前场景与可见预览。停止条件：场景动效关闭、`prefers-reduced-motion`、页面隐藏、预览面板关闭、`pagehide`；恢复时复用同一画布，不重复建循环，非活动状态不留任何 RAF。

`app/reader-atmosphere.js` 把森林/海边与炉火放进同一套可见性、动效偏好与页面退出门控；`app/reader-atmosphere.css` 把森林/海边旧的“照片漂移 + 弱透明遮罩”换成光柱与窄波纹的 CSS 光影层。画布渲染器可用时（`.atmosphere-elements[data-nature-renderer=canvas]`）CSS 光影层自动隐藏，避免双重叠加；画布不支持、`getContext` 失败或上下文丢失时自动退回 CSS 光影层。这条退路是合成器 CSS 动画，不是 GPU 渲染，也不作此声明。渲染器从不采样照片像素，照片始终只是 CSS 背景：图片解码失败最多留下静止照片加光影，不会阻塞或拖垮渲染。

## 边界

- 这是叠加光照，不是真正的水体位移或折射；照片、缩略图与阅读相机保持静止是设计要求，不是缺陷。
- 画布与照片同为 cover 居中裁切，极端宽高比下水平线可能有几个百分点的偏差；波纹从水平线以下淡入，没有硬边可对齐。
- 测试断言绘制几何、透明度变化、稳定水平线、20fps 上限与循环释放，用记录型 context 代替 GPU，不等价于真机像素观感。真实浏览器像素/视觉/移动端/夜读/低动态验收由父任务负责。
- 待接入（不在本任务授权范围，未改动）：本机 `server/server.mjs` 的静态模块白名单需注册 `/nature-motion.mjs`（`hearth-motion.mjs` 同一数组补 `'nature-motion.mjs'`），否则本机开发入口会 404 该模块并使 `reader-atmosphere.js` 模块图加载失败；托管构建走 esbuild 打包，不受影响。`tests/atmosphere-assets.test.mjs` 的服务路径断言可同步补 `/nature-motion.mjs`。
