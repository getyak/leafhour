# 渐进显示书架（GET-166）

书房首次创建 12 张卡片，接近书架底部时每次追加 12 张。没有 IntersectionObserver 的浏览器仍可使用「继续显示」按钮；键盘触发按钮后，焦点进入新增的第一本书。自动追加不移动焦点，也不重建已经显示的卡片。

这是 DOM 渐进渲染。服务仍一次返回当前账号可见的完整书籍 metadata，搜索、筛选、总数和排序都使用完整列表。保存顺序时包含尚未显示的书籍 ID，不能把可见窗口误当作整座书架。

账号或筛选条件变化后重置为首批；普通刷新保持已展开的数量。键盘或菜单将当前书移到窗口之外时，窗口扩展到该书，保留操作焦点。旧账号的观察器与待执行帧失效，退出登录立即移除私人卡片。

阅读正文沿用现有的按章获取与本地排版。此改动不拆卸正文段落，避免影响选字、复制、引用定位及稳定段落 ID，也不改变 API 的网络分页方式。

## 本地验收

使用 200 本合成私人书籍与 30 本公版书，所有请求限制在隔离的本机服务，模型适配器关闭。390、768、1440 px 三种宽度的首屏卡片从 230 张降到 12 张，均无横向溢出或脚本错误。

三个宽度分别验证：搜索尚未显示的书、跨批次移动及完整 230 个排序 ID、滚动展示全部书且无遗漏/重复、保留原有卡片节点与搜索焦点。另在禁用 IntersectionObserver 的手机宽度验证键盘追加与退出登录后私人卡片消失。

新增自动化测试覆盖手动与自动追加、旧账号回调、筛选重置、完整顺序与锚点扩容、焦点行为，以及真实 HTTP 下模块的状态、MIME 和字节。独立审查未发现确认的 P0、P1 或 P2。完整 Node 套件 1148 项通过、1 项按平台条件跳过；508 文件发布清单与 202 文件公开构建检查通过。

本地证据不代表生产已发布。远程 CI、部署与正式环境验收在对应 PR 和 Linear 任务中继续记录；这些门禁完成前保持任务未完成。
