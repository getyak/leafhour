# 阅读时间的口径

阅读工具中的计时默认关闭。选择口径后明确点击开始，只有结束当前这次计时才能换口径。

| 来源 | 如何记录 | 停止计时的条件 |
|---|---|---|
| 主动专注 `reader_focus` | 允许在同一段停留思考，不要求滚动 | 隐藏、失焦、冻结、手动暂停或结束 |
| 前台估计 `reader_estimate` | 开启后估计阅读页的前台停留；2分钟无可信键盘、指针或滚动操作时截止 | 同上；闲置截止后，实际操作才从当时继续，操作不能解除手动暂停 |
| 手动补记（自报）`manual` | 自己填写已结束的开始/结束时间、设备时区与当前原文锚点 | 单个正区间，最长24小时，结束不能晚于服务端当前时间 |

手动补记不是设备测量。打开补记会暂停实时计时，关闭后由自己继续。日期输入使用设备本地时间，界面显示实际时刻与时区偏移；不存在的日期或夏令时时刻拒绝。重复的本地时刻采用设备选定的偏移，提交前可核对。未提交输入不保存；已提交但待确认的记录冻结原时间和标识，不能用修改后的输入覆盖。

本机队列先保留再向书房同步。丢应答、离线和刷新恢复均使用同一标识；只有匹配来源、实际区间与最终状态的回执才表示完成。若浏览器无法保存，时段仅在当前页面，可重试或“另存待同步时段”；失败状态不会冒充已经进入书房。

日历总时长合并全部书籍、设备和来源的实际区间，重叠只算一次。每种来源另按该来源的区间去重，各来源可能彼此重叠，不能直接相加。比如专注12:00–12:10、估计12:05–12:15、补记12:10–12:20，总时长20分钟，各来源分别10分钟。明细列出来源、记录时区、有效区间和原文位置，可返回核对。

运行时每秒观察，超过5秒的观察断档不补算，只保留最后一次已观察到的区间。每30秒尝试保存检查点，页面隐藏/失焦/结束时也尝试保留。设备强退不能保证触发关闭事件；恢复只使用已保留的检查点，可能缺少尚未保留的尾段，不推断中断期间仍在阅读。每次最多24小时/120个区间，达到边界会结束并提示新开一轮。

旧 `reader_focus` 保留原义。旧设计预览记录可随备份保留，但不计入正式时间。未知来源和 Agent 自己读取章节的时间不能写成用户阅读；Agent 的既有只读内容/活动权限不因此扩大。时长、个人评论、问题和自己确认的读完标记分别记录，时长不证明理解、掌握或学习成果。

三种来源随个人记录和完整书房备份保存；恢复使用相同书籍/版本/锚点/区间校验，坏包在写入前拒绝。手动补记同一标识必须是同一份内容，改变区间返回冲突并保留原记录。密钥和授权不进入记录包。
