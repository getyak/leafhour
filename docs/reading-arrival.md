# Book-aware arrival

GET-159 keeps the paper companion and immediate transition to readable content. The character gently looks down and turns a page; feet stay planted. Hidden pages and the existing reduced-motion preference pause or disable motion. The ending dialog's bookmark pose stays still.

All 30 current public books have source-bound excerpts. The 27 structured catalog openings are deterministically generated by `tools/build-arrival-catalog.mjs`; no translations are invented for them. The three existing translated excerpts retain their checked source/version/passage and AI-draft translation attribution. A book outside that public registry, including a private book no longer falls back to Alice. It starts with a quiet book-opening message, then uses only the same already-authorized reading response to show the actual title and a short original sentence (up to 160 characters, with word-boundary fallback) when available. No additional fetch, local storage, model call, generated translation or minimum loading delay is introduced. Missing original text stays absent instead of being filled with another book.

Updates are bound to the requested book and current arrival ticket; stale retries and completed loads cannot replace content. Original-only excerpts are labeled as original text, with the response's source language. Private excerpts stay in the current page memory and are never added to a public registry.

Verification includes source-bound excerpt tests, unknown-book and stale-ticket checks, real browser delayed/error/fast loads, motion versus reduced-motion, mobile/night layouts, and current-head CI. Run `node --test tests/reading-arrival.test.mjs` for the focused contract; the task delivery record records what actually ran.

Regenerate public source-bound excerpts with `node tools/build-arrival-catalog.mjs`, then verify `--check` and `node --test tests/arrival-catalog.test.mjs`. The check compares current source versions and passage IDs with the actual catalog service.

The generator uses audited paragraph IDs for seven editions whose reading start contains a heading, byline, date or numbered prefix. These select actual reading text without changing the book's reading start; an edition change that removes the audited paragraph fails generation. Regression assertions cover those openings as well as source identity.
