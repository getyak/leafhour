# Public boundary review

Scope: all 102 selected UTF-8 Git blobs, 3,529,412 bytes, before copying as byte-identical reference text. The selection uses explicit product/test/build source roots and checks all changed path metadata for omitted source candidates. `deploy/hosted-auth.mjs` was additionally checked and already exists in public main history, so it does not require a new text object.

Every selected byte was scanned for private keys, common GitHub/provider/cloud token formats, JWTs, credential-shaped literals, email addresses, UUIDs, host-specific home paths and private-fixture/account markers. No private-key/provider-token/JWT/UUID/home-path match was found. No actual account address, machine configuration, user book payload or personal record was identified. The source objects are unchanged; no masking or fabricated replacements were applied.

Eight blobs produced email or credential-literal matches and were manually inspected in context. Addresses use reserved example domains and HTML placeholders. URL credentials are a negative safe-URL test. Cookie/Authorization strings compose synthetic in-memory or temporary local test sessions. The MCP fixture imports `auth-fixture.mjs` and `reading-fixtures.mjs`; their inspected definitions use a mocked provider, in-memory rows, reserved example hosts, synthetic IDs and short authored test paragraphs. They do not read real accounts. The audio transport fixture creates its own temporary source and disables providers. Profile fixtures use literal synthetic display names and reserved example addresses. Additional private/owner/source markers in test fixtures and UI catalogs were reviewed as test data or UI/source code, rather than user content.

The scan is supporting evidence with a manual boundary review, not a guarantee about arbitrary secrets. No real private material was found among the selected 102 blobs, so `privacy_exclusions` is empty. User resources, runtime evidence, environment files and machine configuration were never selected or copied. This review does not authorize executing the historical source or its tests.

Validation: unique object/path mapping; Git blob identity; SHA-256 and byte counts; all eight tip inventories; UTF-8/no-NUL; no symlinks, executable copies or runtime-root edits. No dependency install, application/native build, provider/model call, browser/simulator probe or diagnostic grant was run.
