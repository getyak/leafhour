# Web 交互盘点与改进契约

循页已有完整的阅读辅助工具，当前需要收敛的是入口层级、状态反馈与浮层规则。正文应始终比工具醒目；边框只承担输入、选中、焦点或浮层边界，不能给每个阅读动作都画一只盒子。

盘点日期：2026-10-15。公开基线：`6c8985d74ad123a4c3ae98cde8bd5b28e4b89929`，仓库 `getyak/marginalia-reader`。范围是正式 `app/` Web 页面与实际挂载模块；`_briefs/preview.html` 等设计样稿不算正式应用。本文固定记录优化前的行为与问题，后续实现和验收另列，避免把建议写成已交付。

## 阅读这份清单

每行是一项独立控件，或共享行为的重复控件族。编号只用于审阅定位，不表示用户操作次序。重复书卡、段落、目录章、日期、声音与对话轮次按生成规则列出，不随账号数据数量膨胀成几百个重复行。下拉框是一个控件，选项在同一行完整列明；不能把选项数当成按钮数。

证据等级：`源`表示已读到渲染、事件与状态分支；`见`表示浏览器快照实际出现；`点`表示本轮实际点击并读回结果。未标`点`的行都不能理解为已点击验收。表中“验收”是待执行的条件，不是通过声明。登录、生成、上传、保存与导出均有外部或持久副作用，源码覆盖不代表这些链路已经实测。

默认验收约定 `K`：桌面与390px手机都能触达；按钮/输入的触摸高度至少44px；键盘焦点可见；长中文不截掉关键动词；关闭后位置与焦点合理；减少动态效果生效。原生选择框与系统文件选择器保留系统操作。`D`：默认、悬停、键盘焦点、按下、选中、禁用、加载、成功和失败只呈现相关状态，不能单靠颜色区分。`B`：同一操作只保留一个主按钮，辅助动作使用文字或轻背景；边框保留给字段、焦点与明确的浮层边界。各行的验收在这些共同条件上追加。

## 设计判断

主体是“回到上次的书句”，不是通用办公台。保留本地衬线正文、安静留白与真实书封，沿用现有松绿交互色。推荐共同语义色：纸面 `#FBFAF4`、正文 `#26382F`、次文 `#687268`、动作 `#355845`、边界 `#D8DDD2`、错误 `#9D4F3B`；夜色用现有主题变量反转，不能在深色纸面上保留固定浅色控件。字体仍用中文本机宋体/英文 Georgia，界面使用系统无衬线。正文保持约680px宽，工具说明短于正文，不再添加无业务含义的编号、小标题或装饰线。

注意力分为三层：正文与“继续阅读”最高；当前段落的翻译/想法/朗读其次；排版、备份和系统信息收进相应面板。官网可以用一处光影建立记忆，书页上的动效只回应操作。默认纸面不动、不出声；氛围声音应由有清楚预期的动作启动。细边框、书架与阴影应有实际空间关系，不为每条工具增加同强度轮廓。

优先修正：听读面板遮罩关闭只检查左侧；多类32–38px小控件；阅读工具内同等权重的动作过多；部分禁用服务入口占据主视觉；选中态、忙碌态与返回焦点规则不统一；兼容体验与正式公版阅读的能力差异未集中说明。每项下文均有定位与验收。
