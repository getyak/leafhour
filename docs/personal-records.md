# 修改自己的想法与问题

在段落旁注的“我的想法”或“问题”中，找到已保存的记录，选择“修改原话”或“修改问题”。保存后会显示修改时间；原文位置、当时的引用和创建时间保留。问题仍是自己的未解决问题，修改文字不代表已经得到答案。

输入的文字按文本显示，包含 HTML 字符也不会作为网页执行。作者原文、译文、编辑说明、AI 回答与自己的原话各有归属；编辑自己的记录不会改写其他内容。

如果另一处已经修改，当前草稿会保留。草稿同时保留开始修改时的原话版本，刷新也不会自动采用新版本。选择“读取较新原话/问题”，核对新旧文字，再次选择保存，才会更新已保存的版本；不会自动用旧页面覆盖新的原话。容量或输入校验明确拒绝时，草稿仍在，可以调整文字后再次保存。

如果保存应答中断，可以“重试上次修改”。重试先确认上次提交，期间新写的文字仍留作草稿，需要再保存一次。“暂存并关闭”会保留尚未确认的提交和新草稿，不能撤回可能已保存的修改；取消一份尚未提交的修改不会改变书房里的原话。

修改草稿按账号、书籍、原文版本和记录分别保留在当前浏览器。若浏览器不能保存，页面会明确提示先复制文字，不把页面中的草稿称为已经同步。现有书房备份包含已保存的原话、创建/修改时间和引用；**导出前先保存修改**，尚未保存的修改草稿不自动进入现有书房备份。不要依赖清除浏览器数据来处理未确认的修改。

在“我的记录”可回到相应书籍和段落。无法确定原文位置或版本时，原话与引用仍可查看，页面标记“原文位置待确认”，不猜测移动，也不在未确认的位置修改。已存在的旧记录保持兼容；恢复备份不会覆盖书房里已有的同 ID 原话。
