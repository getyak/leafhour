# 人物与作品

人物页把生平、作品与原文放在一条阅读路径里。从书内的作者入口进入，可以先看这本书的来处，再沿着人生事件继续读。人物馆入口是 `/people`。

页面提供简体中文、繁体中文、英文和日文。人物内容缺少当前语言时，保留原语言并标出回退。切换语言不会重新生成传记。年份可以只精确到年，也可以保留约年或争议，不用一个空的逝世日期推断人物仍在世。

## 阅读与整理

已有资料直接读取保存版本。“整理人物资料”会先展示本次范围与可用来源，确认后才调用生成服务。没有配置服务、没有取得可读来源，或本次额度不可用时，已有内容仍可阅读和编辑。保存手工资料不会启动模型。

本次整理只处理一个人物，可关联一部作品。每次最多处理 20 件事件、8 部作品和 3 段原文。实际调用使用独立的资助额度，每次供应商请求的总预算上限为 US$0.02。不扣读者的阅读点数，不购买余额。账号每天最多发起 20 次，共享每日上限为 80 次，日界按服务端 UTC 计算。取消和失败仍保留额度回执，不能通过不确定重试突破上限。

生成的简介和事实保持“资料待核”。附上来源编号，只表示有待核对的材料。工具与生成服务都不能自行把新说法升级为已核事实。修改既有叙述时，新候选使用自己的证明引用，原有已核事实和原句的来源绑定继续保留。

作者自述、文献明确记载、编辑解读和同时期背景分别保存。事件发生在一本书之前，不足以证明它导致了这本书。资料不能解释写作缘由时，页面保留这个缺口。

## 分享与自己的资料

分享先展示公开版本。公共人物的个人修改只影响当前账号，分享继续使用公共资料。新建私人资料的简介、个人叙述和未经核对的标签不会随引用自动公开。公开来源也只保留实际使用的证据片段，来源尾部及私人元数据不进入副本。

发布会生成独立的 `/p/:shareId` 副本。它不会进入人物目录或搜索索引。重新打开分享面板，可以查看并逐个撤回已有副本。修改人物不会悄悄改掉别人已经打开的那份。删除私人资料会撤回其副本，原书、笔记与公共人物不受影响。撤回或安全策略已失效的链接返回失效页面。

“保存图片”提供竖图和方图。长原句按真实排版分页，保留结尾。原文与译文分别标识，未由本人复核的译文保持草稿。系统分享是否可用取决于浏览器，取消系统分享不会报错。人物页的“导出”保存整份资料，书房备份也会保留阅读对话里的人物引用。

## 阅读对话与外部工具

站内对话在当前书范围内，只查阅与该书匹配的公共作者资料。私人书的匹配使用当前已授权的书目，不把私人书 ID 保存进公共人物。选择“书房与网络”后，可以搜索已有资料及公开人物目录。“允许本次提问创建、修改或删除人物资料”默认关闭，只对这一次提问生效。

书籍连接继续使用 `/api/mcp`，保持原来的按书权限。人物连接使用独立地址 `/api/people/mcp`，在授权页由读者选择人物。工具连接需要实例配置 HTTPS 地址，权限默认只读。可另选 `people:write`、`people:create` 和 `people:generate`，最多授权 20 个人物。生成权限不代替每次准备范围的费用确认，普通写权限不包含发布。

工具包括人物搜索、分页读取、作品背景、精确提取、创建、修改、删除恢复和导出。`people_update_items` 按稳定条目标识修改少量事件或作品，避免为了改一个字段传回整份长年表。工具参数最多 8 KiB，完整响应最多 24 KiB。游标绑定人物版本，资料变化后需从当前版本重读。

外部宿主可使用 [人物撰写 skill](../skills/leafhour-author-portrait/SKILL.md)。站内生成通过官方 DSH 运行时实际加载同一份版本化规则，再验证输出。网页排版由固定组件完成。安装 skill 本身不会建立连接或授予权限。

## 验证口径

正式实现、确定性测试、真实模型调用和读者研究分别记录。首轮 72 项实验保留全部失败，后续修正另存，不能覆盖成一份看起来全绿的结果。综合分数缺少对应证据时保持未完成，不用测试通过率代替审美或启发效果。实际交付状态见人物页验收记录及对应 PR。
