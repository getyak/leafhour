# 旁读 · Marginalia Reader

旁读是一间可自托管的深度阅读书房。正文保持安静；需要时，读者可以核对原文与两种译文、查看论证骨架、留下评论、做章节选择，并把选中的句子生成聚焦分享图。

软件代码采用 AGPL-3.0 开源。默认公版英文原文及来源许可在 `catalog/`，私人书籍、个人译文、笔记、阅读记录和服务端密钥不随源码发布。

## 现在能做什么

本机新增完整入口：官网 → 公版书库 → 本机书房或邮箱验证码 → 上传 PDF / TXT / Markdown → 按段双译 → 个人记录 → 导出恢复与 MCP。默认提供《爱丽丝梦游仙境》《沉思录》和《瓦尔登湖》的完整英文原文，来源及许可保存在 `catalog/`；译文按需生成，不预先声称已译完。默认库不包含私人样书。

新版书房同时支持本机服务与 Vercel + Supabase。云端使用独立的私人数据表、版本检查和私人原文件存储；默认公版书允许匿名试读。当前线上先开放官网和试读，邮箱发送服务待配置，注册入口诚实标示尚未开放。


- 中文、英文、对照三种阅读方式，直译和意译独立保存；缺译对照只显示一次原文，明确标示缺失的版本
- 试读时登录翻译会返回同一原文段落，再次明确点击才生成；服务未配置时如实禁用入口
- 段落原文、注解、想法和问题按稳定 ID 对齐
- X-ray 论证透视、站队翻页、回声批改和克制的章节互动
- 选中句子后生成可配置的单语或双语分享图
- 字体、字号、行高、段距、字距、首行缩进和纸面主题
- 评论、问题、阅读位置及体验数据导入导出
- 本机 JSON 存储，或 Vercel + Supabase 私有托管

## 本机运行

Node.js 22.13 及以上：

```bash
npm install
npm test
npm start
```

默认访问 `http://127.0.0.1:8330/` 官网，`/library` 是书房。原有私人样书入口移到 `/read`；`/read?book=ID` 打开新书房中的指定书。没有本机私人样书时也能用默认公版库启动。本机上传与记录放在被 Git 忽略的 `local/service/portal/`，不会进入公开源码。

PDF 在本机提取，限制为 20 MB、500 页和 200 万文字；扫描 PDF 和加密文件给出明确失败原因，当前不含 OCR。默认三本书使用已核对边界的原书目录，首次从正文开始，前言和附录仍可打开。私人上传暂按每 30 段分成阅读片段，界面注明自动分段，不能当成作者的原章结构。目录调整保留段落 ID，已有笔记与位置继续对应原句。

重新选择无效文件会清除旧选择，不能误传上一次的文件。上传失败后可以重试或换文件；关闭上传窗口会让当前请求继续，成功后更新书架。私人 PDF 阅读页可展开查看文件名与提取说明，明确标示尚未校对。

来源说明中可下载自己上传的原文件校对；下载前校验文件内容，原件仅向所属书房账户提供。JSON 备份没有原件时会明确提示，再上传同一原件可补回并保留已有译文和记录，包括从其他账户迁移的书籍。原件下载不属于现有 MCP 正文授权。

书房显示上次阅读的章节，点击“继续阅读”回到原段落和排版。登录后的服务端位置优先，匿名试读只保存在本机浏览器。多个标签页同时阅读时，旧位置不会静默覆盖新位置；页面保留当前内容，让用户选择较新的位置或继续读这里。导出当前记录也遵守这项检查。

长段落另外保存段内阅读比例，刷新、字号变化或不同窗口宽度下可恢复到段落中相近的位置。旧记录继续按原像素偏移恢复。比例定位不保证逐字相同；原文和段落标识保持不变。

想法和问题保存期间可以继续写。保存确认只清除那次提交，后来写的文字仍作为草稿保留。草稿与待确认的提交按账户和书籍缓存在浏览器；确认丢失后可准确重试，刷新会先核对已保存记录。浏览器无法保留草稿时会提示复制文字；未提交草稿不包含在书房导出中。

匿名试读打开个人记录时，可以登录并回到同一原文段落和面板。返回意图只使用一次，后续刷新仍按正常续读位置。已登录但记录读取失败时可在当前页面重试；读取到更新的位置后，先选择从哪里继续，导出也遵守这项保护。超过引用上限的整段文字不写入记录引用，原文与段落关联保留，重试仍使用同一个提交标识。

### 邮箱与翻译

复制 `.env.example` 为 `.env`，配置 SMTP 后用 `npm run start:configured` 启动。验证码真实通过 SMTP 发送，十分钟过期、一次有效、五次失败后失效；注册与登录共用入口，会话保存在 HttpOnly Cookie 中。没有 SMTP 时不会假装发信；本机书房是独立的单人使用方式，不代表邮箱身份已核验。

退出后清空页面的私人书名、授权列表、显示中的令牌和文件选择；书籍与已创建的 Agent 授权仍保存在服务端，授权需要在书房主动撤回。账户切换后，旧请求不能更新新账户页面，旧恢复任务不能继续向新账户写入；从其他标签页返回时会检查当前身份。

配置 `DEEPSEEK_API_KEY` 后，点击段落再选择“翻译这段”。仅发送当前及前后各一段，直译和意译独立保留为 AI 草稿。字号、已有译文切换和阅读都不调用模型。该按段翻译使用 DeepSeek 接口；原样书回声继续使用官方 DSH。

翻译进行中可以切到其他段落，结果仍归属原段落；回到仍在翻译的段落时不能重复提交。切走或取消选择后，迟到结果不会强制改变阅读语言。失败提示与重试也对应原段落。已有双译直接在本地打开；未配置服务时明确禁用生成入口，保留原文和已有译文。

中文原文直接阅读，没有已有译文时只提供原文视图，不标成英文或缺译。中文段落不调用中文翻译服务；已有的双译记录仍可读取。摘录标示“中文原文”，笔记引用另外保存原文或译文的归属。中英文识别使用文本启发式，加载旧私人书时也会校正早期语言标记；这不代表能准确识别任意混合语言书籍。

“数据与 Agent”能导出书房（提取原文与译文，以及笔记和位置，不包含源 PDF 或密钥），并在新实例恢复。原始 PDF 仍保留在自己的本机数据目录。

恢复前先检查整个备份，再检查每本书与已有原文是否冲突。格式错误会标明第几本书，检查阶段不写入书房；检查通过后按书和数据批次恢复。网络中断或写入失败可能留下部分已恢复数据，页面会说明，可再次选择同一备份合并。恢复的位置使用本实例递增版本，旧阅读标签页仍须处理位置冲突。

### 连接 MCP

先在书房“数据与 Agent”选择书籍和范围，创建七天授权。结果会显示实际授权的书籍、范围和到期日，令牌默认隐藏，只在当前页保留。展开“接到我的 Agent”，可以复制或保存使用当前电脑实际启动路径与端口的配置；预览只含令牌占位，复制或保存的配置包含本次令牌。书籍 ID 与接入步骤也显示在该处。此功能需要在运行旁读的电脑上使用，生成配置不代表已在用户的 Agent 中接入。

收起令牌只清本页显示；撤回会立即停止后续访问，并清除对应的页面令牌和配置预览。已经复制的内容不会自动从其他地方清除。使用官方 MCP SDK 的 stdio 入口，连接同一个本机阅读服务；下面为使用默认端口的手动示例：

```json
{
  "mcpServers": {
    "marginalia": {
      "command": "node",
      "args": ["/absolute/path/to/marginalia-reader/server/mcp.mjs"],
      "env": {
        "READER_SERVICE_URL": "http://127.0.0.1:8330",
        "READER_AGENT_TOKEN": "your-scoped-token"
      }
    }
  }
}
```

工具包括 `reader_get_context`、`reader_get_chapter`、`reader_search`、`reader_get_notes`、`reader_get_reading_activity` 和 `reader_add_comment`。正文、笔记、活动与写评论分别授权；写入只接受明确提供的用户原话，幂等键防止重复保存。Agent 读取不增加阅读时间。本机配置连接环回地址；云端配置通过发布的 `v0.2.0` 源码包启动同一 stdio 适配器，并显式允许配置中的 HTTPS 书房。远程访问仍按书与数据类型授权，拒绝重定向；这不是远程 OAuth MCP 端点。配置生成不代表已在用户 Agent 中安装。

## 私有托管

公开代码与私人数据分开：

```text
GitHub public repo ──自动部署──> Vercel
                                  │ server-side secret
                                  ▼
                         Supabase private tables
                         ├─ book + translations
                         └─ notes + reading state
```

建表迁移在 `supabase/migrations/`。新版使用独立的 `reader_documents` 表与私人 `reader-originals` 存储桶；RLS 开启，`anon` 和 `authenticated` 没有直接表权限。原有两张单书数据表保留，不作为公开入口。Vercel Function 使用服务端 secret 访问。完整部署步骤见 [deploy/README.md](deploy/README.md)。

浏览器端不需要服务端 key。`.env.hosted.example` 只列变量名，真实值应放入 Vercel Environment Variables 或本机被忽略的 `.env`。

## 内容边界

阅读器、数据格式、迁移、导入导出与 Agent 适配可以开源。书籍内容是否可公开取决于书籍授权；软件许可证不会自动授予原书的传播权。个人记录默认只属于部署者自己的实例。
